## 📋 ADR (Architecture Decision Record)

### ADR-001: 클라우드 기반 제어 및 현장 분석의 계층화

| 항목 | 내용 |
|------|------|
| **상황(Context)** | 현장에서 발생하는 복잡한 FT-NIR 분석 데이터와 제어 명령을 효율적으로 처리하고, 재사용 농축액의 농도 변화를 실시간으로 모니터링해야 함. |
| **결정(Decision)** | 현장 분석 (FT-NIR 시스템) 은 데이터 수집과 실시간 전처리, 클라우드 기반 스마트 양액 공급관리 제어시스템은 최적화 알고리즘 및 중앙 제어를 담당하는 계층화 아키텍처 채택. |
| **근거(Rationale)** | 이미지 분석: 현장의 'FT-NIR 분석데이터전송'과 '클라우드 기반 스마트 양액 공급관리 제어시스템' 간의 양방향 통신 구조가 명확히 제시됨. 엣지에서 대용량 센서 데이터를 전처리하면 클라우드는 최적의 농도 계산에만 집중하여 처리 속도 향상. |
| **결과(Consequences)** | 실시간 데이터 처리 지연 최소화, 시스템의 확장성 확보, 중앙에서 농도 최적화 전략 수립 가능. |
| **트레이드오프(Trade-offs)** | 네트워크 연결에 따른 신뢰성 의존도 증가, 엣지 장비를 위한 고유의 유지보수 비용 발생. |

### ADR-002: 배액 재활용 탱크의 자동화된 농도 모니터링

| 항목 | 내용 |
|------|------|
| **상황(Context)** | 배액 재활용을 위한 양액 농축액 보존투입 시스템이 필요하고, 재사용 농축액탱크의 농도를 지속적으로 확인하여 과농을 방지해야 함. |
| **결정(Decision)** | '재사용 농축액탱크' 내부에도 FT-NIR 프로브를 설치하여 농도 데이터를 분석 시스템으로 전송하고, 이를 바탕으로 농축액 정량투출을 제어. |
| **근거(Rationale)** | 이미지 분석: '재사용 농축액탱크'에서 'FT-NIR 분석데이터전송'이 분석시스템으로 향하는 화살표가 존재함. 자원 효율성을 극대화하기 위해 재사용되는 농축액의 농도를 정확히 파악하는 것이 필수적임. |
| **결과(Consequences)** | 배액 재사용률 향상으로 물 및 비료 비용 절감, 식물 성장에 적합한 최적 농도 유지. |
| **트레이드오프(Trade-offs)** | 추가적인 센서 (FT-NIR) 설치 비용, 탱크 내부 구조 (침전물 등) 로 인한 측정 오차 가능성. |

### ADR-003: 최적조성비 기준에 기반한 정밀 양액 투여 제어

| 항목 | 내용 |
|------|------|
| **상황(Context)** | 시스템은 다양한 양액 (A, B, C) 과 pH 조절제를 적정 비율로 혼합하여 혼합탱크에 저장해야 하며, 이를 바탕으로 농축액을 정량적으로 투여해야 함. |
| **결정(Decision)** | 분석시스템이 산출한 최적조성비 기준을 바탕으로 '정량이송펌프'에 명령을 내리도록 설계. |
| **근거(Rationale)** | 이미지 분석: '최적조성비 기준으로 양액 농축액 정량투출 지시' 블록이 존재하며, 이를 통해 '정량이송펌프'를 제어하는 흐름이 그려짐. 수동적 관리에서 능동적 자동화 제어로 전환. |
| **결과(Consequences)** | 농약 혼합 효율 극대화, 인력 개입 최소화, 일관된 양액 농도 공급. |
| **트레이드오프(Trade-offs)** | 펌프 고장이나 제어 소프트웨어 오류 시 시스템 전체가 마비될 위험. |

## ⚠️ 잠재적 위험 분석

### 1. FT-NIR 분석기의 고장 또는 측정 오차
- **설명:** 이미지와 분석시스템의 핵심인 FT-NIR 분석기가 고장나거나, 혼합액의 색상 변화, 기포 형성 등으로 인해 측정값이 왜곡될 경우, 부정확한 농도 데이터를 기반으로 제어 명령이 발령될 수 있음.
- **심각도:** 🔴 High
- **발생 가능성:** 🟡 Medium
- **대응 방안:**
    1.  FT-NIR 프로브에 대해 정기적인 교정 (Calibration) 절차 자동화.
    2.  데이터 이상치 (Outlier) 탐지 알고리즘을 도입하여 특정 시간대 측정값을 배제.
    3.  비상 모드 (비상 정지) 로직 구현하여 신뢰할 수 없는 데이터가 나올 경우 자동으로 펌프 정지.

### 2. 네트워크 중절 및 엣지-클라우드 연동 실패
- **설명:** '클라우드 기반 스마트 양액 공급관리 제어시스템'과 현장 분석시스템 간의 통신이 끊어지면, 최신 최적화 전략 적용이나 원격 모니터링이 불가능해질 수 있음.
- **심각도:** 🔴 High
- **발생 가능성:** 🟡 Medium
- **대응 방안:**
    1.  분석시스템에 로컬 백업 알고리즘을 탑재하여 네트워크 연동 실패 시에도 사전에 학습된 기본 제어 로직으로 가동.
    2.  MQTT 등 경량 프로토콜 사용 및 5G/LAN 등 안정적 통신 경로 확보.

### 3. 재사용 농축액의 농도 농화 (Over-concentration)
- **설명:** 재사용 농축액탱크에 물이 증발하거나 농축액이 추가적으로 농축되어, 설정된 농도 기준을 초과하는 경우가 발생할 수 있음.
- **심각도:** 🔴 High
- **발생 가능성:** 🟡 Medium
- **대응 방안:**
    1.  재사용 농축액탱크에 별도의 농도 센서 또는 FT-NIR 프로브를 지속적으로 부착하여 농도 상승 감지.
    2.  농도 임계값 초과 시 추가 농축액 투입을 자동 차단 및 경고.

### 4. 정량이송펌프의 정밀도 부족 및 제어 지연
- **설명:** 펌프가 고장나거나 제어 시스템의 명령 지연으로 인해 최적 조성비를 준수하지 못하여 혼합액의 비율이 불안정해질 수 있음.
- **심각도:** 🟡 Medium
- **발생 가능성:** 🟡 Medium
- **대응 방안:**
    1.  정량이송펌프의 정밀도 (Flow rate accuracy)를 주기적으로 검증.
    2.  펌프 제어 PID 게인 튜닝을 최적화하여 제어 응답 속도 향상.

### 5. 보안 취약점 및 데이터 유출
- **설명:** 'FT-NIR Data 전송 및 데이터베이스 구축'과 같은 데이터 이동 및 저장 과정에서 보안이 취약해져 농약 데이터, 식물 상태 정보 등 민감 정보가 유출될 수 있음.
- **심각도:** 🟡 Medium
- **발생 가능성:** 🟢 Low
- **대응 방안:**
    1.  ISO/IEC 30141:2024 등 IoT 보안 표준에 준하는 암호화 통신 (TLS) 적용.
    2.  네트워크 분리 ( VLAN 구분) 및 접근 제어 (Role-Based Access Control) 구현.
