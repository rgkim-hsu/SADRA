# 🏗️ 아키텍처 분석 보고서

## 📋 ADR (Architecture Decision Record)

### ADR-001: 클라우드 기반 영양액 최적화 및 원격 제어 아키텍처 채택

| 항목 | 내용 |
|------|------|
| **상황(Context)** | 재배 농장(100) 내 개별 작물의 상태에 따른 정밀한 양액 공급이 필요하며, 사용자의 숙련도에 의존하지 않고 서버(300)의 전문 데이터를 기반으로 최적의 재배 환경을 구축해야 함. |
| **결정(Decision)** | 로컬 컨트롤러(600)가 독립적으로 동작하는 대신, 외부 서버(300)로부터 실시간 '서버 양액 정보'를 수신하고 모바일 기기(200)의 '사용자 양액 정보'와 동기화하여 양액 탱크(400)를 제어하는 하이브리드 클라우드 구조를 채택함. |
| **근거(Rationale)** | 대규모 작물 재배 DB를 로컬에 저장하기에는 리소스 한계가 있으며, 지속적인 데이터 업데이트와 다수의 농장 정보를 통합 관리하기 위해 중앙 집중식 분석 및 배포 구조가 효율적임. |
| **결과(Consequences)** | (긍정적) 최신화된 영양 공급 알고리즘 적용 가능, 모바일 앱을 통한 실시간 모니터링 및 개입 용이. (부정적) 네트워크 의존성 증가 및 서버 장애 시 현장 제어 기능의 제약 가능성. |
| **트레이드오프(Trade-offs)** | 고도화된 지능형 농업 서비스를 제공하는 대신, 시스템 구성의 복잡도 상승과 통신 인프라 유지 비용을 감수함. |

## ⚠️ 잠재적 위험 분석

### 1. 단일 장애점(SPOF) 위험
- **설명:** 중앙 서버(300) 또는 네트워크 장애 발생 시, 컨트롤러(600)가 최적의 양액 정보를 수신하지 못해 자동 제어 루프가 중단될 수 있음.
- **심각도:** 🔴 High
- **발생 가능성:** 🟡 Medium
- **대응 방안:** 컨트롤러(600)에 로컬 캐싱 기능을 구현하여 네트워크 단절 시에도 마지막으로 검증된 파라미터로 동작하는 'Safe Mode' 운영 정책 수립.

### 2. 양액 농도 및 공급 과부하 (하드웨어 오작동)
- **설명:** 제어 로직의 버그나 센서 데이터 오류로 인해 양액 탱크(400)에서 작물(110)로 과도하거나 잘못된 배합의 양액이 공급되어 작물이 고사할 위험.
- **심각도:** 🔴 High
- **발생 가능성:** 🟡 Medium
- **대응 방안:** 물리적 한계치(Physical Threshold)를 설정한 하드웨어 인터록(Interlock) 회로를 구성하고, 이상 징후 발생 시 조명(120)을 통해 현장 시각 알람 송출.

### 3. 모바일 기기(200) 접근 권한 탈취 및 보안
- **설명:** 사용자의 스마트폰이 해킹되어 비정상적인 양액 정보가 서버로 전달되거나, 제어 명령이 악의적으로 조작될 시 전체 농장 시스템이 마비될 수 있음.
- **심각도:** 🔴 High
- **발생 가능성:** 🟡 Medium
- **대응 방안:** MFA(다요소 인증) 도입 및 모바일-서버-컨트롤러 간 종단간 암호화(E2EE) 적용, 비정상적인 수치 입력 시 관리자 재승인 프로세스 구축.

### 4. 데이터 정합성 불일치
- **설명:** 서버(300)의 '서버 양액 정보'와 사용자가 모바일(200)에서 설정한 '사용자 양액 정보' 사이의 충돌이 발생할 경우 컨트롤러(600)가 어느 값을 우선순위로 둘지 결정하지 못함.
- **심각도:** 🟡 Medium
- **발생 가능성:** 🔴 High
- **대응 방안:** 명확한 데이터 우선순위 정책(Conflict Resolution Policy)을 아키텍처에 정의하고, 모든 설정 변경 이력을 타임스탬프와 함께 로깅하여 충돌 발생 시 알림 제공.

### 5. 환경 센서 및 조명(120) 연동 실패
- **설명:** 상단 조명(120)의 상태 정보가 컨트롤러(600)의 제어 주기와 동기화되지 않아 작물의 광합성 주기와 양액 공급 타이밍이 어긋날 위험.
- **심각도:** 🟡 Medium
- **발생 가능성:** 🟡 Medium
- **대응 방안:** 실시간 통신 프로토콜(예: MQTT, CoAP)을 사용하여 센서 데이터와 액추에이터 제어 명령 간의 동기화 지연시간(Latency)을 100ms 이내로 관리.
