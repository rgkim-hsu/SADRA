📋 ADR (Architecture Decision Record)
-------------------------------------

### ADR-001: **IoT 기반 실시간 환경 모니터링 및 제어 시스템 도입**

| 항목                     | 내용                                                                                                                                              |
| ---------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| **상황(Context)**        | 스마트팜 시스템은 온실 내 온도, 습도, CO₂ 농도 등 환경 변수를 실시간으로 모니터링하고 제어해야 합니다. 기존 수동 관리 방식은 효율성이 낮고 인적 오류가 발생하기 쉽습니다. 또한, 원격으로 환경 데이터를 확인하고 제어할 수 있는 시스템이 필요합니다. |
| **결정(Decision)**       | IoT 센서(온도, 습도, CO₂)를 통해 실시간으로 환경 데이터를 수집하고, 웹/스마트폰 제어 시스템을 통해 사용자가 원격으로 데이터를 확인 및 제어할 수 있도록 합니다. 또한, 환경 제어 시스템이 피드백을 통해 자동으로 환경을 최적화하도록 설계합니다.  |
| **근거(Rationale)**      | IoT 센서는 실시간 데이터 수집을 가능하게 하며, 웹/모바일 인터페이스는 사용자 접근성을 높입니다. 자동화된 환경 제어 시스템은 인적 개입을 최소화하고, 데이터 기반의 정확한 제어를 가능하게 합니다. 이는 스마트팜의 생산성을 극대화하는 핵심 요소입니다.  |
| **결과(Consequences)**   | **장점:** 실시간 모니터링으로 환경 최적화, 원격 제어로 편의성 향상, 자동화로 인한 인력 비용 절감. **단점:** IoT 센서의 유지보수 필요, 네트워크 의존성, 보안 취약점 가능성.                                      |
| **트레이드오프(Trade-offs)** | **장점:** 생산성 및 효율성 향상, 데이터 기반 의사결정 가능. **단점:** 초기 구축 비용 증가, 시스템 복잡성 증가, 보안 리스크 상존.                                                               |

* * *

⚠️ 잠재적 위험 분석
------------

### 1. **IoT 센서 고장 또는 오류**

* **설명:** 온도, 습도, CO₂ 센서가 고장나거나 오류를 발생시켜 잘못된 데이터를 전송하는 경우, 환경 제어 시스템이 잘못된 명령어를 내릴 수 있습니다.
* **심각도:** 🔴 High
* **발생 가능성:** 🟡 Medium
* **대응 방안:** 센서의 주기적인 검사 및 교체, 다중 센서를 통해 데이터 교차 검증, 오류 감지 알고리즘 도입.

* * *

### 2. **네트워크 연결 불량**

* **설명:** 인터넷 연결이 불안정하거나 끊기면 실시간 데이터 수집 및 원격 제어가 불가능해집니다.
* **심각도:** 🔴 High
* **발생 가능성:** 🟡 Medium
* **대응 방안:** 로컬 백업 시스템 구축, 모바일 네트워크(5G/LTE) 등 대체 연결 방식 마련, 오프라인 모드에서 제한적 기능 제공.

* * *

### 3. **보안 취약점**

* **설명:** 웹/스마트폰 제어 시스템이 해킹당하거나, IoT 기기가 보안 취약점으로 인해 제어권을 잃을 수 있습니다.
* **심각도:** 🔴 High
* **발생 가능성:** 🟡 Medium
* **대응 방안:** 데이터 암호화, 인증 강화(2FA), 정기적인 보안 패치 및 모니터링, 네트워크 분리(Isolation) 적용.

* * *

### 4. **데이터 오염 또는 손실**

* **설명:** 센서에서 수집된 데이터가 오염되거나 저장 중 손실될 경우, 환경 제어 시스템이 잘못된 결정을 내릴 수 있습니다.
* **심각도:** 🔴 High
* **발생 가능성:** 🟢 Low
* **대응 방안:** 데이터 백업 및 복구 시스템 구축, 데이터 무결성 검증 메커니즘 도입, 클라우드 스토리지 활용.

* * *

### 5. **시스템 호환성 문제**

* **설명:** 웹/스마트폰 제어 시스템과 환경 제어 시스템 간에 호환성 문제가 발생하여 제어 명령이 제대로 전달되지 않을 수 있습니다.
* **심각도:** 🟡 Medium
* **발생 가능성:** 🟡 Medium
* **대응 방안:** 표준화된 프로토콜(예: MQTT, HTTP REST API) 사용, 시스템 통합 테스트 강화, 펌웨어 및 소프트웨어 정기 업데이트.

* * *

### 6. **전력 공급 중단**

* **설명:** 시스템이 전기 공급에 의존하고 있을 경우, 정전 시 모든 기능이 정지될 수 있습니다.
* **심각도:** 🔴 High
* **발생 가능성:** 🟢 Low
* **대응 방안:** 비상 전원 공급 장치(UPS) 설치, 태양광 등 대체 에너지원 도입, 에너지 효율적인 하드웨어 사용.
