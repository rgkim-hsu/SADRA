### ADR-001: 표준화된 계층형 서비스 기반 마이크로서비스 아키텍처 채택

| 항목 | 내용 |
|------|------|
| **상황(Context)** | 스마트 농업 시스템은 센서, 환경 모니터링, 기상 예측 등 이질적이고 폭발적으로 증가하는 실시간 데이터를 다룹니다. 또한, 단순 데이터 수집을 넘어 농업 전문 지식(Agricultural Information)을 바탕으로 '의사 결정(Decisions)'을 지원해야 하므로, 시스템은 높은 **상호운용성(Interoperability)**, **확장성(Scalability)**, 그리고 **신뢰성(Reliability)**을 동시에 요구합니다. |

## ⚠️ 잠재적 위험 분석

### 1. 데이터 인터페이스 및 상호운용성 위험 (Interoperability Failure)
- **설명:** 현장의 센서, 구동기(Actuators), 레거시 장비 등 다양한 공급업체의 이기종 장치들이 표준화되지 않은 프로토콜(예: 독점 RS-485, Zigbee, LoRaWAN 등)을 사용하여 데이터를 전송할 때, 데이터 수집 계층(Data Collection Functional Entity)에서 통일된 포맷으로 변환하는 과정에서 실패가 발생할 수 있습니다.
- **심각도:** 🔴 High
- **발생 가능성:** 🔴 High
- **대응 방안:** 데이터 수집 게이트웨이(Edge Gateway) 레벨에 **지능형 데이터 어댑터 계층(Intelligent Adapter Layer)**을 구축하고, 모든 데이터는 입수 즉시 표준화된 데이터 모델(예: JSON Schema 기반 농업 데이터 모델)로 강제 변환(Schema Enforcement)해야 합니다. 표준화된 API 규격(oneM2m)을 필수적으로 적용합니다.

### 2. 사이버 보안 및 데이터 무결성 위험 (Cybersecurity & Integrity Risk)
- **설명:** 농업 시스템은 물리적 환경(물, 비료, 작물)을 제어하는 시스템(IoT control systems)과 연결되어 있어, 사이버 공격을 받으면 물리적 재해로 이어질 수 있습니다. 악의적인 공격자가 네트워크를 통해 제어 신호를 변조하거나 중요 데이터를 탈취할 위험이 높습니다.
- **심각도:** 🔴 High
- **발생 가능성:** 🟡 Medium
- **대응 방안:** **제로 트러스트 아키텍처(Zero Trust Architecture)**를 적용하여 모든 장치와 사용자에 대해 '절대 신뢰하지 않는다'는 전제로 접근 제어를 구현합니다. 데이터 전송 구간은 TLS 1.3 또는 VPN을 사용하며, 모든 제어 명령은 다중 인증 및 권한 검증(Authorization)을 거쳐야 합니다.

### 3. 예측 모델의 드리프트 및 신뢰성 위험 (Model Drift & Reliability Risk)
- **설명:** 시스템의 핵심인 '데이터 분석(Data Analysis)' 및 '예측 기능(Prediction Functional Entity)'은 AI/ML 모델에 의존합니다. 그러나 기후 변화, 새로운 병충해 출현 등 예측하지 못한 외부 요인(Novelty)이 발생하거나 환경 데이터의 패턴이 변할 경우(Model Drift), 모델의 예측 정확도가 급격히 떨어져 잘못된 의사결정(Decisions)을 유발할 수 있습니다.
- **심각도:** 🔴 High
- **발생 가능성:** 🟡 Medium
- **대응 방안:** AI 모델 운영을 **MLOps(Machine Learning Operations)** 파이프라인으로 자동화하고, 모델 성능 모니터링을 필수화합니다. 예측 결과가 특정 임계값(Threshold)을 벗어나거나, 입력 데이터의 편차가 클 경우, 시스템은 예측값을 제시하는 대신 사용자에게 **'주의' 또는 '수동 검토 필요'** 알림을 발생시켜 최종 의사결정의 위험을 낮춰야 합니다.

### 4. 확장성 및 실시간 데이터 처리 지연 위험 (Scalability & Latency Risk)
- **설명:** 스마트팜은 시간에 따라 폭발적으로 증가하는 시계열 데이터(Time-series Data)를 초당 수만 건씩 수집합니다. 이러한 대용량의 실시간 데이터가 '농업 정보 저장소(Agricultural Information Repository)'에 적시에 적재되거나, '계산 기능(Calculation Functional Entity)'을 거쳐 분석에 사용되지 못하고 지연될 경우, 시스템의 실시간 대응 능력이 상실됩니다.
- **심각도:** 🟡 Medium
- **발생 가능성:** 🔴 High
- **대응 방안:** 엣지 컴퓨팅(Edge Computing)을 활용하여 데이터 전처리를 근거리에서 수행하고, 데이터 저장소는 **스트리밍 플랫폼(예: Apache Kafka/Kinesis)**을 통해 대용량의 데이터를 버퍼링하고 비동기적으로 처리해야 합니다. 또한, 데이터베이스는 시계열 데이터에 최적화된 데이터베이스(예: TimescaleDB)를 채택해야 합니다.

### 5. 시스템 최적화 실패 위험 (Operational Misalignment Risk)
- **설명:** 시스템이 단순히 데이터를 수집하고 분석하는 것을 넘어, 실제 환경에 '제어 명령(Control Signal)'을 내려 작물 생육 환경을 물리적으로 변경하는 단계(Actuation)까지 연결됩니다. 만약 소프트웨어 로직과 실제 현장의 물리적 제어 장치(PLC, 밸브 등) 간의 인터페이스 오작동이나 통신 지연이 발생하면, 작물에 치명적인 피해를 입힐 수 있습니다.
- **심각도:** 🔴 High
- **발생 가능성:** 🟡 Medium
