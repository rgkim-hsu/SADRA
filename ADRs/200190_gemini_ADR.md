# 🏗️ 아키텍처 분석 보고서

## 📋 ADR (Architecture Decision Record)

### ADR-001: 중앙 집중형 농업 정보 저장소(Agricultural Information Repository) 기반의 데이터 파이프라인 구축

| 항목 | 내용 |
|------|------|
| **상황(Context)** | 스마트팜 환경에서 발생하는 실시간 환경 데이터, 로그 데이터, 그리고 전문가의 노하우(Know-how) 데이터를 통합하여 사용자에게 고도화된 재배 계획 및 예측 정보를 제공해야 함. 파편화된 데이터 수집 모듈들 간의 정합성을 유지하고 분석 기능과의 유연한 연동이 필수적인 상황임. |
| **결정(Decision)** | 모든 수집 데이터(Environment, Log, Expertise)를 단일 'Agricultural Information Repository'로 통합하고, 이를 'Data Analysis Function' 및 'Plan Consulting Function'과 연결하는 데이터 중심 아키텍처(Data-Centric Architecture)를 채택함. |
| **근거(Rationale)** | 1) 데이터 일관성 확보: 다양한 소스에서 오는 데이터를 단일 지점에서 관리하여 분석 신뢰도 향상. 2) 확장성: 새로운 수집 엔티티나 분석 모델 추가 시 중앙 저장소 인터페이스만 맞추면 되므로 시스템 복잡도 감소. 3) 의사결정 지원: 과거 데이터와 실시간 데이터를 결합한 복합 분석 최적화. |
| **결과(Consequences)** | 긍정적: 데이터 기반의 정확한 재배 가이드 제공 가능, 시스템 유지보수 효율성 증대. 부정적: 저장소 장애 시 전체 서비스 마비 가능성(SPOF), 데이터 처리량 증가에 따른 저장소 병목 현상 발생 가능. |
| **트레이드오프(Trade-offs)** | 저장소의 일관성과 관리 편의성을 얻는 대신, 대규모 트래픽 발생 시 저장소의 확장 비용(Scaling Cost)과 가용성 확보를 위한 추가 인프라 설계 비용이 발생함. |

---

## ⚠️ 잠재적 위험 분석

### 1. 중앙 데이터 저장소의 단일 장애점(SPOF) 위험
- **설명:** 모든 데이터 수집 및 분석 기능이 Agricultural Information Repository에 의존하므로, 해당 저장소 장애 시 전체 스마트팜 서비스가 중단됨.
- **심각도:** 🔴 High
- **발생 가능성:** 🟡 Medium
- **대응 방안:** DB 클러스터링 및 다중 가용 영역(Multi-AZ) 배치, 실시간 백업 및 자동 장애 조치(Failover) 메커니즘 구축.

### 2. 네트워크 지연 및 연결 유실에 따른 데이터 누락
- **설명:** 현장의 센서 데이터를 네트워크를 통해 전송하는 과정에서 불안정한 통신 환경으로 인해 환경 모니터링 데이터가 유실되어 분석 결과의 왜곡이 발생함.
- **심각도:** 🔴 High
- **발생 가능성:** 🔴 High
- **대응 방안:** 엣지 컴퓨팅(Edge Computing) 도입으로 로컬 1차 저장 후 재전송(Store-and-Forward) 기술 적용, 메시지 큐(Message Queue)를 활용한 전송 보장.

### 3. 노하우(Know-how) 기반 데이터의 주관성 및 품질 저하
- **설명:** Expertise Data는 전문가의 경험에 의존하므로 정형화되지 않은 데이터나 검증되지 않은 정보가 유입될 경우, 예측 모델의 정확도를 떨어뜨릴 수 있음.
- **심각도:** 🟡 Medium
- **발생 가능성:** 🟡 Medium
- **대응 방안:** 전문가 데이터 입력 프로세스에 검증(Validation) 단계 도입, AI 기반의 이상치 탐지를 통해 상충하는 노하우 데이터 필터링.

### 4. 예측 모델(Prediction Functional Entity)의 편향성 및 오작동
- **설명:** 과거 데이터에만 치중하여 학습된 예측 모델이 기후 변화나 돌발적인 환경 변수를 반영하지 못해 잘못된 재배 솔루션을 제공함.
- **심각도:** 🔴 High
- **발생 가능성:** 🟡 Medium
- **대응 방안:** 주기적인 모델 재학습(Retraining) 파이프라인 구축 및 실시간 피드백 루프를 통한 모델 성능 지속 모니터링.

### 5. 농업 데이터 및 사용자 정보의 보안 위협
- **설명:** 서비스 사용자의 농가 정보 및 상업적 가치가 높은 재배 노하우 데이터가 네트워크 전송 또는 저장소 접근 과정에서 외부로 유출됨.
- **심각도:** 🔴 High
- **발생 가능성:** 🟡 Medium
- **대응 방안:** 종단간 암호화(End-to-End Encryption), 역할 기반 접근 제어(RBAC) 강화, 네트워크 구간 보안(VPN/SSL) 및 주기적인 보안 취약점 점검.
