## 📋 ADR (Architecture Decision Record)

### ADR-001: [심화학습 기반 제어 에이전트 도입 (DDPG 선택)]

| 항목 | 내용 |
|------|------|
| **상황 (Context)** | 스마트 온실 환경은 온도, 습도, 광량 등 연속적인 변수들이 복합적으로 작용하며, 실시간으로 변화하는 기상 조건 (Weather forecast) 에 대응해야 합니다. 기존의 PID 제어나 규칙 기반 제어는 이러한 비선형적이고 동적인 환경 최적화에 한계가 있으며, 데이터 기반의 지능형 제어 기법이 필요합니다. |
| **결정 (Decision)** | 이산적 행동 공간이 아닌 연속적인 환경 제어 (밸브 개도, 팬 속도 등) 를 위한 **DDPG (Deep Deterministic Policy Gradient)** 알고리즘을 에이전트 구현의 핵심 로직으로 채택함. |
| **근거 (Rationale)** | <ul><li>**연속 제어 변수 처리:** 밸브, 팬, 난방장치 등 온실 제어기는 연속적인 값 (Continuous Action Space) 을 갖는데, DDPG 는 연속 공간에 최적화됨.</li><li>**모델 무관 (Model-Free):** 정밀한 물리 모델을 구축하지 않아도 실시간 센서 데이터 (State) 와 보상 (Reward) 으로 학습 가능하여 개발 효율성 높음.</li></ul> |
| **결과 (Consequences)** | <ul><li>**긍정적:** 복잡한 기상 변화 및 식물 생장 패턴에 대한 최적 제어 전략 (Optimal Policy) 자동 생성 가능.</li><li>**부정적:** 초학습 (Training) 기간이 길고, 초기에는 예측 불가능한 제어 출력이 발생할 수 있음.</li></ul> |
| **트레이드오프 (Trade-offs)** | <ul><li>**장점:** 극한 기상 상황이나 생체 신호 변화에 대한 적응성 (Robustness) 극대화.</li><li>**단점:** 컴퓨팅 자원 요구량 증가 및 모델의 투명성 (Black-box) 저하.</li></ul> |

### ADR-002: [가상 환경 기반 강화학습 학습 전략 수립]

| 항목 | 내용 |
|------|------|
| **상황 (Context)** | 실온실 (Physical Greenhouse) 에서 직접 강화학습을 수행할 경우, 실수를 통해 작물이 손상될 수 있으며 데이터 수집 및 학습 속도가 매우 느립니다. 또한 인간 전문가의 경험과 지식을 시스템에 통합해야 합니다. |
| **결정 (Decision)** | **시뮬레이션 기반 가상 학습 (Sim-to-Real Transfer)** 아키텍처를 도입. 인간 전문가 (Human experts) 와 기상 데이터 (Weather forecast) 를 포함한 **Greenhouse Library KR** 가상 환경을 구축하여 에이전트를 사전 학습시킴. |
| **근거 (Rationale)** | <ul><li>**안전성:** 가상 환경에서의 실패는 실제 작물에 피해가 없어 안전한 학습이 가능합니다.</li><li>**데이터 확장성:** 기상 조건, 질병 등 실제보다 다양한 시나리오 (Scenarios) 를 생성하여 학습할 수 있습니다.</li><li>**효율성:** 인간 전문가의 피드백을 빠르게 반영하여 보상 함수 (Reward Function) 를 최적화할 수 있습니다.</li></ul> |
| **결과 (Consequences)** | <ul><li>**긍정적:** 학습 시간 단축 및 실제 배포 전 리스크 제거.</li><li>**부정적:** 시뮬레이션과 현실 환경 간의 차이 (Sim-to-Real Gap) 로 인해 실제 환경에서 성능이 저하될 수 있음.</li></ul> |
| **트레이드오프 (Trade-offs)** | <ul><li>**장점:** 다양한 에지 (Edge) 기반 시나리오 테스트 가능.</li><li>**단점:** 시뮬레이션 엔진의 물리 엔진 정밀도가 실제 정확도를 제한할 수 있음.</li></ul> |

## ⚠️ 잠재적 위험 분석

### 1. [실제-가상 환경 간 격차 (Sim-to-Real Gap)]
- **설명:** 시뮬레이션 모델 (Greenhouse Library KR) 이 실제 물리적 온실의 복잡성 (센서 노이즈, 장비 노후화, 미세 기후 변화) 을 완벽히 반영하지 못할 경우, 가상에서 학습된 정책이 현실에서 실패할 위험이 있습니다.
- **심각도:** 🔴 High
- **발생 가능성:** 🟡 Medium
- **대응 방안:** 도메인 랜덤화 (Domain Randomization) 기법을 적용하고, 시뮬레이션과 실제의 파라미터 불일치를 최소화하는 보정 (Fine-tuning) 프로세스를 도입함.

### 2. [AI 에이전트의 안전성 및 보안 취약점]
- **설명:** 강화학습 에이전트가 보상 함수를 극대화하기 위해 예기치 않은 행동을 보일 수 있습니다. (예: 과격한 온도 상승으로 작물 손상). 또한, IoT 네트워크 취약점을 공격받으면 공격자가 에이전트를 조작하여 제어 명령을 조작할 수 있습니다.
- **심각도:** 🔴 High
- **발생 가능성:** 🟡 Medium
- **대응 방안:** 에이전트 출력에 하드웨어 레벨의 안전장치 (Hardware Limiters) 를 설치하고, ITU-T X.1352 및 ETSI EN 303 645 기준에 맞는 암호화 통신 및 접근 제어 목록 (ACL) 을 적용함.

### 3. [데이터 드리프트 및 일반화 능력 부족]
- **설명:** 학습 데이터에 포함된 기상 데이터 분포와 실제 운영 환경의 기후 패턴이 다르면 (예: 장기 가뭄 또는 폭우), 에이전트의 성능이 급격히 떨어질 수 있습니다.
- **심각도:** 🟡 Medium
- **발생 가능성:** 🔴 High
- **대응 방안:** 지속적인 온라인 학습 (Online Learning) 또는 주기적인 재학습 (Re-training) 을 통해 새로운 데이터 분포를 적응하도록 모델을 업데이트하는 파이프라인 구축.

### 4. [지연성 (Latency) 과 실시간 제어 부실]
- **설명:** 엣지 장치에서 수집된 센서 데이터 처리 및 Actor-Critic 네트워크 추론 과정에서 지연이 발생할 경우, 급변하는 온실 환경 (예: 돌연 날씨 변화) 에 대응하지 못해 작물이 피해를 입습니다.
- **심각도:** 🟡 Medium
- **발생 가능성:** 🟢 Low
- **대응 방안:** DNN 추론 최적화 (Quantization, Pruning) 를 적용하고, 제어 지연 시간을 허용 가능한 임계값 (Threshold) 이나 안전 모드로 전환되는 로직을 구현함.

### 5. [블랙박스 문제 및 의사 결정 투명성 저하]
- **설명:** 농업 전문가들은 "왜 난방을 켰는지"에 대한 논리적 이유를 필요로 합니다. DNN 기반의 모델은 결정 근거를 제공하지 않아 (Black-box) 전문가들의 신뢰를 얻기 어렵고, 규제 승인 (ISO/IEC 30141:2024 준수) 이 어려울 수 있습니다.
- **심각도:** 🟡 Medium
- **발생 가능성:** 🔴 High
- **대응 방안:** SHAP (SHapley Additive exPlanations) 등의 설명 가능한 AI (XAI) 기술을 적용하여 에이전트 의사결정의 주요 요인을 시각화하여 전문가에게 보고함.
