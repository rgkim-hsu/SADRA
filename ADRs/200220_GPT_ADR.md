📋 ADR (Architecture Decision Record)
-------------------------------------

### ADR-001: 센서 데이터 기반 통합 제어 및 스마트 원격 운영 아키텍처 채택

| 항목                     | 내용                                                                                                                                                                                                                          |
| ---------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **상황(Context)**        | 시스템은 기상관측센서(온도, 습도, 풍향, 풍속, 강우, 일사량), 내부 환경센서(온도/습도), CCTV를 통해 데이터를 수집하고, 이를 통합제어기에서 처리하여 전자 밸브, 컨베이어 벨트, 열전 시설 등을 제어한다. 사용자 관제는 인터넷과 스마트폰을 통해 이루어진다. 핵심 과제는 “다양한 환경 데이터를 실시간으로 수집·분석하여 시설 제어를 자동화하고, 원격에서 효율적으로 운영하는 것”이다. |
| **결정(Decision)**       | 센서 데이터 수집 계층과 통합제어기 기반 제어 계층을 중심으로, 스마트폰 원격 제어 인터페이스를 결합한 중앙집중형 제어 아키텍처를 채택한다. 데이터 흐름은 “센서 → 통합제어기 → 제어 시스템 → 시설 동작 → 환경 변화 → 센서 피드백”의 폐루프 구조로 구성한다.                                                                        |
| **근거(Rationale)**      | 스마트팜 및 스마트 염전과 같은 환경에서는 다양한 외부/내부 요인을 동시에 고려해야 하므로 통합 제어가 필수적이다. 중앙 제어 방식은 전체 시스템 상태를 일관되게 관리할 수 있으며, 원격 제어는 운영 효율성과 대응 속도를 높인다.                                                                                            |
| **결과(Consequences)**   | **긍정적:** 실시간 환경 대응, 자동화 수준 향상, 운영 효율성 증가, 원격 관리 가능**부정적:** 중앙 제어 의존성 증가, 장애 발생 시 영향 범위 확대, 초기 구축 비용 증가                                                                                                                      |
| **트레이드오프(Trade-offs)** | 통합 제어로 인한 효율성과 편의성을 얻는 대신, 시스템 장애 및 확장성 문제에 대한 대비가 필요하다.                                                                                                                                                                    |

* * *

⚠️ 잠재적 위험 분석
------------

### 1. 센서 데이터 오류 및 누락

* **설명:** 기상 및 환경 센서 오류로 인해 잘못된 제어 명령이 내려질 수 있음

* **심각도:** 🔴 High

* **발생 가능성:** 🟡 Medium

* **대응 방안:** 센서 이중화, 데이터 검증 및 보정 알고리즘 적용

### 2. 통합제어기 장애

* **설명:** 중앙 통합제어기 고장 시 전체 시설 제어 중단

* **심각도:** 🔴 High

* **발생 가능성:** 🟡 Medium

* **대응 방안:** 이중화 구성(Active-Standby), 로컬 제어 fallback 시스템 구축

### 3. 네트워크 의존성 문제

* **설명:** 인터넷 장애 시 스마트폰 기반 원격 제어 및 모니터링 불가

* **심각도:** 🟡 Medium

* **발생 가능성:** 🔴 High

* **대응 방안:** 로컬 자동 제어 유지, 오프라인 모드 지원, 네트워크 이중화

### 4. 영상 데이터 처리 및 저장 부담

* **설명:** CCTV 데이터 증가로 저장소 및 네트워크 부하 발생

* **심각도:** 🟡 Medium

* **발생 가능성:** 🟡 Medium

* **대응 방안:** 이벤트 기반 녹화, 영상 압축, 엣지 분석 도입

### 5. 제어 시스템 오작동

* **설명:** 전자 밸브, 컨베이어 벨트, 열전 시설 오작동 시 생산성 저하 또는 장비 손상

* **심각도:** 🔴 High

* **발생 가능성:** 🟡 Medium

* **대응 방안:** 상태 모니터링, 예방 정비, 이상 감지 및 자동 차단 시스템 구축

### 6. 보안 취약점 (원격 제어 시스템)

* **설명:** 스마트폰 앱 또는 네트워크 해킹 시 시설 제어 권한 탈취 가능

* **심각도:** 🔴 High

* **발생 가능성:** 🟡 Medium

* **대응 방안:** 인증/인가 강화, 암호화 통신, 접근 제어 및 로그 감사

### 7. 환경 변화 대응 지연

* **설명:** 급격한 기상 변화에 대해 시스템 반응 속도가 늦을 경우 품질 저하 발생

* **심각도:** 🟡 Medium

* **발생 가능성:** 🟡 Medium

* **대응 방안:** 실시간 스트리밍 데이터 처리, 임계치 기반 자동 제어, 엣지 컴퓨팅 활용
