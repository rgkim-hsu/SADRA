# 🏗️ 아키텍처 분석 보고서

## 📋 ADR (Architecture Decision Record)

### ADR-001: [가상 환경 계층과 실제 제어 계층의 논리적 분리]

| 항목 | 내용 |
|------|------|
| **상황 (Context)** | 통합 환경 시뮬레이션 시스템은 실제 물리 디바이스 없이 소프트웨어 상에서 환경을 생성, 제어, 시각화하는 것을 목표로 합니다. 상단에 '환경 제너레이터', '가상 센서/제어기' 로직 블록이, 하단에 '스마트팜 통합제어시스템', '3D 환경 뷰어' 가 위치합니다. 실제 하드웨어 의존도를 줄이고 소프트웨어 테스트 및 시뮬레이션을 극대화해야 합니다. |
| **결정 (Decision)** | 시스템 아키텍처는 상단의 '가상 환경 로직' (제너레이터, 센서, 제어기) 과 하단의 '사용자/인터페이스 계층' (스마트팜 제어, 3D 뷰어) 을 엄격하게 분리합니다. 가상 계층은 표준화된 API 로 실제 제어 시스템에 데이터를 제공하는 독립적인 계층으로 설계됩니다. |
| **근거 (Rationale)** | **1. 유연성 & 테스트:** 문서 [별표 26] 에서 언급된 '디지털 트윈 기반 스마트 축사 가상 센서' 표준과 일치합니다. 실제 센서 없이 소프트웨어 로직만 변경하여 테스트 비용을 절감할 수 있습니다.<br>**2. 확장성:** 3D 뷰어처럼 표현 방식은 쉽게 변경할 수 있지만, 내부 로직은 유지할 수 있습니다. ISO/IEC 30141:2024 에서 강조하는 재사용 가능한 설계 원칙과 부합합니다.<br>**3. 위험 고립:** 시뮬레이션 오류가 실제 제어 시스템의 직접적인 로직 오류로 이어지지 않도록 장벽을 둡니다. |
| **결과 (Consequences)** | **긍정:** 실제 장비 없이도 환경 변화 (날씨, 온도) 를 시뮬레이션하여 제어 알고리즘 검증이 가능해집니다.<br>**부정:** 시뮬레이션 로직과 실제 하드웨어 간 인터페이스 오버헤드가 발생할 수 있으며, 초기 개발 속도는 다소 느릴 수 있습니다. |
| **트레이드오프 (Trade-offs)** | **장점:** 하드웨어 교체 없이 다양한 시나리오 테스트 가능.<br>**단점:** 가상 환경 모델링에 리소스와 시간이 추가로 필요합니다. |

## ⚠️ 잠재적 위험 분석

### 1. [실시간 제어 데이터의 지연 및 불일치]
- **설명:** '가상 센서/제어기' 가 생성하는 데이터가 '스마트팜 통합제어시스템' 에 전달될 때 네트워크 지연이나 버퍼링 문제로 인해 실제 환경 제어와 시뮬레이션 데이터가 비동기화될 수 있습니다.
- **심각도:** 🔴 High
- **발생 가능성:** 🔴 High (실시간 제어 시스템의 특성상)
- **대응 방안:** 우선순위 (QoS) 를 높은 실시간 메시징 프로토콜 (예: MQTT QoS 2, DDS) 을 사용하거나, 지연 시간을 최소화하기 위한 엣지 컴퓨팅 구조를 적용합니다.

### 2. [가상 환경 로직의 실제 시스템 충돌]
- **설명:** 상단의 '가상 제어기' 로직이 실제 '스마트팜 통합제어시스템' 의 명령어를 잘못 해석하거나, 시뮬레이션 상에서는 허용되는 명령이 실제 장비에서 지원되지 않는 경우 시스템 다운이나 손상 우려가 있습니다.
- **심각도:** 🔴 High
- **발생 가능성:** 🟡 Medium
- **대응 방안:** ADR 에 명시된 대로 가상 계층과 실제 계층을 격리하며, 실제 제어 명령이 실제 장비를 조작하기 전에 '명령 유효성 검사 (Validation Gateway)'를 거치도록 만듭니다.

### 3. [보안 위협 및 무단 접근]
- **설명:** '가상 제어로드' 또는 '가상 제어로더' (상하 화살표 구간) 를 통해 해커가 가상 환경을 조작하여 실제 스마트팜 제어시스템으로 악의적인 명령을 주입할 수 있습니다. 특히 문서 [ITU-T X.1352] 에서 언급된 IoT 보안 기준을 위반할 위험이 있습니다.
- **심각도:** 🔴 High
- **발생 가능성:** 🟡 Medium
- **대응 방안:** ETSI EN 303 645 에서 요구하는 사이버보안 가이드라인을 준수하여, 모든 인터페이스 트래픽을 암호화하고 (TLS/SSL), 제어로더 접근 권한을 엄격히 제한합니다.

### 4. [복잡한 의존성 및 유지보수 부담]
- **설명:** '환경 제너레이터', '가상 센서', '가상 제어기', '3D 뷰어', '스마트팜 제어시스템' 등 다양한 컴포넌트가 통합되어 있어, 하나의 컴포넌트 업데이트 시 전체 시스템 호환성 검증이 어려울 수 있습니다.
- **심각도:** 🟡 Medium
- **발생 가능성:** 🔴 High
- **대응 방안:** 마이크로서비스 아키텍처를 따르거나, 컨테이너화 (Docker/Kubernetes) 를 통해 각 컴포넌트를 독립적으로 배포하고 관리하여 의존성을 낮춥니다.

### 5. [3D 모델링 리소스 과부하]
- **설명:** '3D 환경 뷰어' 가 실시간으로 대규모 데이터를 렌더링해야 하므로, CPU/GPU 리소스가 급증하여 시스템 전체의 성능 저하를 유발할 수 있습니다.
- **심각도:** 🟡 Medium
- **발생 가능성:** 🟡 Medium
- **대응 방안:** 뷰어 계층에서 데이터 양을 필터링하거나 LOD(Level of Detail) 기술을 적용하여 렌더링 부하를 최적화합니다.
