### ADR-001: 듀얼 통신 기반 스마트팜 IoT 게이트웨이 아키텍처 채택

| 항목                     | 내용                                                                                                                                                                                                                                                                                 |
| ---------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **상황(Context)**        | 스마트팜 환경에서는 온도, 습도, 토양 상태, CO₂ 농도, 급수 상태 등 다양한 센서 데이터의 안정적 수집과 원격 제어가 필수적이다. 농업 현장은 네트워크 품질이 불안정하고 전력 공급이 제한적인 경우가 많으며, 실시간 제어와 데이터 유실 방지가 중요하다. 이미지 상의 시스템은 제1 통신부(401), 제2 통신부(402), 제어부(403), 메모리(404), 전원부(405), 에너지 하베스트부(406)로 구성되어 있으며, 이기종 통신과 저전력 운영을 동시에 만족해야 하는 과제를 가진다. |
| **결정(Decision)**       | 시스템은 이중 통신 인터페이스(Dual Communication Interface)를 채택한다. 제1 통신부는 근거리 저전력 센서망(LPWAN, Zigbee, BLE 등) 연결용으로 사용하고, 제2 통신부는 외부 클라우드 또는 농장 관리 서버와의 광역 통신(LTE, NB-IoT, Wi-Fi 등)을 담당한다. 제어부는 통신 우선순위 및 장애 전환(Failover)을 관리하며, 메모리는 Edge Buffer 및 임시 캐시로 동작한다.                                 |
| **근거(Rationale)**      | 스마트팜은 센서 노드 수가 많고 설치 환경이 넓기 때문에 단일 통신 방식으로는 안정성과 확장성을 확보하기 어렵다. 이중 통신 구조를 통해 내부 센서 네트워크와 외부 관리 네트워크를 분리하면 데이터 충돌과 장애 영향을 최소화할 수 있다. 또한 Edge 기반 제어 구조는 네트워크 단절 상황에서도 자동 제어를 유지할 수 있다.                                                                                               |
| **결과(Consequences)**   | 센서 데이터 수집 안정성이 향상되고 통신 장애 발생 시 서비스 연속성이 확보된다. 또한 네트워크 부하 분산이 가능해지고 다양한 스마트팜 디바이스와의 연동성이 증가한다. 반면 통신 모듈 증가로 BOM 비용 및 전력 소비가 증가하며, 제어 로직 복잡성이 상승한다.                                                                                                                                  |
| **트레이드오프(Trade-offs)** | 높은 안정성과 유연성을 얻는 대신, 하드웨어 복잡도와 유지보수 난이도가 증가한다. 또한 이중 통신 프로토콜 관리와 보안 정책 이원화가 필요하다.                                                                                                                                                                                                   |

### ADR-002: 에너지 하베스팅 기반 저전력 운영 구조 적용

| 항목                     | 내용                                                                                                                       |
| ---------------------- | ------------------------------------------------------------------------------------------------------------------------ |
| **상황(Context)**        | 스마트팜 센서 노드는 외부 농지, 비닐하우스, 축사 등 전원 인프라가 제한된 환경에 설치되는 경우가 많다. 지속적인 배터리 교체는 유지보수 비용을 증가시키며 운영 효율을 저하시킨다.                    |
| **결정(Decision)**       | 시스템은 전원부(405)와 에너지 하베스트부(406)를 결합하여 태양광, 열전, 진동 기반의 에너지 회수 구조를 채택한다. 제어부는 배터리 상태를 모니터링하고 저전력 모드 및 Duty Cycling 정책을 적용한다. |
| **근거(Rationale)**      | 스마트팜은 장기간 무인 운영이 요구되므로 저전력 설계가 필수적이다. 에너지 하베스팅을 적용하면 유지보수 주기를 연장할 수 있으며, 배터리 교체 비용을 절감할 수 있다.                            |
| **결과(Consequences)**   | 장기 운영성과 친환경성이 향상된다. 배터리 의존도가 감소하고 농장 운영 비용이 절감된다. 그러나 발전량이 환경 조건에 의존하므로 전력 공급이 불안정할 수 있다.                                |
| **트레이드오프(Trade-offs)** | 유지보수 효율성과 에너지 절감을 얻는 대신, 전력 관리 알고리즘 복잡성과 초기 구축 비용이 증가한다.                                                                 |

### ADR-003: Edge Intelligence 기반 로컬 제어 구조 채택

⚠️ 잠재적 위험 분석
------------

### 1. 이중 통신 모듈 간 간섭 위험

* **설명:** 제1 통신부와 제2 통신부가 동일 주파수 대역을 사용할 경우 RF 간섭이 발생하여 데이터 손실 및 지연이 발생할 수 있음

* **심각도:** 🔴 High

* **발생 가능성:** 🟡 Medium

* **대응 방안:** 채널 분리, 안테나 간 거리 확보, Adaptive Frequency Hopping 적용 및 RF Shield 설계 수행

### 2. 에너지 하베스팅 전력 부족 위험

* **설명:** 장기간 흐린 날씨나 실내 환경으로 인해 발전량이 감소하면 시스템 셧다운이 발생할 수 있음

* **심각도:** 🔴 High

* **발생 가능성:** 🟡 Medium

* **대응 방안:** 슈퍼커패시터 및 보조 배터리 적용, 저전력 Sleep 정책 강화, Critical Task 우선 실행 정책 도입

### 3. Edge 제어 로직 오작동 위험

* **설명:** 로컬 제어 알고리즘 오류로 인해 급수 과다, 온도 이상 제어 등 작물 피해가 발생할 수 있음

* **심각도:** 🔴 High

* **발생 가능성:** 🟡 Medium

* **대응 방안:** 시뮬레이션 기반 검증, Fail-safe 정책 적용, 원격 OTA 롤백 기능 구현

### 4. 메모리 데이터 손상 위험

* **설명:** 전원 불안정 또는 반복적인 쓰기 작업으로 인해 센서 로그 및 정책 데이터가 손상될 수 있음

* **심각도:** 🟡 Medium

* **발생 가능성:** 🟡 Medium

* **대응 방안:** Wear Leveling 지원 Flash 사용, ECC(Error Correction Code) 적용, 주기적 백업 수행

### 5. 원격 통신 보안 취약점

* **설명:** 외부 네트워크를 통한 악성 접근 시 센서 데이터 탈취 및 제어 명령 위변조 가능성이 존재함

* **심각도:** 🔴 High

* **발생 가능성:** 🔴 High

* **대응 방안:** TLS 기반 암호화 통신, 디바이스 인증서 적용, Secure Boot 및 Firmware Signing 도입

### 6. 네트워크 장애 시 데이터 유실 위험

* **설명:** 클라우드 연결이 끊길 경우 실시간 수집 데이터가 손실될 가능성이 있음

* **심각도:** 🟡 Medium

* **발생 가능성:** 🔴 High

* **대응 방안:** 메모리 기반 Store-and-Forward 구조 적용, MQTT QoS 정책 활용, 로컬 캐시 저장 기능 구현

### 7. 스마트팜 환경 특성에 따른 하드웨어 열화 위험

* **설명:** 습기, 먼지, 농약 노출로 인해 통신부 및 전원부 부식이 발생할 수 있음

* **심각도:** 🟡 Medium

* **발생 가능성:** 🔴 High

* **대응 방안:** IP65 이상 방수/방진 설계, Conformal Coating 적용, 산업용 부품 사용 및 정기 유지보수 수행
