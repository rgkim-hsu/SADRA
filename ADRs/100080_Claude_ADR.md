📋 ADR (Architecture Decision Record)
-------------------------------------

### ADR-001: VR 기반 스마트팜 교육 시뮬레이터와 원격 모니터링의 클라우드 중계 아키텍처 채택

| 항목                     | 내용                                                                                                                                                                                                                                   |
| ---------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **상황(Context)**        | 스마트팜 교육생(사용자, 컴포넌트 #10~#130)은 현장 방문 없이 시설 설치, 재배 교육, 시세 확인 등 복합적 학습이 필요하며, 원격 관리자(#20, #300)는 실시간으로 농장 상태를 모니터링해야 한다. VR 글러브(#10)와 스마트팜 VR 교육 시스템(#120)이 생성하는 인터랙션 데이터를 데이터 웹 서버(#300)를 통해 원격지와 양방향으로 교환해야 하는 이기종 멀티 클라이언트 환경이 존재한다. |
| **결정(Decision)**       | 중앙 데이터 웹 서버(#300)를 단일 중계 허브로 채택하여, VR 시뮬레이터(#100/#110)의 교육 세션 데이터와 원격 관리자 모니터링 단말(#20)의 요청을 REST 또는 WebSocket 기반 API로 통합 처리한다. VR 글러브(#10)는 로컬 BLE/Wi-Fi로 시뮬레이터에 연결하고, 시뮬레이터는 웹 서버를 통해 클라우드로 데이터를 업링크한다.                             |
| **근거(Rationale)**      | 스마트팜 환경은 농촌 지역의 네트워크 불안정성을 고려할 때, 엣지(시뮬레이터)에서 1차 처리 후 클라우드로 집계하는 계층적 구조가 지연 최소화와 오프라인 복원력 확보에 유리하다. 단일 웹 서버 중계는 원격 관리자의 다중 디바이스(스마트폰/태블릿, #20) 접근을 표준화하고, 교육 이력 데이터의 중앙 집중 관리를 가능하게 한다.                                              |
| **결과(Consequences)**   | ✅ 교육생과 원격 관리자 간 실시간 데이터 공유 가능 / ✅ VR 교육 이력 및 농장 운영 데이터의 중앙 집중 저장으로 분석 용이 / ⛔ 웹 서버(#300)가 단일 장애점(SPOF)으로 작동하여 서버 다운 시 전체 시스템 마비 / ⛔ 농촌 지역 고대역폭 VR 스트리밍에 필요한 안정적 인터넷 인프라 의존도 증가                                                        |
| **트레이드오프(Trade-offs)** | 【획득】 아키텍처 단순성, 관리 포인트 집중화, 원격 다중 접속 표준화 / 【감수】 중앙 서버 가용성에 대한 전체 시스템 의존, 고화질 VR 데이터 전송을 위한 높은 대역폭 비용, VR 글러브-시뮬레이터 간 로컬 지연과 클라우드 왕복 지연의 복합 발생 가능성                                                                                     |

### ADR-002: VR 글러브(햅틱 인터페이스)를 주요 HMI(Human-Machine Interface)로 채택

| 항목                     | 내용                                                                                                                                                              |
| ---------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **상황(Context)**        | 스마트팜 교육에서 시설 설치 및 재배 조작 학습은 실제 물리적 감각을 요구한다. 기존 키보드/마우스 기반 시뮬레이터는 몰입감 부족으로 교육 효과가 제한적이며, 교육생(#10 사용자)이 VR 환경 내 작물 관리 동작을 실습해야 한다.                               |
| **결정(Decision)**       | VR 글러브(#10)를 주요 입력 장치로 채택하고, Smart Farm VR Simulator(#100)와 연동하여 제스처 기반 인터랙션(시설 설치, 수확, 방제 등)을 구현한다. 디스플레이 유닛(#110)은 VR 환경을 대형 화면으로 렌더링하여 강사-학생 동시 시청 구조를 지원한다. |
| **근거(Rationale)**      | 농업 기술 교육에서 신체 운동학적(kinesthetic) 학습은 절차 기억 형성에 효과적이다. VR 글러브는 실제 농장 방문 비용과 안전 리스크 없이 반복 실습을 가능하게 하며, 스마트팜의 IoT 센서 연동 시나리오를 가상으로 체험할 수 있게 한다.                     |
| **결과(Consequences)**   | ✅ 교육 몰입도 및 절차 숙지율 향상 / ✅ 농번기·악천후와 무관한 교육 일정 운영 가능 / ⛔ VR 글러브 하드웨어 유지보수 및 캘리브레이션 비용 증가 / ⛔ 사용자 VR 멀미(Cybersickness) 발생 가능성                                       |
| **트레이드오프(Trade-offs)** | 【획득】 현장 교육 대비 비용 절감, 위험 작업 안전 실습, 반복 학습 가능 / 【감수】 고가 하드웨어 초기 투자, 장비 고장 시 교육 중단, 신체적 불편감 유발 가능                                                                   |

⚠️ 잠재적 위험 분석
------------

### 1. 단일 데이터 웹 서버(#300)의 단일 장애점(SPOF) 위험

* **설명:** 데이터 웹 서버(#300)는 VR 시뮬레이터(#100)와 원격 관리자 단말(#20) 모두가 의존하는 유일한 중계 노드다. 서버 장애, 네트워크 단절, 또는 DDoS 공격 발생 시 VR 교육 세션 저장 불가, 원격 모니터링 단절이 동시에 발생하며 전체 서비스가 중단된다.
* **심각도:** 🔴 High
* **발생 가능성:** 🟡 Medium
* **대응 방안:** Active-Active 또는 Active-Standby 이중화 서버 구성 도입. 시뮬레이터 로컬에 엣지 캐시 레이어를 추가하여 서버 단절 시에도 세션 데이터를 로컬 저장 후 복구 시 자동 동기화(Store-and-Forward 패턴) 적용. CDN 및 로드밸런서 도입 검토.

### 2. 농촌 지역 네트워크 인프라 불안정으로 인한 VR 스트리밍 품질 저하

* **설명:** VR 시뮬레이터(#100/#110)의 고해상도 렌더링 데이터와 VR 글러브(#10)의 실시간 제스처 데이터는 낮은 지연(Low Latency)을 필수로 요구한다. 스마트팜이 주로 위치하는 농촌 지역은 광대역 인터넷 인프라가 취약하여, 패킷 손실 또는 50ms 이상 지연 발생 시 VR 인터랙션이 끊기고 교육 세션이 강제 중단될 수 있다.
* **심각도:** 🔴 High
* **발생 가능성:** 🔴 High
* **대응 방안:** 엣지 컴퓨팅 아키텍처 도입으로 VR 렌더링 연산을 로컬 시뮬레이터에서 수행하고 메타데이터만 서버와 동기화. 5G MEC(Mobile Edge Computing) 또는 농촌 전용 공공 와이파이 인프라 활용 검토. 오프라인 모드 시나리오 패키지 사전 다운로드 지원.

### 3. VR 글러브 및 HMD 하드웨어 위생·내구성 위험

* **설명:** VR 글러브(#10)는 다수의 교육생이 교대로 착용하는 공용 장비다. 농업 교육 특성상 토양·습기 환경 노출 시뮬레이션 중 땀이나 오염물질이 글러브 내부 센서를 부식시키거나, 반복 사용으로 햅틱 액추에이터가 마모되어 교육 중 오작동이 발생할 수 있다. 감염병 상황에서는 위생 문제도 대두된다.
* **심각도:** 🟡 Medium
* **발생 가능성:** 🔴 High
* **대응 방안:** 교육생별 전용 위생 커버(disposable liner) 의무화 및 UV-C 살균 보관함 도입. 글러브 착용 횟수·압력 데이터를 펌웨어로 기록하여 예방적 유지보수(PM) 스케줄 자동화. 스페어 장비 상시 보유(N+1 재고 정책) 수립.

### 4. VR 교육 데이터 및 농장 운영 정보의 보안 취약성

* **설명:** 데이터 웹 서버(#300)는 VR 교육 이력(교육생 행동 데이터), 스마트팜 운영 정보(작물 종류, 수확 시기, 재배 기술 등 영업 기밀), 원격 관리자 접속 인증 정보를 모두 보유한다. API 엔드포인트가 적절히 보호되지 않으면 경쟁 농가 또는 외부 공격자에 의한 데이터 탈취, 원격 모니터링 세션 하이재킹이 발생할 수 있다.
* **심각도:** 🔴 High
* **발생 가능성:** 🟡 Medium
* **대응 방안:** 전 구간 TLS 1.3 암호화 적용 및 API 게이트웨이에 OAuth 2.0 + JWT 인증 도입. 원격 관리자 단말(#20) 접속에 MFA(다중 인증) 의무화. 농장 운영 데이터는 역할 기반 접근 제어(RBAC)로 교육 데이터와 논리적 분리 저장. 정기적 침투 테스트 및 OWASP Top 10 기준 보안 점검 수행.

### 5. 교육생 VR 사이버멀미(Cybersickness) 및 안전사고 위험

* **설명:** VR 시뮬레이터(#100/#110) 장시간 사용 시 프레임 드롭(목표치 90fps 미달)이나 모션-디스플레이 불일치(Motion-to-Photon Latency > 20ms)가 발생하면 교육생이 심각한 어지럼증, 구역질을 경험할 수 있다. 특히 VR 글러브(#10) 착용 중 균형 감각 교란으로 물리적 낙상 사고가 발생할 위험이 있으며, 기저 질환자(전정기관 장애, 간질 등)에게는 의료적 위험으로 이어질 수 있다.
* **심각도:** 🔴 High
* **발생 가능성:** 🟡 Medium
* **대응 방안:** 교육 시작 전 건강 상태 체크리스트 및 VR 금기 사항 안내 프로토콜 수립. 시뮬레이터 소프트웨어에 Motion-to-Photon Latency 실시간 모니터링 및 임계값 초과 시 자동 세션 중단 기능 구현. 교육 세션을 30분 단위로 제한하고 10분 휴식 의무화. VR 체험 공간 주변 안전 매트 및 보호 가드 레일 설치.

### 6. 스마트팜 VR 교육 콘텐츠의 현실 괴리 및 기술 진부화 위험

* **설명:** Smart Farm VR Simulator(#100) 내 재배 교육·시설 설치 콘텐츠가 실제 최신 스마트팜 기술(AI 기반 생육 분석, 차세대 환경 제어 시스템 등)을 반영하지 못할 경우, 교육생이 습득한 지식이 현장에서 무효화되는 교육 품질 문제가 발생한다. 농업기술 표준이 개정될 때마다 콘텐츠 전체를 재개발해야 하는 유지보수 부담도 크다.
* **심각도:** 🟡 Medium
* **발생 가능성:** 🔴 High
* **대응 방안:** 콘텐츠를 데이터 주도형(Data-Driven) 모듈 구조로 설계하여 농업기술 파라미터(온습도 기준값, 병해충 시나리오 등)를 콘텐츠 코드와 분리. 농촌진흥청·스마트팜혁신밸리 공식 기술 기준과 연동하는 콘텐츠 자동 업데이트 파이프라인 구축. 현장 농가 전문가 자문단을 구성하여 연 2회 콘텐츠 현실성 검증 실시.
