# 🏗️ 아키텍처 분석 보고서

## 📋 ADR (Architecture Decision Record)

### ADR-001: 중앙 집중형 데이터 웹 서버 기반의 실시간 통합 교육 및 모니터링 아키텍처 채택

| 항목 | 내용 |
|------|------|
| **상황(Context)** | 사용자가 VR 기기(110)와 VR 글로브(120)를 통해 스마트팜 가상 환경에서 시설 설치 및 재배 교육을 수행할 때, 학습 데이터의 실시간 동기화와 원격 관리자(20)의 실시간 모니터링 지원이 필수적임. |
| **결정(Decision)** | VR 시뮬레이터 단말(100)과 관리자 단말(300) 사이의 데이터 교환을 중계하는 **중앙 집중형 데이터 웹 서버(200)**를 아키텍처의 핵심 계층으로 배치함. |
| **근거(Rationale)** | 교육생의 행동 데이터와 시뮬레이션 상태를 서버에 집중시켜 데이터 일관성을 유지하고, 관리자가 물리적 장소에 구애받지 않고 모바일 기기(300)를 통해 실시간 피드백을 제공할 수 있도록 하기 위함. |
| **결과(Consequences)** | 교육 성취도(시세 확인, 재배 교육 등)에 대한 정교한 로그 수집이 가능해지며, 향후 다수의 교육생을 동시에 관리할 수 있는 확장성을 확보함. 단, 서버 의존도가 높아져 네트워크 가용성이 중요해짐. |
| **트레이드오프(Trade-offs)** | **장점:** 실시간 원격 제어 및 데이터 통합 관리 용이성. <br>**단점:** 서버 가동 중단 시 교육 시스템 전체 마비 및 네트워크 지연(Latency) 발생 시 VR 사용자 경험(멀미 등) 저하 가능성. |

---

## ⚠️ 잠재적 위험 분석

### 1. 실시간 데이터 전송 지연 (Latency Issue)
- **설명:** VR 글로브(120)의 모션 데이터나 서버에서 전달되는 시각적 상태 값이 네트워크 병목 현상으로 인해 지연될 경우, 사용자가 느끼는 시각과 신체 감각의 불일치(Motion-to-Photon Latency)로 인한 사이버 멀미 유발.
- **심각도:** 🔴 High
- **발생 가능성:** 🟡 Medium
- **대응 방안:** Edge Computing 기술을 도입하여 로컬 연산을 강화하고, 데이터 전송 시 경량 프로토콜(MQTT 또는 WebSocket) 및 패킷 최적화 적용.

### 2. 데이터 웹 서버 단일 장애점 (Single Point of Failure)
- **설명:** 중앙 데이터 웹 서버(200)에 장애가 발생할 경우, VR 시뮬레이터의 실시간 데이터 저장 및 관리자의 원격 모니터링 기능이 전면 중단됨.
- **심각도:** 🔴 High
- **발생 가능성:** 🟢 Low
- **대응 방안:** 서버 이중화(HA) 구성 및 로드 밸런싱 적용, 네트워크 단절 시를 대비한 단말 내 로컬 캐싱 시스템 구축.

### 3. 민감 교육 데이터 및 스마트팜 정보 유출
- **설명:** 데이터 웹 서버에 저장된 교육생의 정보나 스마트팜 시설 설계 데이터가 외부 해킹으로 인해 유출되거나 조작될 위험.
- **심각도:** 🔴 High
- **발생 가능성:** 🟡 Medium
- **대응 방안:** SSL/TLS를 통한 전송 구간 암호화, API 인증 체계(OAuth 2.0 등) 강화 및 데이터베이스 암호화 적용.

### 4. 하드웨어 호환성 및 인터페이스 오류
- **설명:** VR 글로브(120)와 시뮬레이터(100) 간의 펌웨어 버전 불일치 또는 다양한 관리자 단말(300)의 OS 버전 차이로 인한 시스템 오작동.
- **심각도:** 🟡 Medium
- **발생 가능성:** 🟡 Medium
- **대응 방안:** 표준 API 가이드를 수립하고, 하드웨어 추상화 계층(HAL)을 도입하여 기기 종속성을 최소화하며 정기적인 호환성 테스트 수행.

### 5. 사용자 환경 변화에 따른 VR 트래킹 정밀도 저하
- **설명:** 교육 현장의 물리적 환경(조명, 장애물 등) 변화로 인해 VR 기기(110)의 위치 추적 및 센서 데이터 수집의 정밀도가 떨어져 교육의 질이 하락함.
- **심각도:** 🟡 Medium
- **발생 가능성:** 🔴 High
- **대응 방안:** 환경 보정 알고리즘(Calibration) 자동화 및 비정상 데이터 유입 시 관리자에게 즉각 알림을 보내는 자가 진단 기능 구현.
