📋 ADR (Architecture Decision Record)
-------------------------------------

### ADR-001: 상태 기반 환경 제어(State Machine)와 다변수 센서 융합 제어 아키텍처 채택

| 항목                     | 내용                                                                                                                                                                                                                     |
| ---------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **상황(Context)**        | 시스템은 온도 기반 제어(High/Normal/Low 상태)와 습도 및 가스(CO₂, NH₃) 기반 제어를 결합한 구조를 가진다. 온도는 상태 전이(State Transition)를 통해 제어되며, 습도 및 가스 농도는 별도의 임계값 기반 제어 로직으로 작동한다. 핵심 과제는 “다양한 환경 변수(온도, 습도, 유해가스)를 통합적으로 고려하여 안정적인 축사 환경을 유지하는 것”이다. |
| **결정(Decision)**       | 온도 제어는 상태 머신(State Machine) 기반으로 High/Normal/Low 상태를 정의하고 히스테리시스(Dead zone)를 적용하여 안정성을 확보한다. 동시에 습도, CO₂, NH₃는 다변수 센서 융합 기반 임계값 제어 로직을 적용하여 병렬적으로 환경을 제어하는 하이브리드 제어 아키텍처를 채택한다.                                        |
| **근거(Rationale)**      | 상태 기반 제어는 급격한 환경 변화에 대한 안정적인 대응을 가능하게 하며, 히스테리시스는 잦은 상태 전환(채터링)을 방지한다. 또한 축사 환경에서는 온도뿐 아니라 습도 및 유해가스가 중요한 요소이므로 다변수 제어가 필수적이다.                                                                                         |
| **결과(Consequences)**   | **긍정적:** 안정적인 환경 유지, 다변수 기반 정밀 제어, 축산 질병 예방 효과**부정적:** 제어 로직 복잡성 증가, 센서 의존성 증가, 설정값 튜닝 필요                                                                                                                              |
| **트레이드오프(Trade-offs)** | 환경 제어의 정밀성과 안정성을 확보하는 대신, 시스템 설계 및 운영 복잡성이 증가한다.                                                                                                                                                                       |

* * *

⚠️ 잠재적 위험 분석
------------

### 1. 상태 전이 오류 (State Transition Error)

* **설명:** 온도 상태 전이 조건이 잘못 설정될 경우 High/Low 상태가 반복되거나 비정상 유지

* **심각도:** 🔴 High

* **발생 가능성:** 🟡 Medium

* **대응 방안:** 히스테리시스 범위 최적화, 시뮬레이션 검증, 실시간 튜닝 기능 제공

### 2. 센서 데이터 불일치

* **설명:** 온도, 습도, CO₂, NH₃ 센서 간 데이터 불일치로 잘못된 제어 발생

* **심각도:** 🔴 High

* **발생 가능성:** 🟡 Medium

* **대응 방안:** 센서 교정 및 이중화, 데이터 필터링 및 이상치 제거

### 3. 임계값 설정 부적절

* **설명:** 습도 및 가스 농도 임계값이 환경에 맞지 않을 경우 과도한 제어 또는 제어 부족 발생

* **심각도:** 🟡 Medium

* **발생 가능성:** 🔴 High

* **대응 방안:** 환경별 맞춤 설정, AI 기반 자동 튜닝, 사용자 설정 인터페이스 제공

### 4. 다중 변수 충돌 제어

* **설명:** 온도 제어와 가스 제어가 서로 상충하는 명령을 발생시킬 가능성

* **심각도:** 🟡 Medium

* **발생 가능성:** 🟡 Medium

* **대응 방안:** 제어 우선순위 정책 정의, 통합 제어 엔진 설계

### 5. 제어 시스템 응답 지연

* **설명:** 센서 데이터 처리 및 제어 명령 전달 지연으로 환경 변화 대응 실패

* **심각도:** 🟡 Medium

* **발생 가능성:** 🟡 Medium

* **대응 방안:** 실시간 처리 시스템 적용, 엣지 컴퓨팅 활용

### 6. 유해가스 센서 고장

* **설명:** CO₂ 또는 NH₃ 센서 고장 시 위험 상황 감지 실패

* **심각도:** 🔴 High

* **발생 가능성:** 🟡 Medium

* **대응 방안:** 센서 상태 모니터링, 이중화 구성, 정기 점검

### 7. 환경 변화 외부 요인 미반영

* **설명:** 외부 기상 조건(외기 온도, 환기 상태 등)이 충분히 반영되지 않을 경우 제어 정확도 저하

* **심각도:** 🟡 Medium

* **발생 가능성:** 🟡 Medium

* **대응 방안:** 외부 환경 데이터 연계, 예측 기반 제어 알고리즘 도입
