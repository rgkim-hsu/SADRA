📋 ADR (Architecture Decision Record)
-------------------------------------

### ADR-001: AI 기반 재배환경 데이터 통합 학습 및 실시간 판별 아키텍처 채택

| 항목                     | 내용                                                                                                                                                                                                                                |
| ---------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **상황(Context)**        | 동충하초 재배 환경은 온도·습도·조도·대기조성(CO₂) 등 다변수 환경 데이터와 곰팡이·생장장애 등 수확률 저하 요인이 복합적으로 작용한다. 기존 경험 기반 재배 방식으로는 오염 발생 시점을 사전에 예측하기 어려우며, 대량 재배 환경에서의 품질 균일성 확보가 구조적으로 불가능하다. 데이터 암호화 잠금 아이콘이 명시된 것으로 보아 외부 공개 없이 내부 폐쇄망 학습 환경이 전제되어 있다.          |
| **결정(Decision)**       | 재배환경 센서 데이터(온도·습도·조도·CO₂)와 수확률 저하 요인 데이터(곰팡이 발생, 생장장애)를 통합하여 AI 엔진에 학습시키고, 학습된 모델을 스마트팜 현장 플랫폼에 배포하여 실시간 오염 판별 및 생육 주기 예측을 수행하는 엣지-클라우드 하이브리드 AI 아키텍처를 채택한다. 최종 출력은 식용·의약용·기타 동충하초 품종별 분류 및 전주기 재배 자동화로 연결된다.                     |
| **근거(Rationale)**      | ① 다변수 환경 데이터의 시계열 패턴과 오염 발생 간 상관관계는 단순 임계값 기반 룰 엔진으로 처리 불가하며 머신러닝/딥러닝 모델이 필수적이다. ② 재배 현장의 네트워크 불안정성을 고려할 때 엣지 추론이 가용성을 보장한다. ③ 데이터 암호화 구간을 명시함으로써 농업 빅데이터의 지식재산 보호 및 보안 컴플라이언스를 충족한다. ④ 품종별 분류(식용·의약용·기타) 출력 구조는 시장 다변화 전략과 직결된다. |
| **결과(Consequences)**   | 긍정적: 수확률 향상, 오염 사전 차단, 고품질 동충하초 대량 재배의 표준화 실현. 부정적: AI 모델 학습을 위한 고품질 라벨링 데이터 확보 비용 증가, 엣지 디바이스의 추론 성능 및 전력 제약 관리 필요.                                                                                                              |
| **트레이드오프(Trade-offs)** | 얻는 장점: 실시간 오염 조기 감지로 폐기율 최소화, 재배 노하우의 데이터화·자산화. 감수해야 할 단점: 초기 데이터 수집 및 모델 학습 기간 동안 시스템 신뢰도가 낮을 수 있으며, AI 모델 블랙박스 특성으로 인한 현장 농가의 수용성 저하 가능성.                                                                                       |

### ADR-002: 데이터 암호화 기반 폐쇄형 빅데이터 파이프라인 아키텍처 채택

| 항목                     | 내용                                                                                                                                                                          |
| ---------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **상황(Context)**        | 동충하초 재배 노하우 및 환경 빅데이터는 핵심 지식재산으로, 외부 유출 시 경쟁사에 의한 기술 복제 위험이 크다. 개념도 중앙의 데이터 잠금(암호화) 아이콘은 AI 학습 데이터 전송 구간의 보안 처리가 아키텍처 설계 원칙으로 포함되어 있음을 나타낸다.                                |
| **결정(Decision)**       | 센서-엣지-클라우드 전 구간에 종단간 암호화(E2EE)를 적용하고, AI 학습용 데이터셋은 접근 권한 기반 내부 데이터 레이크에 격리 저장한다. 외부 스마트팜 보급 단계에서는 연합학습(Federated Learning) 방식을 검토하여 원본 데이터 외부 전송 없이 모델 파라미터만 집계하는 구조를 지향한다. |
| **근거(Rationale)**      | 농업 분야 빅데이터는 국가 R&D 과제 특성상 데이터 보안 및 관리 지침 준수가 의무적이며, 플랫폼 보급 확대 시 다수 농가 데이터의 중앙 집중화에 따른 개인정보 및 영업비밀 보호가 필요하다.                                                                 |
| **결과(Consequences)**   | 긍정적: 기술 유출 방지, 농가 신뢰 확보, 규제 컴플라이언스 충족. 부정적: 암호화로 인한 데이터 처리 레이턴시 증가, 연합학습 인프라 구축 복잡도 상승.                                                                                     |
| **트레이드오프(Trade-offs)** | 얻는 장점: 지식재산 보호 및 플랫폼 신뢰성. 감수해야 할 단점: 운영 복잡도 증가 및 키 관리 체계 유지 비용 발생.                                                                                                          |

⚠️ 잠재적 위험 분석
------------

### 1. AI 모델 학습용 고품질 라벨링 데이터 부족

* **설명:** 동충하초 오염(곰팡이, 생장장애) 판별 모델의 성능은 라벨링된 이미지 및 센서 데이터의 품질과 수량에 절대적으로 의존한다. 초기 재배 데이터가 충분히 축적되기 전 모델을 현장 배포할 경우, 오탐(False Positive) 및 미탐(False Negative)이 빈발하여 농가 신뢰를 조기에 상실할 위험이 있다.
* **심각도:** 🔴 High
* **발생 가능성:** 🔴 High
* **대응 방안:** 초기 6~12개월간 전문 재배사와 협력하여 정밀 라벨링 데이터를 집중 수집하고, 전이학습(Transfer Learning) 기반으로 소량 데이터에서도 유효한 모델을 구축한다. 모델 불확실성 구간에서는 AI 판단을 보조 참고로만 활용하고 전문가 검수를 의무화하는 Human-in-the-Loop 파이프라인을 병행한다.

* * *

### 2. 엣지 디바이스 장애로 인한 실시간 모니터링 중단

* **설명:** 재배 현장의 엣지 디바이스(센서 허브, 추론 단말)가 전력 불안정, 네트워크 단절, 하드웨어 고장으로 중단될 경우 온도·습도·CO₂ 등 환경 데이터 수집이 중단되고, AI 기반 이상 감지가 작동하지 않아 오염이 전파되어 대규모 수확 손실이 발생할 수 있다.
* **심각도:** 🔴 High
* **발생 가능성:** 🟡 Medium
* **대응 방안:** 센서 및 엣지 컴퓨팅 노드에 이중화(Redundancy) 구성을 적용하고, 오프라인 상태에서도 로컬 룰 기반 알림이 작동하는 폴백(Fallback) 메커니즘을 구현한다. 디바이스 상태를 중앙에서 원격 모니터링하는 디바이스 관리 플랫폼(MDM)을 도입하고 예방적 유지보수 주기를 수립한다.

* * *

### 3. 재배환경 데이터 및 AI 모델의 보안 침해

* **설명:** 개념도에 명시된 데이터 암호화 구간 외부에서 API 취약점, 내부자 위협, 또는 엣지 디바이스 물리적 탈취를 통해 재배 노하우 데이터와 학습된 AI 모델 파라미터가 외부로 유출될 경우, 경쟁사에 의한 기술 복제 및 플랫폼 무력화가 발생할 수 있다.
* **심각도:** 🔴 High
* **발생 가능성:** 🟡 Medium
* **대응 방안:** 전 구간 TLS 1.3 이상 암호화 적용, AI 모델 파일에 대한 모델 워터마킹(Model Watermarking) 적용, 엣지 디바이스에 TPM(Trusted Platform Module) 기반 보안 부팅 구현, 접근 권한 최소화 원칙(Least Privilege) 및 정기적 침투 테스트를 시행한다.

* * *

### 4. AI 모델 드리프트(Model Drift)로 인한 판별 정확도 저하

* **설명:** 계절 변화, 새로운 오염 균주 출현, 재배 품종 추가 등으로 인해 현장 데이터 분포가 학습 당시와 달라질 경우, 배포된 AI 모델의 판별 성능이 점진적으로 저하(Data/Concept Drift)된다. 이를 감지하지 못하면 오염 미탐이 누적되어 플랫폼 신뢰성이 무너진다.
* **심각도:** 🔴 High
* **발생 가능성:** 🔴 High
* **대응 방안:** 모델 성능 지표(정확도, F1-score, AUC)를 실시간 모니터링하는 MLOps 파이프라인을 구축하고, 드리프트 감지 임계값 초과 시 자동 재학습 트리거를 설정한다. 신규 오염 사례 데이터를 지속 수집하는 액티브 러닝(Active Learning) 체계를 도입한다.

* * *

### 5. 다품종(식용·의약용·기타) 분류 오류로 인한 제품 안전 사고

* **설명:** AI가 의약용 동충하초를 식용으로 잘못 분류하거나, 오염된 개체를 정상 판정하여 출하할 경우 소비자 건강 피해 및 법적 책임이 발생한다. 특히 의약용 품종은 유효 성분 규격이 엄격하므로 분류 오류의 파급 효과가 일반 농산물 대비 훨씬 크다.
* **심각도:** 🔴 High
* **발생 가능성:** 🟡 Medium
* **대응 방안:** 품종 분류 출력 단계에 신뢰도 임계값(Confidence Threshold)을 설정하여 임계값 미만 결과는 반드시 전문가 검수를 거치도록 강제화한다. 식용·의약용 분류에 대해서는 별도의 독립 검증 모델을 이중으로 적용하는 앙상블 검증 체계를 구성하고, 출하 전 최종 품질 검사 체크리스트를 시스템과 연동한다.

* * *

### 6. 스마트팜 보급 확대 시 이기종 환경 호환성 문제

* **설명:** 동충하초 스마트팜 플랫폼이 다수 농가에 보급될 경우, 농가별로 상이한 센서 제조사, 통신 프로토콜(Zigbee, LoRa, Wi-Fi), 재배 시설 규모에 따라 데이터 수집 품질과 형식이 불균일해진다. 이는 중앙 AI 모델의 입력 데이터 품질을 저하시켜 판별 정확도에 악영향을 준다.
* **심각도:** 🟡 Medium
* **발생 가능성:** 🔴 High
* **대응 방안:** 센서 데이터 수집 레이어에 표준 데이터 인터페이스(예: FIWARE NGSI-LD, IEC 61968 기반 농업 IoT 표준)를 정의하고, 이기종 프로토콜을 통합 변환하는 IoT 게이트웨이 어댑터 레이어를 아키텍처에 추가한다. 보급 전 센서 인증 기준을 명문화하여 플랫폼 호환성을 검증한다.
