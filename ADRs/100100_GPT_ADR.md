📋 ADR (Architecture Decision Record)
-------------------------------------

### ADR-001: 근적외선(NIR) 기반 스마트팜 정밀 분석 아키텍처 도입

| 항목                     | 내용                                                                                                                                                                                                                  |
| ---------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **상황(Context)**        | 시스템은 전자기파 스펙트럼 중 근적외선(0.8~2.5μm) 영역을 활용하여 작물 및 환경 데이터를 분석하는 구조를 고려한다. 해당 영역에서는 FT-NIR 기반 정량 분석이 가능하며, 오버톤(Overtone) 및 조합(Combination) 신호를 활용한 성분 분석이 이루어진다. 스마트팜에서는 작물의 수분, 영양 상태, 생육 상태를 비파괴 방식으로 측정하는 것이 핵심 과제이다. |
| **결정(Decision)**       | 근적외선 분광(NIR Spectroscopy) 기반 센서 분석 모듈을 스마트팜 데이터 수집 아키텍처에 통합한다. 기존 IoT 센서(온습도, CO2 등)와 함께 NIR 분석 데이터를 결합하여 다차원 데이터 분석 체계를 구축한다.                                                                                      |
| **근거(Rationale)**      | NIR 기술은 비파괴, 실시간 측정이 가능하며 작물 내부 성분 분석에 강점을 가진다. 기존 환경 센서만으로는 얻기 어려운 생화학적 정보를 제공하므로 스마트팜 정밀 농업에 적합하다.                                                                                                                |
| **결과(Consequences)**   | 작물 상태를 보다 정밀하게 파악할 수 있어 생산성 및 품질 향상이 기대된다. 그러나 장비 비용과 데이터 해석 복잡성이 증가한다.                                                                                                                                             |
| **트레이드오프(Trade-offs)** | 정밀 분석 가능(장점) vs 비용 증가(단점), 비파괴 측정(장점) vs 데이터 해석 난이도 증가(단점)                                                                                                                                                          |

* * *

⚠️ 잠재적 위험 분석
------------

### 1. 분석 데이터 해석 오류

* **설명:** NIR 스펙트럼 해석이 잘못되어 작물 상태를 오판하는 경우

* **심각도:** 🔴 High

* **발생 가능성:** 🟡 Medium

* **대응 방안:** 표준 스펙트럼 라이브러리 구축, ML 기반 해석 모델 적용

### 2. 센서 장비 비용 부담

* **설명:** FT-NIR 장비 도입 비용이 높아 시스템 구축 비용 증가

* **심각도:** 🟡 Medium

* **발생 가능성:** 🔴 High

* **대응 방안:** 단계적 도입, 공유 인프라 활용

### 3. 데이터 통합 문제

* **설명:** 기존 IoT 센서 데이터와 NIR 데이터 간 형식 및 해상도 차이

* **심각도:** 🟡 Medium

* **발생 가능성:** 🟡 Medium

* **대응 방안:** 데이터 표준화, 통합 데이터 모델 설계

### 4. 측정 환경 영향

* **설명:** 조명, 온도 등 외부 환경 변화가 NIR 측정 결과에 영향

* **심각도:** 🟡 Medium

* **발생 가능성:** 🔴 High

* **대응 방안:** 측정 환경 표준화, 보정 알고리즘 적용

### 5. 실시간 처리 부담

* **설명:** 스펙트럼 데이터 처리량 증가로 시스템 성능 저하

* **심각도:** 🟡 Medium

* **발생 가능성:** 🟡 Medium

* **대응 방안:** 엣지 컴퓨팅 기반 전처리, GPU 가속

### 6. 모델 일반화 한계

* **설명:** 특정 작물 또는 환경에서 학습된 모델이 다른 조건에서 성능 저하

* **심각도:** 🔴 High

* **발생 가능성:** 🟡 Medium

* **대응 방안:** 다양한 데이터셋 확보, 지속적 모델 재학습 및 검증
