# 🏗️ 아키텍처 분석 보고서

## 📋 ADR (Architecture Decision Record)

### ADR-001: 데이터 기반 지능형 컨설팅 및 통합 관리 아키텍처 채택

| 항목 | 내용 |
|------|------|
| **상황(Context)** | 스마트팜 운영 요청 시, 단순 운영을 넘어 전문적인 컨설팅과 실시간 데이터 수집을 통한 정밀 제어 및 스케줄링 관리가 요구됨. 사용자의 컨설팅 여부에 따라 프로세스가 분기되며, 계약 이후 생성되는 방대한 디지털 데이터의 체계적인 수집 및 피드백 루프 구축이 필요함. |
| **결정(Decision)** | 전문가 시스템(Expert System) 중심의 데이터 입력 인터페이스를 구축하고, 전자계약 모델과 연동된 '디지털 데이터 수집-분석-스케줄링' 파이프라인을 아키텍처의 핵심 엔진으로 결정함. 특히 관리 스케줄 전송을 RTS(Real-Time System)와 연동하여 동적 제어 성능을 확보함. |
| **근거(Rationale)** | (S6)단계에서 전문가 시스템을 통한 정밀 진단 데이터를 확보함으로써 개인화된 운영이 가능해지며, (S12, S14)의 연속된 데이터 흐름은 작물 생장 주기와 환경 변화에 즉각 대응하기 위한 기술적 필수 요건임. |
| **결과(Consequences)** | 운영 효율성 극대화 및 작물 품질의 상향 평준화가 가능함. 데이터 기반의 명확한 근거로 컨설팅 신뢰도가 향상되며, 전 과정을 디지털화(전자계약 포함)하여 운영의 투명성과 이력을 확보함. |
| **트레이드오프(Trade-offs)** | 고도화된 전문가 시스템 및 실시간 데이터 수집 서버 구축에 따른 초기 인프라 비용이 상승함. 또한, 현장 농민의 디지털 기기 활용 숙련도에 따라 초기 데이터 입력(S6) 단계에서 병목 현상이 발생할 수 있음. |

---

## ⚠️ 잠재적 위험 분석

### 1. 실시간 데이터 수집 및 전송 지연 (S12 ~ S14)
- **설명:** 스마트팜 현장의 네트워크 불안정으로 인해 수집된 디지털 데이터가 서버로 누락되거나, 관리 스케줄 전송이 RTS로 적시에 도달하지 못하는 시나리오.
- **심각도:** 🔴 High
- **발생 가능성:** 🟡 Medium
- **대응 방안:** 로컬 엣지 컴퓨팅 기기를 도입하여 일시적 네트워크 장애 시 데이터를 로컬에 캐싱하고, 재연결 시 동기화하는 메커니즘 구축.

### 2. 전문가 시스템 입력 데이터의 신뢰성 결여 (S6)
- **설명:** 사용자가 전문가 시스템에 부정확하거나 불충분한 자료를 입력하여, 이후 생성되는 컨설팅 결과 및 관리 스케줄의 품질이 저하되는 상황.
- **심각도:** 🟡 Medium
- **발생 가능성:** 🔴 High
- **대응 방안:** 데이터 입력 단계에 입력 가이드라인 및 유효성 검사(Validation) 로직을 강화하고, 사진 기반 AI 분석 기능을 도입하여 수동 입력의 오류를 최소화함.

### 3. 전자계약 및 민감 데이터 보안 위협 (S8)
- **설명:** 운영 전자계약 과정에서 개인정보, 계약 조건 및 농장 노하우가 담긴 디지털 데이터가 외부로 유출되거나 위변조되는 보안 사고.
- **심각도:** 🔴 High
- **발생 가능성:** 🟢 Low
- **대응 방안:** 종단간 암호화(E2EE) 적용, 블록체인 기반의 계약 위변조 방지 기술 도입 및 엄격한 IAM(Identity and Access Management) 정책 시행.

### 4. 확장성 부족으로 인한 시스템 부하 가중 (S10 ~ S12)
- **설명:** 스마트팜 도입 농가가 급증함에 따라 일/월/년 단위 점검표 생성 및 대규모 실시간 데이터 트래픽 처리가 서버 자원을 초과하여 시스템이 다운되는 시나리오.
- **심각도:** 🟡 Medium
- **발생 가능성:** 🟡 Medium
- **대응 방안:** 클라우드 네이티브 마이크로서비스 아키텍처(MSA)를 채택하여 트래픽 증가에 따른 유연한 오토스케일링(Auto-scaling) 환경 구축.

### 5. RTS(실시간 시스템) 피드백 루프의 정합성 오류
- **설명:** 전송된 관리 스케줄(S14)이 실제 현장 구동 장치(환경 제어기 등)의 물리적 상태와 충돌하여 비정상적인 작동을 유발하거나 작물에 피해를 주는 상황.
- **심각도:** 🔴 High
- **발생 가능성:** 🟢 Low
- **대응 방안:** 스케줄 적용 전 시뮬레이션 단계를 추가하고, 현장 장비의 상태를 역으로 모니터링하여 임계치 초과 시 즉시 수동 제어로 전환하는 Fail-safe 기능 구현.
