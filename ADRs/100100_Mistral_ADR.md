📋 ADR (Architecture Decision Record)
-------------------------------------

### ADR-001: **근적외선(NIR) 센싱 기술을 기반으로 한 스마트팜 모니터링 시스템 채택**

| 항목                     | 내용                                                                                                                                                                      |
| ---------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **상황(Context)**        | 스마트팜에서 작물의 성장 상태, 토양 영양, 수분 함량 등 실시간 모니터링이 필요하며, 비파괴적 방식으로 정밀한 데이터를 수집해야 함. 기존 가시광선 또는 단일 센서만으로는 충분한 정보를 얻기 어려움.                                                        |
| **결정(Decision)**       | **0.8μm~2.5μm 대역의 근적외선(NIR) 센싱 기술을 핵심으로 채택**하며, FT-NIR(FT-Near Infrared), 반사 분석, Overtone 조합 등 다중 분석 기법을 적용하여 작물 및 토양 데이터를 수집.                                          |
| **근거(Rationale)**      | 근적외선은 분자진동에 민감하여 유기물질(예: 수분, 탄소화합물)의 정량 분석이 가능. FT-NIR는 고해상도 스펙트럼 데이터를 제공하며, 반사 분석은 표면 상태를, Overtone 조합은 내부 구성 성분을 분석하는 데 효과적. 스마트팜에서 실시간으로 다중 파라미터를 모니터링할 수 있는 최적의 기술. |
| **결과(Consequences)**   | **정밀한 작물 상태 분석 가능**, 수확량 예측 정확도 향상, 비료/물 사용 최적화. 단, 고가의 장비와 복잡한 데이터 처리 필요.                                                                                              |
| **트레이드오프(Trade-offs)** | **장점**: 비파괴적 분석, 실시간 데이터 수집, 다중 파라미터 동시 모니터링. **단점**: 장비 비용 증가, 데이터 처리 복잡성, 전문가 의존도 높음.                                                                                 |

* * *

⚠️ 잠재적 위험 분석
------------

### 1. **센서 오작동으로 인한 데이터 오류**

* **설명:** 근적외선 센서의 오염 또는 노화로 인해 스펙트럼 데이터가 왜곡되어 잘못된 작물 상태 분석 결과 도출.
* **심각도:** 🔴 High
* **발생 가능성:** 🟡 Medium
* **대응 방안:** 정기적인 센서 교정 및 유지보수, 중복 센서 설치를 통한 교차 검증, AI 기반 이상 탐지 알고리즘 적용.

* * *

### 2. **데이터 과부하로 인한 시스템 지연**

* **설명:** 고해상도 스펙트럼 데이터가 대량으로 수집되어 실시간 처리 지연 발생, 스마트팜 제어 시스템의 반응 속도 저하.
* **심각도:** 🔴 High
* **발생 가능성:** 🟡 Medium
* **대응 방안:** 엣지 컴퓨팅 기반 사전 처리(예: 필터링, 압축) 적용, 클라우드-엣지 하이브리드 아키텍처 구축.

* * *

### 3. **보안 취약점으로 인한 데이터 유출**

* **설명:** 센서 네트워크 또는 클라우드 저장소에 대한 사이버 공격으로 인해 민감한 작물 데이터가 유출됨.
* **심각도:** 🔴 High
* **발생 가능성:** 🟡 Medium
* **대응 방안:** 데이터 암호화(예: TLS 1.3), 접근 제어 강화(예: Zero Trust 모델), 정기적인 보안 감사 수행.

* * *

### 4. **환경 요인에 의한 센서 성능 저하**

* **설명:** 높거나 낮은 온도, 습도, 먼지 등 스마트팜 환경이 센서의 성능을 저하시킴(예: NIR 센서의 신호 대 잡음비 감소).
* **심각도:** 🟡 Medium
* **발생 가능성:** 🔴 High
* **대응 방안:** 환경 내구성이 뛰어난 센서 선택(예: IP67 등급), 환경 제어 시스템(예: 온습도 조절) 통합.

* * *

### 5. **표준화 부족으로 인한 시스템 호환성 문제**

* **설명:** 근적외선 센서 및 분석 장비 간 표준화된 프로토콜 부족으로 인해 다른 스마트팜 시스템과 호환되지 않음.
* **심각도:** 🟡 Medium
* **발생 가능성:** 🟡 Medium
* **대응 방안:** 오픈 표준(예: OPC UA) 채택, API 기반 통합 인터페이스 개발, 산업 컨소시엄 참여를 통한 표준화 노력.
