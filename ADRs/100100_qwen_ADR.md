# 🏗️ 아키텍처 분석 보고서

## 📋 ADR (Architecture Decision Record)

### ADR-001: [근적외선 (NIR) 기반 빠른 스크리닝 아키텍처 채택]

| 항목 | 내용 |
|------|------|
| **상황(Context)** | 스마트팜 및 가축 모니터링 시스템(문서 기준) 에서 실시간으로 식물의 엽록소, 수분 함량, 또는 가축의 생체지표(질량, 수분 등) 를 빠르게 측정해야 하는 요구사항이 있음. 이미지 분석에 따르면, 근적외선(Near-IR, 0.8~2.5µm) 대역은 중첩(Overtone) 과 조합(Combination) 진동 모드를 분석할 수 있음. |
| **결정(Decision)** | 시스템의 핵심 센서 모듈로서 **근적외선 (FT-NIR)** 기술을 주요 분석 수단으로 선정하며, 이를 통해 정량 분석 및 중첩/조합 대역 분석을 수행하는 아키텍처를 채택함. |
| **근거(Rationale)** | 이미지 분석 결과, 근적외선 (NIR) 은 0.8µm~2.5µm 파장대를 커버하며, 중첩(Overtone) 과 조합(Combination) 진동 모드를 통해 물질의 성분 분석이 가능함. 이 대역은 물질의 투과도가 높아 비파괴 측정 및 실시간 고속 측정에 유리하며, FT-NIR 분석기법을 통한 정량 분석은 스마트팜의 자동화 제어 로직(정밀 농약/물 주기) 에 바로 연동 가능함. |
| **결과(Consequences)** | **긍정적:** 실시간 데이터 수집 비용 절감, 고체 내부를 관측하는 투과성 확보, 대량 샘플(작물/가축) 분석 속도 향상.<br>**부정적:** 근적외선 대역의 피크가 근본 모드보다 약해져 신호 대 잡음비 (SNR) 가 낮을 수 있으므로 정밀한 보정 알고리즘이 필요함. |
| **트레이드오프(Trade-offs)** | **장점:** 저렴하고 소형화된 센서 구현 가능 (IoT 게이트웨이에 탑재 용이).<br>**단점:** 원적외선/중적외선 (FT-IR) 보다 분해능이 낮고 화학 결합의 기본 진동 (Stretching, Bending) 직접 관측은 어려워, 간접 추정 모델 (Machine Learning) 이 필수적임. |

## ⚠️ 잠재적 위험 분석

### 1. [스펙트럼 간섭 및 데이터 노이즈 위험]
- **설명:** 이미지에서 정의된 파장 범위 (0.8µm ~ 2,500µm) 내외로 대기 중 수증기 (H2O) 및 이산화탄소 (CO2) 가 특정 파장을 흡수하여 스펙트럼 신호를 왜곡시킬 수 있음. 특히 근적외선 (NIR) 대역은 수증기 흡수와 공존할 위험이 큼.
- **심각도:** 🔴 High
- **발생 가능성:** 🔴 High
- **대응 방안:** 센서 모듈 주변에 건조제나 공기 정화 필터를 도입하여 대기 중 수분 농도를 제어하고, 실시간 보정 알고리즘 (Reference Scan) 을 주기적으로 실행하여 노이즈 필터링을 수행함.

### 2. [센서 드리프트 및 보정 주기 위험]
- **설명:** FT-NIR 및 FT-IR 센서는 열적 환경 변화에 민감하여, 이미지에서 언급된 0.8µm~2.5µm 등의 파장 기준이 변조될 수 있음. 특히 스마트팜의 온도/습도 변화 (문서 기준 스마트 축사 환경 데이터) 에 따라 센서 감도가 떨어질 수 있음.
- **심각도:** 🟡 Medium
- **발생 가능성:** 🔴 High
- **대응 방안:** 시스템 상단에 표준 참조 물질 (Reference Material) 을 내장하고, 주기적인 자동 보정 (Auto-Calibration) 사이클을 도입하여 센서 드리프트를 실시간으로 보상하는 아키텍처를 설계함.

### 3. [복잡한 화학 조합 (Combination) 데이터 해석 위험]
- **설명:** 이미지에서 근적외선 영역이 '조합 (Combination)'과 '중첩 (Overtone)' 분석을 위해 사용됨. 이들은 기본 진동 모드보다 파장 수차가 작고 신호가 약하여, 표준 화학 데이터베이스와 대조할 때 오인식 (False Positive) 이 발생할 위험이 있음.
- **심각도:** 🟡 Medium
- **발생 가능성:** 🟡 Medium
- **대응 방안:** 단순 신호 분석보다는 AI/ML 기반의 스펙트럼 분석 모델 (예: PCA, PLS Regression) 을 적용하여 복잡한 조합 대역 패턴을 학습하고, 데이터의 신뢰도 구간 (Confidence Interval) 을 명시하여 사용자에게 위험을 경고함.

### 4. [IoT 상호운용성 및 표준화 데이터 포맷 위험]
- **설명:** 문서의 '스마트팜 데이터 상호운용 프레임워크 (TTA 표준 등)'와 연동하기 위해 스펙트럼 데이터 (파장, 파수, 강도) 를 표준화된 형식 (예: JSON, MQTT) 으로 변환해야 함. 이미지와 문서가 다른 분야 (물리화학 vs IT 표준) 에 해당하므로, 데이터 메타데이터 표준 (ISO/IEC, TTA) 을 따르는 것이 어려울 수 있음.
- **심각도:** 🟡 Medium
- **발생 가능성:** 🟡 Medium
- **대응 방안:** 표준화 가이드 (ISO/IEC 30141 등) 에 따라 스펙트럼 데이터에 필요한 필수 메타데이터 (측정 시간, 센서 ID, 파장 범위 0.8-2.5um 등) 를 정의한 오픈 포맷 스키마를 적용하여 다른 IoT 기기 (가장, 게이트웨이) 와 원활하게 연동할 수 있도록 함.

### 5. [에너지 효율 및 전력 소비 위험]
- **설명:** 이미지에는 적외선 발생 및 분석 장비가 포함될 수 있으며, 특히 FT-IR 및 FT-NIR 분석기는 광원 및 인터페로미터 구동에 상당한 전력을 필요로 함. 스마트팜의 제한된 전원 환경 (태양광 등) 과 충돌할 수 있음.
- **심각도:** 🟡 Medium
- **발생 가능성:** 🟢 Low
- **대응 방안:** 근적외선 (FT-NIR) 은 광원 소모가 적고 소형화되어 IoT 디바이스에 적합함. 분석 주기를 최적화 (예: 온도 변화 시에만 측정) 하여 불필요한 전력 소비를 줄이고, 에너지 효율을 극대화하는 휴먼 (Sleep) 모드 알고리즘을 도입함.
