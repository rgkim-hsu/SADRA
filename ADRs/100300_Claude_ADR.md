📋 ADR (Architecture Decision Record)
-------------------------------------

### ADR-001: 스마트팜 식품 생산 공정의 순차적 단계별 파이프라인 아키텍처 채택

| 항목                     | 내용                                                                                                                                                                                                                                            |
| ---------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **상황(Context)**        | 스마트팜 환경에서 생산되는 농산물(예: 쌀, 곡물류)을 최종 출하 가능한 상품으로 가공하기 위해 알받기 → 젤리 투입 → 톱밥 공급 및 교체 → 절식 → 출하의 5단계 공정이 필요하다. 각 단계는 선행 단계의 완료를 전제로 하며, 단계 간 상태 전이 실패 시 품질 불량 및 생산 손실이 발생한다. 특히 생물학적 공정(알 부화, 젤리 영양 공급, 톱밥 환경 조성)이 포함되어 있어 실시간 모니터링과 정밀 제어가 핵심 과제이다. |
| **결정(Decision)**       | 각 공정 단계(S210~S250)를 독립적인 마이크로서비스 또는 독립 제어 모듈로 분리하되, 순차적 파이프라인(Sequential Pipeline) 패턴으로 연결한다. 각 단계는 완료 조건(Completion Criteria)을 충족해야만 다음 단계로 전이되는 상태 기계(State Machine) 방식을 채택한다.                                                              |
| **근거(Rationale)**      | 생물학적 공정 특성상 단계 간 순서를 건너뛰거나 병렬 처리할 수 없다. 알받기(S210) 없이 젤리 투입(S220)이 불가하고, 톱밥 환경(S230) 조성 전 절식(S240) 진행 시 폐사율이 급증한다. 단계별 독립 모듈화는 특정 공정의 장애가 전체 라인을 중단시키는 것을 방지하고, 단계별 SLA(Service Level Agreement) 측정 및 품질 추적성(Traceability)을 확보한다.              |
| **결과(Consequences)**   | (긍정) 각 공정의 KPI 개별 측정 가능, 불량 단계 신속 격리, 공정별 자동화 수준 독립적 고도화 가능. (부정) 단계 간 데이터 연계 인터페이스 복잡도 증가, 파이프라인 전체 처리 지연(Latency) 누적 가능성 존재.                                                                                                                |
| **트레이드오프(Trade-offs)** | 얻는 장점: 공정 가시성 향상, 단계별 롤백 및 재처리 용이, 품질 추적성 확보. 감수할 단점: 단계 간 핸드오프 오버헤드 발생, 상태 관리 로직 복잡도 증가, 전체 파이프라인 완료 시간이 각 단계 합산보다 길어질 수 있음.                                                                                                                 |

* * *

⚠️ 잠재적 위험 분석
------------

### 1. 단계 간 전이 조건 미충족으로 인한 공정 중단 위험

* **설명:** S210(알받기) 단계에서 수율이 기준치 미달인 상태로 S220(젤리 투입)이 자동 트리거될 경우, 이후 전 단계의 생산 품질이 연쇄적으로 저하된다. 수동 검수 없이 자동화 전이 조건만 신뢰할 경우 불량 배치(Batch) 전체가 출하(S250)까지 도달하는 시나리오가 발생한다.
* **심각도:** 🔴 High
* **발생 가능성:** 🟡 Medium
* **대응 방안:** 각 단계 완료 시 자동 품질 검증 게이트(Quality Gate) 삽입. IoT 센서 기반 실시간 수율 측정값이 임계치 초과 시에만 다음 단계 전이 허용. 이상 감지 시 담당자 알림 및 수동 승인 워크플로우 병행 운영.

### 2. 톱밥 공급·교체(S230) 환경 제어 실패로 인한 생물 폐사 위험

* **설명:** S230 단계에서 톱밥 습도, 온도, 교체 주기가 자동화 시스템 오류(센서 드리프트, 액추에이터 고장)로 인해 적정 범위를 이탈할 경우, 내부 생물(곤충류 등)의 대량 폐사가 발생한다. 이는 S240(절식) 및 S250(출하) 물량에 직접적 영향을 미쳐 매출 손실로 이어진다.
* **심각도:** 🔴 High
* **발생 가능성:** 🟡 Medium
* **대응 방안:** 온습도 센서 이중화(Redundancy) 및 크로스 검증 로직 적용. 환경 파라미터 이상 시 백업 액추에이터 자동 전환. 24시간 환경 데이터 로깅 및 이상 패턴 ML 기반 예측 경보 시스템 도입.

### 3. 젤리 투입(S220) 공급 중단으로 인한 영양 결핍 위험

* **설명:** 젤리(영양 배지) 공급 라인 장애, 재고 부족, 또는 투입 자동화 장비 오작동 발생 시 S220 단계가 지연되며, 알받기 이후 적기 영양 공급 골든타임을 초과하여 생존율이 급격히 저하된다. 공급망 단절(젤리 원자재 수급 이슈) 시 전체 생산 사이클이 중단될 수 있다.
* **심각도:** 🔴 High
* **발생 가능성:** 🟢 Low
* **대응 방안:** 젤리 재고 최소 버퍼(안전재고) 기준 설정 및 자동 발주 시스템 연동. 투입 장비 예방정비(PM) 주기 체계화. 수동 투입 비상 절차(SOP) 수립 및 정기 훈련 실시.

### 4. 출하(S250) 단계 데이터 위변조 및 이력 추적 불가 위험

* **설명:** 스마트팜 생산 이력(각 배치의 공정 단계별 데이터)이 출하 시점에 정확히 연계되지 않거나, 시스템 장애로 데이터가 소실될 경우 식품 안전 법규(HACCP, GAP 인증) 위반 및 리콜 발생 시 원인 추적이 불가능해진다. 악의적 데이터 조작 시 불량품이 출하되는 보안 위협도 존재한다.
* **심각도:** 🔴 High
* **발생 가능성:** 🟡 Medium
* **대응 방안:** 각 공정 단계(S210~S250) 데이터를 불변 로그(Immutable Log) 또는 블록체인 기반 이력 원장으로 기록. 출하 단계에서 전 공정 데이터 완결성 검증 후 출하 승인. 접근 권한 기반 데이터 수정 이력 감사(Audit Trail) 적용.

### 5. 단일 제어 시스템 장애로 인한 전체 파이프라인 단일 실패점(SPOF) 위험

* **설명:** 5개 공정 단계(S210~S250)를 통합 제어하는 중앙 관리 시스템(SCADA/PLC 또는 클라우드 플랫폼)이 단일 장애점으로 존재할 경우, 해당 시스템 다운 시 전체 공정이 즉시 중단된다. 특히 생물학적 공정 특성상 제어 중단은 시간이 지날수록 복구 불가능한 손실로 이어진다.
* **심각도:** 🔴 High
* **발생 가능성:** 🟡 Medium
* **대응 방안:** 제어 시스템 Active-Standby 이중화 구성 및 자동 Failover 적용. 각 공정 단계별 로컬 엣지 컨트롤러 배치로 중앙 시스템 장애 시에도 단계별 자율 운영 가능하도록 설계. RTO(복구 목표 시간) 및 RPO(복구 목표 시점) 기준 수립 및 정기 DR 훈련 실시.

### 6. 절식 공정(S240) 타이밍 오류로 인한 상품 품질 저하 위험

* **설명:** S240(절식) 단계는 출하 전 내용물 비움을 목적으로 하며, 절식 시간이 과도하게 길거나 짧을 경우 상품 품질(중량, 위생) 기준 미달로 출하 불가 판정이 발생한다. 자동화 타이머 오류 또는 배치 간 혼입 시 전량 폐기 손실이 발생한다.
* **심각도:** 🟡 Medium
* **발생 가능성:** 🟡 Medium
* **대응 방안:** 절식 시작·종료 시각을 배치(Batch) 단위로 자동 기록하고 허용 범위 이탈 시 알림 발송. 배치 간 물리적 격리 구조 설계 및 RFID/바코드 기반 배치 추적 시스템 적용. 절식 완료 기준을 중량 센서로 자동 검증 후 S250 전이 허용.

### 5. 단일 제어 시스템 장애로 인한 전체 파이프라인 단일 실패점(SPOF) 위험
