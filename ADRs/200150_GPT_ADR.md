📋 ADR (Architecture Decision Record)
-------------------------------------

### ADR-001: 센서 기반 실시간 배액 이온 모니터링 중심의 폐루프(Closed-loop) 양액 제어 구조 채택

| 항목                     | 내용                                                                                                                                                                                                                                                                           |
| ---------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **상황(Context)**        | 본 시스템은 스마트팜 수경재배 환경에서 원수탱크(110), 액비탱크(120), 양액탱크(130), 다수의 배액탱크(140, 141), 그리고 센서 기반 양액제어장치(150)로 구성됨. 기존 스마트팜에서는 공급 양액의 EC/pH 중심 제어만 수행되어 실제 작물 근권(Root Zone)의 이온 균형 상태를 정밀하게 반영하지 못하는 문제가 존재함. 특히 작물별·생육단계별 양분 흡수 편차와 배액 내 이온 농도 불균형으로 인해 과시비, 염류집적, 수질오염 및 생산성 저하 문제가 발생함 |
| **결정(Decision)**       | 각 배액탱크(140)에 개별 이온 모니터링 센서(141)를 설치하고, 센서 데이터 기반으로 중앙 양액제어장치(150)가 실시간 폐루프 제어를 수행하는 아키텍처를 채택함. 제어장치는 배액 상태를 분석하여 액비탱크(120) 및 양액탱크(130)의 혼합비율과 공급량을 자동 조정함                                                                                                                    |
| **근거(Rationale)**      | 스마트팜 고도화 추세에서는 단순 EC 기반 제어보다 질산(NO3-), 칼륨(K+), 칼슘(Ca2+) 등 개별 이온 농도 기반 정밀 제어가 중요함. 폐루프 구조는 작물 실제 흡수 상태를 반영할 수 있으며, 양액 손실 최소화와 수확량 최적화에 유리함. 또한 배액 데이터를 활용한 피드백 제어는 디지털트윈 및 AI 기반 생육예측 모델과의 연계 가능성이 높음                                                                         |
| **결과(Consequences)**   | 양액 공급 정밀도가 향상되고, 비료 사용량 및 용수 소비량 절감 효과가 기대됨. 작물 품질 균일성 향상과 자동화 수준 고도화가 가능함. 반면 센서 수 증가로 인한 유지관리 복잡도 및 초기 구축 비용이 증가함                                                                                                                                                          |
| **트레이드오프(Trade-offs)** | 정밀 제어 및 데이터 기반 운영이라는 장점을 확보하는 대신, 센서 교정 비용, 데이터 품질관리, 실시간 처리 인프라 요구사항 증가를 감수해야 함                                                                                                                                                                                             |

### ADR-002: 다중 배액탱크 분산 수집 구조 적용

| 항목                     | 내용                                                                                                  |
| ---------------------- | --------------------------------------------------------------------------------------------------- |
| **상황(Context)**        | 시스템은 여러 재배 구역 또는 베드(Bed) 단위의 배액탱크(140)를 개별적으로 운영하는 구조로 보임. 단일 배액 수집 방식은 구역별 생육 차이와 양분 불균형을 식별하기 어려움 |
| **결정(Decision)**       | 각 재배라인별 독립 배액탱크와 개별 센서를 구성하는 분산형 수집 구조를 적용함                                                         |
| **근거(Rationale)**      | 스마트팜은 환경 편차가 크므로 구역별 데이터 수집이 필수적임. 분산 구조는 생육 이상 탐지와 국소적 장애 분석에 효과적이며, 향후 AI 기반 이상탐지 모델 구축에 유리함      |
| **결과(Consequences)**   | 구역별 맞춤 양액 제어가 가능해짐. 반면 장치 수 증가로 네트워크 구성과 유지보수 포인트가 증가함                                              |
| **트레이드오프(Trade-offs)** | 정밀성 향상과 확장성을 확보하지만, 배선·통신·센서 캘리브레이션 부담이 증가함                                                         |

### ADR-003: 중앙 집중형 양액 제어 오케스트레이션 구조 채택

| 항목                     | 내용                                                                                         |
| ---------------------- | ------------------------------------------------------------------------------------------ |
| **상황(Context)**        | 다수의 센서 및 탱크 데이터를 통합적으로 제어하지 않으면 양액 공급의 일관성 확보가 어려움                                         |
| **결정(Decision)**       | 센서 데이터 분석, 제어 로직, 액비 혼합 제어를 중앙 양액제어장치(150)에서 수행하는 중앙 집중형 오케스트레이션 구조를 채택함                   |
| **근거(Rationale)**      | 중앙 제어 구조는 정책 변경, 알고리즘 업데이트, 데이터 통합 분석을 단일 지점에서 수행 가능함. 또한 클라우드 기반 스마트팜 플랫폼과 연동이 용이함        |
| **결과(Consequences)**   | 운영 효율성과 관리 일관성이 향상됨. 그러나 중앙 제어기의 장애가 전체 시스템에 영향을 미치는 SPOF(Single Point of Failure) 위험이 발생함 |
| **트레이드오프(Trade-offs)** | 통합 관리 편의성을 확보하는 대신 중앙 제어기 장애에 대한 이중화 설계 필요성이 증가함                                           |

### ADR-004: 센서 데이터 기반 자동 양액 보정 알고리즘 적용

| 항목                     | 내용                                                                            |
| ---------------------- | ----------------------------------------------------------------------------- |
| **상황(Context)**        | 작물의 생육 단계 및 환경 조건 변화에 따라 양액 요구량이 지속적으로 변동됨                                    |
| **결정(Decision)**       | 실시간 센서 데이터를 활용하여 양액 농도 및 공급량을 자동 조정하는 적응형 제어 알고리즘을 적용함                        |
| **근거(Rationale)**      | AI/ML 기반 스마트팜 트렌드는 데이터 기반 자율제어를 핵심으로 함. 적응형 알고리즘은 수동 운영보다 빠른 반응성과 높은 생산성을 제공함 |
| **결과(Consequences)**   | 운영자 개입 감소와 생산성 향상이 가능함. 반면 알고리즘 오류 시 과시비 또는 양분 결핍 위험이 존재함                     |
| **트레이드오프(Trade-offs)** | 자동화 수준 향상이라는 장점을 얻지만, 모델 검증과 운영 안정성 확보 비용이 증가함                                |

⚠️ 잠재적 위험 분석
------------

### 1. 센서 오염 및 측정값 드리프트

* **설명:** 배액 내 침전물, 염류, 미생물 등에 의해 이온 센서(141)의 정확도가 저하될 수 있으며, 잘못된 데이터가 제어기에 전달되어 과도한 양액 공급이 발생할 수 있음

* **심각도:** 🔴 High

* **발생 가능성:** 🔴 High

* **대응 방안:** 자동 세정(CIP) 기능 적용, 정기 캘리브레이션 정책 수립, 센서 이중화 및 이상치 탐지 알고리즘 적용

### 2. 중앙 제어장치 장애(SPOF)

* **설명:** 중앙 양액제어장치(150) 장애 발생 시 전체 양액 공급 체계가 중단될 가능성이 있음

* **심각도:** 🔴 High

* **발생 가능성:** 🟡 Medium

* **대응 방안:** 이중화 서버 구성(Active-Standby), Edge Controller 분산 제어 구조 도입, 장애 자동 복구(Failover) 체계 구축

### 3. 네트워크 통신 장애

* **설명:** 센서와 제어기 간 통신 장애 발생 시 실시간 제어 데이터 누락으로 인해 오동작 가능성이 존재함

* **심각도:** 🟡 Medium

* **발생 가능성:** 🟡 Medium

* **대응 방안:** MQTT QoS 적용, 로컬 캐싱 및 Store-and-Forward 구조 적용, 유선/무선 이중 통신망 구성

### 4. 양액 혼합 오류 및 과시비

* **설명:** 제어 알고리즘 오류 또는 액비탱크 밸브 오작동으로 특정 이온 농도가 급격히 증가할 수 있음

* **심각도:** 🔴 High

* **발생 가능성:** 🟡 Medium

* **대응 방안:** 안전 임계치 기반 Hard Limit 적용, 디지털 트윈 시뮬레이션 검증, 이상 농도 발생 시 긴급 차단 로직 구현

### 5. 배액 재사용에 따른 병원균 확산

* **설명:** 배액을 순환 재사용할 경우 곰팡이, 세균, 바이러스 등이 전체 재배라인으로 확산될 수 있음

* **심각도:** 🔴 High

* **발생 가능성:** 🟡 Medium

* **대응 방안:** UV 살균, 오존 처리, RO 정수 시스템 적용 및 병원균 모니터링 체계 구축

### 6. 데이터 품질 불일치 및 AI 모델 오류

* **설명:** 센서 간 데이터 형식 차이 또는 노이즈로 인해 AI 기반 제어 모델이 잘못된 판단을 수행할 가능성이 있음

* **심각도:** 🟡 Medium

* **발생 가능성:** 🟡 Medium

* **대응 방안:** 데이터 정규화 파이프라인 구축, MLOps 기반 모델 검증 체계 적용, 학습 데이터 품질관리 정책 수립

### 7. 스마트팜 OT 보안 취약점

* **설명:** 제어장치가 외부 네트워크와 연결될 경우 원격 침입 및 제어권 탈취 위험이 존재함

* **심각도:** 🔴 High

* **발생 가능성:** 🟡 Medium

* **대응 방안:** IEC 62443 기반 OT 보안 정책 적용, 제어망 분리, TLS 암호화, Zero Trust 접근제어 및 로그 모니터링 체계 구축

### 8. 확장성 부족에 따른 운영 한계

* **설명:** 재배라인 증가 시 중앙 제어기의 처리 성능 한계로 인해 실시간성이 저하될 수 있음

* **심각도:** 🟡 Medium

* **발생 가능성:** 🟢 Low

* **대응 방안:** 마이크로서비스 기반 제어 구조 전환, Edge Computing 도입, 메시지 브로커 기반 이벤트 아키텍처 적용
