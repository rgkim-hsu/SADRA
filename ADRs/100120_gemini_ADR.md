# 🏗️ 아키텍처 분석 보고서

## 📋 ADR (Architecture Decision Record)

### ADR-001: 가상화 계층을 통한 통합 환경 시뮬레이션 및 스마트팜 제어 로직 분리

| 항목 | 내용 |
|------|------|
| **상황(Context)** | 실제 농장의 환경 변화를 실시간으로 반영하면서도, 물리적인 설비 없이 제어 알고리즘의 유효성을 검증해야 함. 또한, 실제 스마트팜 통합제어시스템과 시뮬레이션 환경 간의 데이터 정합성을 유지하며 3D 시각화 피드백을 실시간으로 제공해야 하는 과제에 직면함. |
| **결정(Decision)** | **'환경 제너레이터'**, **'가상 센서/로드'**, **'가상 제어기/로드'**를 포함하는 **통합 환경 시뮬레이션 시스템**을 중앙 아키텍처로 구축. 실제 제어 시스템과 동일한 인터페이스를 갖는 가상화 계층(Virtualization Layer)을 도입하여 양방향 데이터 동기화 구조를 채택함. |
| **근거(Rationale)** | 가상 센서와 가상 제어기 계층을 통해 실제 하드웨어의 의존성을 제거함으로써 개발 및 테스트 비용을 절감할 수 있음. 환경 제너레이터를 독립시켜 기후 변화 시나리오를 자유롭게 생성하고, 3D 뷰어와 별도 연동하여 물리적 현상과 데이터의 흐름을 직관적으로 검증하기 위함임. |
| **결과(Consequences)** | 실제 농지 없이도 고도화된 제어 시나리오 테스트가 가능해지며, 3D 뷰어를 통한 몰입형 모니터링 환경이 구축됨. 다만, 가상 모델의 정밀도에 따라 실제 환경과의 오차가 발생할 수 있는 리스크가 존재함. |
| **트레이드오프(Trade-offs)** | 초기 시뮬레이션 모델링 및 엔진 구축에 높은 비용과 시간이 소요되나, 장기적으로 운영 안정성 확보 및 실제 하드웨어 장애 발생 시의 리스크를 사전 차단할 수 있는 이점을 얻음. |

---

## ⚠️ 잠재적 위험 분석

### 1. 가상-물리 모델 간의 동역학적 오차 (Model Fidelity Gap)
- **설명:** 환경 제너레이터가 생성하는 가상 데이터와 실제 농장의 물리적 기후/생장 지표 간의 괴리로 인해, 시뮬레이션에서 검증된 알고리즘이 실제 환경에서 오작동할 위험.
- **심각도:** 🔴 High
- **발생 가능성:** 🟡 Medium
- **대응 방안:** 실제 농장에서 수집된 빅데이터를 기반으로 가상 센서 모델을 지속적으로 튜닝(Digital Twin Calibration)하고, 머신러닝 기반의 환경 모델링 고도화.

### 2. 양방향 통신 지연으로 인한 실시간성 저하
- **설명:** 통합제어시스템, 시뮬레이션 시스템, 3D 환경 뷰어 간의 복잡한 데이터 교환 과정에서 네트워크 지연이 발생하여 제어 루틴의 실시간 동기화가 깨질 위험.
- **심각도:** 🟡 Medium
- **발생 가능성:** 🔴 High
- **대응 방안:** 고성능 메시지 브로커(MQTT/Kafka) 도입 및 데이터 패킷 최적화, 3D 뷰어의 경우 렌더링 부하 분산을 위한 엣지 컴퓨팅 활용.

### 3. 가상 제어 로드와 실제 제어기 간의 로직 불일치
- **설명:** 가상 제어로드를 통해 테스트된 펌웨어나 로직이 실제 스마트팜 통합제어 하드웨어의 물리적 특성(전압, 응답 속도 등)을 완벽히 반영하지 못할 위험.
- **심각도:** 🔴 High
- **발생 가능성:** 🟡 Medium
- **대응 방안:** HIL(Hardware-in-the-Loop) 테스트 단계를 추가하여 가상 시뮬레이션과 실제 제어 보드를 직접 연결하는 하이브리드 검증 절차 도입.

### 4. 3D 환경 뷰어의 자원 점유로 인한 시스템 성능 저하
- **설명:** 고해상도 3D 시각화 처리가 시스템 자원을 과도하게 점유하여 핵심 제어 시뮬레이션 연산 속도에 영향을 줄 위험.
- **심각도:** 🟢 Low
- **발생 가능성:** 🟡 Medium
- **대응 방안:** 시뮬레이션 엔진과 시각화 엔진의 프로세스 분리(Decoupling) 및 멀티코어 최적화, 저사양 기기를 위한 LoD(Level of Detail) 관리 전략 적용.

### 5. 데이터 무결성 및 외부 침입 보안 위험
- **설명:** 시뮬레이션 시스템과 통합제어시스템 간의 연결 접점이 외부 공격에 노출될 경우, 가상 센서 값을 조작하여 실제 농장 제어에 치명적인 오류를 유도할 위험.
- **심각도:** 🔴 High
- **발생 가능성:** 🟢 Low
- **대응 방안:** 시스템 간 통신 구간 암호화(TLS), API 인증 및 인가 체계 강화, 시뮬레이션 환경과 실제 제어 망 간의 논리적 격리(Sandbox) 구축.
