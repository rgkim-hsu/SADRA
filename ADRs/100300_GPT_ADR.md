📋 ADR (Architecture Decision Record)

### ADR-001: 공정 단계 기반 배치(Batch) 생산 아키텍처 채택

| 항목                     | 내용                                                                                                                                                                                                      |
| ---------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **상황(Context)**        | 이미지의 공정 흐름은 알받기 공정(S210) → 젤리 투입 공정(S220) → 톱밥 공급 및 교체 공급(S230) → 절식 공정(S240) → 출하(S250)로 구성되어 있다. 이는 곤충 사육 또는 스마트 축산/스마트팜 기반 생물 생산 공정으로 해석되며, 각 단계의 환경 조건과 운영 시점이 다르다. 공정별 품질 편차 최소화와 생산성 확보가 핵심 과제이다. |
| **결정(Decision)**       | 단계별 생산 흐름을 관리하는 Batch 기반 공정 아키텍처를 채택한다. 각 공정 단계는 독립적인 작업 단위로 관리되며, 중앙 제어 시스템이 공정 상태, 작업 이력, 환경 데이터를 통합 관리한다.                                                                                            |
| **근거(Rationale)**      | 생물 기반 생산 공정은 개체 성장 단계에 따라 환경 조건과 작업 절차가 달라진다. Batch 단위 관리는 추적성(Traceability) 확보와 품질 관리에 유리하며, 공정 간 오염 및 품질 편차를 줄일 수 있다.                                                                                 |
| **결과(Consequences)**   | 공정별 품질 관리 및 생산 이력 추적이 가능해진다. 불량 원인 분석과 운영 최적화가 용이해진다. 반면 공정 관리 시스템 복잡도와 데이터 저장 요구사항이 증가한다.                                                                                                              |
| **트레이드오프(Trade-offs)** | 품질 안정성과 운영 가시성을 얻는 대신, 생산 데이터 관리 비용과 운영 절차 복잡성이 증가한다.                                                                                                                                                   |

### ADR-002: 환경 제어 기반 자동화 사육 시스템 적용

| 항목                     | 내용                                                                                            |
| ---------------------- | --------------------------------------------------------------------------------------------- |
| **상황(Context)**        | 젤리 공급, 톱밥 공급 및 교체, 절식 과정은 생물의 성장 상태와 위생 조건에 직접적인 영향을 미친다. 수작업 중심 운영은 품질 편차와 감염 위험을 증가시킬 수 있다. |
| **결정(Decision)**       | 센서 기반 자동 환경 제어 및 공급 시스템을 적용한다. 습도, 온도, 급이 상태, 사육 밀도 등을 실시간 모니터링하며, 자동 급이 및 환경 유지 기능을 수행한다.    |
| **근거(Rationale)**      | 자동화된 환경 제어는 생육 품질의 균일성을 확보하고 운영 인력 부담을 줄일 수 있다. 또한 스마트팜 기술과 연계하여 데이터 기반 생산 최적화가 가능하다.         |
| **결과(Consequences)**   | 생산 효율과 품질 균일성이 향상된다. 작업자 의존도가 감소하며 대량 생산 체계 구축이 가능해진다. 그러나 초기 자동화 설비 비용이 증가한다.                |
| **트레이드오프(Trade-offs)** | 생산 자동화와 품질 향상을 얻는 대신, 설비 구축 비용과 유지보수 복잡성이 증가한다.                                               |

### ADR-003: 출하 전 절식(Fasting) 품질 안정화 공정 채택

| 항목                     | 내용                                                                                |
| ---------------------- | --------------------------------------------------------------------------------- |
| **상황(Context)**        | 절식 공정(S240)은 출하 전 생물 내부 잔여물을 제거하고 위생 상태를 개선하기 위한 단계로 해석된다. 출하 품질과 위생 기준 충족이 중요하다. |
| **결정(Decision)**       | 출하 전 일정 시간 절식 공정을 필수 단계로 포함한다. 제어 시스템은 절식 시간 및 환경 조건을 자동 관리한다.                    |
| **근거(Rationale)**      | 절식은 위생성 향상과 저장 안정성 확보에 효과적이며, 유통 과정 중 품질 저하를 감소시킬 수 있다.                           |
| **결과(Consequences)**   | 출하 품질과 상품 안정성이 향상된다. 식품·사료 안전 기준 대응력이 증가한다. 반면 절식 시간 증가로 출하 리드타임이 길어질 수 있다.       |
| **트레이드오프(Trade-offs)** | 위생성과 품질 향상을 얻는 대신, 공정 시간이 증가하고 생산 스케줄 유연성이 감소한다.                                  |

### ADR-004: 공정 데이터 추적 및 이력 관리 구조 적용

| 항목                     | 내용                                                                                      |
| ---------------------- | --------------------------------------------------------------------------------------- |
| **상황(Context)**        | 생물 생산 공정은 질병, 환경 변화, 공급 재료 상태 등에 따라 품질 편차가 발생할 수 있으며, 원인 분석을 위한 데이터 추적이 중요하다.           |
| **결정(Decision)**       | 공정 단계별 데이터를 수집·저장하는 Traceability 시스템을 구축한다. 각 Batch는 입식, 급이, 환경 상태, 출하 이력을 고유 ID로 관리한다. |
| **근거(Rationale)**      | 스마트팜 및 식품 생산 분야에서는 생산 이력 관리가 품질 인증 및 규제 대응에 필수적이다.                                      |
| **결과(Consequences)**   | 품질 문제 발생 시 원인 추적이 가능하며, 운영 최적화 데이터 확보가 가능하다. 그러나 저장 데이터 증가와 관리 시스템 비용이 상승한다.            |
| **트레이드오프(Trade-offs)** | 품질 신뢰성과 규제 대응력을 확보하는 대신, 데이터 인프라 운영 비용이 증가한다.                                           |

⚠️ 잠재적 위험 분석
------------

### 1. 공정 간 교차 오염 위험

* **설명:** 톱밥 교체 및 급이 과정에서 미생물 또는 병원균 오염이 발생할 수 있음

* **심각도:** 🔴 High

* **발생 가능성:** 🟡 Medium

* **대응 방안:** 공정 구역 분리, UV 살균 및 정기 소독 수행, 작업자 위생 관리 강화

### 2. 자동 급이 시스템 오작동 위험

* **설명:** 젤리 공급 장치 이상으로 과다 공급 또는 공급 중단이 발생할 수 있음

* **심각도:** 🔴 High

* **발생 가능성:** 🟡 Medium

* **대응 방안:** 센서 기반 공급량 검증, Fail-safe 로직 적용, 수동 Override 기능 제공

### 3. 환경 제어 실패 위험

* **설명:** 온습도 제어 실패 시 생육 환경 악화로 대량 폐사가 발생할 수 있음

* **심각도:** 🔴 High

* **발생 가능성:** 🟡 Medium

* **대응 방안:** 이중 센서 적용, 알람 시스템 구축, 비상 냉난방 장치 운영

### 4. 절식 시간 관리 오류 위험

* **설명:** 절식 시간이 과도하거나 부족할 경우 출하 품질 저하가 발생할 수 있음

* **심각도:** 🟡 Medium

* **발생 가능성:** 🟡 Medium

* **대응 방안:** 자동 타이머 기반 공정 관리, 품질 기준 기반 출하 검증 절차 적용

### 5. 생산 이력 데이터 손실 위험

* **설명:** Batch 데이터 손실 시 품질 추적 및 문제 원인 분석이 어려워질 수 있음

* **심각도:** 🟡 Medium

* **발생 가능성:** 🟡 Medium

* **대응 방안:** 클라우드 백업, 이중 저장소 구성, 정기 데이터 무결성 점검 수행

### 6. 출하 단계 품질 검수 누락 위험

* **설명:** 최종 검수 누락 시 불량 개체 또는 품질 미달 제품이 유통될 수 있음

* **심각도:** 🔴 High

* **발생 가능성:** 🟡 Medium

* **대응 방안:** AI 비전 검사 시스템 적용, 출하 전 자동 품질 체크리스트 운영

### 7. 스마트팜 설비 유지보수 지연 위험

* **설명:** 자동화 설비 고장 방치 시 전체 생산 라인 중단이 발생할 수 있음

* **심각도:** 🔴 High

* **발생 가능성:** 🟡 Medium

* **대응 방안:** Predictive Maintenance 적용, 정기 예방 점검 및 원격 상태 모니터링 수행
