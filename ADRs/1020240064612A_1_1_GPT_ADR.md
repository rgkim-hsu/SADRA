📋 ADR (Architecture Decision Record)
-------------------------------------

### ADR-001: 로봇팔 기반 스마트팜 환경 제어를 위한 센서-액추에이터 통합 제어 아키텍처

| 항목                     | 내용                                                                                                                                                                                     |
| ---------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **상황(Context)**        | 시스템은 제어부에서 생성된 확장/축소/회전 제어 신호를 로봇팔에 전달하고, 로봇팔은 다양한 센서(가상센서, 공간센서, 지온센서, CO2센서)와 연동하여 스마트팜 환경을 제어한다. 핵심 과제는 물리적 액추에이터(로봇팔)와 다종 센서 간의 실시간 피드백 루프를 안정적으로 구성하고, 환경 변화에 따라 정밀 제어를 수행하는 것이다. |
| **결정(Decision)**       | 폐루프(Closed-loop) 제어 구조를 기반으로 센서 피드백 중심 아키텍처를 채택한다. 로봇팔을 단순 실행 장치가 아닌 ‘지능형 엣지 제어 노드’로 정의하고, 각 센서 데이터를 실시간으로 수집하여 제어부와 로컬에서 동시에 의사결정을 수행하는 하이브리드 제어 방식을 적용한다.                            |
| **근거(Rationale)**      | 스마트팜 환경은 온도, CO2, 공간 상태 등이 빠르게 변하기 때문에 단방향 제어(Open-loop)로는 정밀한 제어가 어렵다. 폐루프 제어는 센서 데이터를 기반으로 지속적인 보정이 가능하며, 로봇팔을 엣지 노드로 활용하면 지연을 최소화할 수 있다.                                            |
| **결과(Consequences)**   | 환경 변화에 대한 빠른 대응과 정밀 제어가 가능해진다. 그러나 시스템 복잡도가 증가하고, 센서 데이터 품질에 대한 의존도가 높아진다.                                                                                                             |
| **트레이드오프(Trade-offs)** | 제어 정확도 향상(장점) vs 시스템 설계 복잡성 증가(단점), 실시간 대응성 확보(장점) vs 센서 오류에 대한 민감도 증가(단점)                                                                                                             |

* * *

⚠️ 잠재적 위험 분석
------------

### 1. 센서 데이터 오류로 인한 오제어

* **설명:** 지온센서 또는 CO2센서의 오작동으로 잘못된 환경 데이터가 입력되어 로봇팔이 부적절한 동작 수행

* **심각도:** 🔴 High

* **발생 가능성:** 🟡 Medium

* **대응 방안:** 센서 이중화, 데이터 필터링, 이상치 탐지 알고리즘 적용

### 2. 로봇팔 제어 실패 또는 기계적 오류

* **설명:** 확장/회전 명령 수행 중 로봇팔의 기계적 고장 또는 제어 오류 발생

* **심각도:** 🔴 High

* **발생 가능성:** 🟡 Medium

* **대응 방안:** 정기적 유지보수, 상태 모니터링, 안전 정지(fail-safe) 메커니즘 적용

### 3. 실시간 제어 지연

* **설명:** 제어부와 로봇팔 간 통신 지연으로 인해 환경 변화 대응이 늦어지는 경우

* **심각도:** 🔴 High

* **발생 가능성:** 🟡 Medium

* **대응 방안:** 엣지 컴퓨팅 기반 로컬 제어 강화, 경량 프로토콜(MQTT 등) 사용

### 4. 가상센서 신뢰성 문제

* **설명:** 가상센서가 실제 환경을 정확히 반영하지 못할 경우 잘못된 제어 판단 발생

* **심각도:** 🟡 Medium

* **발생 가능성:** 🟡 Medium

* **대응 방안:** 실제 센서와의 교차 검증, 모델 지속 학습 및 보정

### 5. 센서 간 데이터 불일치

* **설명:** 공간센서, 지온센서, CO2센서 간 데이터가 상충되어 제어 로직 혼란 발생

* **심각도:** 🟡 Medium

* **발생 가능성:** 🟡 Medium

* **대응 방안:** 데이터 융합(Data Fusion) 알고리즘 적용, 우선순위 기반 의사결정 로직 설계

### 6. 제어부 단일 장애점(SPOF)

* **설명:** 중앙 제어부 장애 시 전체 제어 시스템이 중단되는 문제

* **심각도:** 🔴 High

* **발생 가능성:** 🟡 Medium

* **대응 방안:** 분산 제어 구조 도입, 제어부 이중화 및 장애 복구 시스템 구축
