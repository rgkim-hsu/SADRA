📋 ADR (Architecture Decision Record)
-------------------------------------

### ADR-001: 온도 기반 다중 상태 제어와 습도·가스 기반 제어의 계층적 분리 아키텍처 채택

| 항목                     | 내용                                                                                                                                                                                                                                                                            |
| ---------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **상황(Context)**        | 스마트 축사 환경에서는 온도(T-indoor), 상대습도(RH-indoor), CO₂, NH₃ 등 복수의 환경 변수를 실시간으로 감지하고 제어해야 한다. 각 변수는 서로 다른 응답 속도와 임계값 특성을 가지며, 특히 온도는 High/Normal/Low 세 가지 이산 상태(state machine)로 동작하는 반면, 가스·습도는 연속적 임계값 비교 방식으로 동작한다. 이 이질적인 두 제어 로직을 단일 제어 루프에 통합할 경우, 상태 충돌 및 제어 우선순위 불명확 문제가 발생한다. |
| **결정(Decision)**       | 제어 시스템을 **Temperature-based Control Stage**와 **Humidity & Gas-based Control Stage**의 두 계층으로 수직 분리한다. 온도 제어는 dead zone(α) 파라미터를 포함한 Finite State Machine(FSM) 방식으로 High/Normal/Low 상태를 전이하며, 습도·가스 제어는 Normal State 달성 이후 독립적으로 동작하는 하위 파이프라인으로 설계한다.                          |
| **근거(Rationale)**      | 온도는 축사 전체 환경의 기저 조건으로, 이것이 정상 범위에 진입(Normal State)해야만 습도·가스 제어가 실질적 효과를 발휘한다. Dead zone(α) 도입으로 온도 경계값 근처에서의 제어 oscillation(채터링)을 방지하며, 계층 분리로 각 제어 루프의 독립적 튜닝과 장애 격리가 가능하다. IEC 61511(기능 안전) 및 스마트팜 ICT 표준(농식품부 고시)에서도 다중 센서 제어의 우선순위 명시를 권고한다.                              |
| **결과(Consequences)**   | 긍정적: 온도 비정상 상태에서 습도·가스 제어가 불필요하게 작동하지 않아 에너지 절감 및 제어 안정성 향상. 각 레이어별 독립 테스트·유지보수 가능. 부정적: NH₃ 급증과 같이 온도와 무관하게 즉각 대응이 필요한 위급 상황에서 상위 온도 레이어의 상태가 하위 가스 제어를 지연시킬 수 있는 구조적 맹점 존재.                                                                                                 |
| **트레이드오프(Trade-offs)** | **얻는 것:** 제어 로직의 명확한 책임 분리, oscillation 방지, 유지보수 용이성, 에너지 효율. **감수해야 할 것:** NH₃·CO₂의 긴급 임계값 초과 시 온도 레이어 우회(bypass) 메커니즘 부재로 인한 응답 지연 위험; 두 레이어 간 인터페이스 설계 복잡도 증가.                                                                                                             |

### ADR-002: Dead Zone(α) 파라미터 기반 히스테리시스 제어 도입

| 항목                     | 내용                                                                                                                                                                           |
| ---------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **상황(Context)**        | T-indoor가 T-high 또는 T-low 경계값 근처에서 미세하게 진동할 경우, 상태(High↔Normal, Low↔Normal)가 수초 단위로 반복 전이되어 냉난방 장치의 빈번한 ON/OFF가 발생한다. 이는 장비 수명 단축, 에너지 낭비, 제어 불안정의 원인이 된다.                   |
| **결정(Decision)**       | 상태 전이 조건에 dead zone α를 도입하여, High State 진입은 T-indoor > T-high + α, 복귀는 T-indoor < T-high - α로 이중 임계값(hysteresis band)을 적용한다. Low State도 동일 원칙 적용.                            |
| **근거(Rationale)**      | 히스테리시스 제어는 HVAC 및 축사 환경제어 분야의 산업 표준 기법으로, KS B 6879(공조기 제어 기준) 및 ASHRAE Guideline 14에서도 권고된다. α값은 축종(돼지·소·닭)별 열생리학적 허용 범위와 센서 측정 불확도(uncertainty)를 반영하여 현장 교정값으로 설정 가능해야 한다. |
| **결과(Consequences)**   | 긍정적: 장비 수명 연장, 에너지 효율 향상, 제어 안정성 확보. 부정적: α 파라미터 설정이 부적절할 경우(너무 큰 α), 실제 위험 온도 구간에서 제어 개입이 지연되어 가축 폐사 위험.                                                                    |
| **트레이드오프(Trade-offs)** | **얻는 것:** 장비 보호, 에너지 절감, 안정적 제어. **감수해야 할 것:** α 최적값 도출을 위한 현장 튜닝 공수 필요; 계절·사육 밀도 변화에 따른 α 동적 재조정 체계 미비 시 성능 저하.                                                             |

⚠️ 잠재적 위험 분석
------------

### 1. NH₃ 급증 시 온도 레이어 우선순위로 인한 긴급 대응 지연

* **설명:** 분뇨 발효 가속화 등으로 NH₃ 농도가 축사 허용 기준(돼지: 25ppm, ACGIH TLV)을 순간적으로 초과할 때, 시스템이 온도 Normal State 진입을 기다리는 동안 NH₃ 배출 환기 명령이 지연된다. 특히 겨울철 Low Temperature State에서 환기량을 줄인 상태라면 NH₃와 저온 제어 간 충돌이 발생한다.
* **심각도:** 🔴 High
* **발생 가능성:** 🟡 Medium
* **대응 방안:** NH₃·CO₂에 대한 **절대 임계값 인터럽트(Emergency Bypass)** 레이어를 온도 제어 레이어보다 상위에 별도 추가한다. 가스 농도가 위험 임계값 초과 시 온도 상태와 무관하게 즉시 강제 환기 명령을 실행하는 인터럽트 서비스 루틴(ISR) 방식 적용.

* * *

### 2. 단일 센서 장애로 인한 잘못된 상태 전이(Sensor Single Point of Failure)

* **설명:** T-indoor를 측정하는 온도 센서가 단선, 노이즈 유입, 또는 분진·습기로 인해 오작동할 경우, 시스템은 실제와 무관한 High/Low State로 전이되어 냉방기 또는 난방기가 부적절하게 작동한다. 혹한기 난방 차단 시 가축 저체온 폐사까지 이어질 수 있다.
* **심각도:** 🔴 High
* **발생 가능성:** 🟡 Medium
* **대응 방안:** 동일 공간 내 **온도 센서 이중화(Redundancy)** 배치 및 Voting Logic(2-out-of-3) 적용. 센서값의 급격한 변화율(Rate of Change) 모니터링을 통한 이상값 자동 필터링. 센서 장애 감지 시 알람 발령 및 마지막 유효 상태(Last Known Good State) 유지 모드 전환.

* * *

### 3. Dead Zone(α) 파라미터 오설정으로 인한 열 스트레스 누적

* **설명:** α값이 과도하게 크게 설정된 경우, T-indoor가 실제 가축에게 위험한 수준임에도 불구하고 High State로 전이되지 않아 냉방 조치가 지연된다. 예를 들어 돼지의 열 스트레스 임계 온도(28°C 이상)에서 α=3°C로 설정 시 31°C까지 냉방 미작동 가능. 이는 사료 섭취량 감소, 번식 성능 저하, 심각 시 폐사로 이어진다.
* **심각도:** 🔴 High
* **발생 가능성:** 🟡 Medium
* **대응 방안:** 축종별·성장 단계별 **α 권장값 가이드라인** 수립 및 시스템 내 사전 정의 프리셋 제공. α 설정값에 대한 **상한값(Max α) 하드코딩** 제한 적용. 정기적 α 파라미터 감사(Audit) 프로세스 운영.

* * *

### 4. 습도·가스 센서 측정값의 교차 간섭(Cross-interference) 오진단

* **설명:** NH₃ 센서는 CO₂ 및 수증기(고습도)에 의해 측정값이 영향받는 교차 감응(cross-sensitivity) 특성을 가진다. 고습도(RH > 80%) 환경에서 NH₃ 센서가 실제보다 높은 값을 출력하면, 시스템은 불필요한 환기 명령을 내려 축사 온도를 급격히 떨어뜨릴 수 있으며, 이는 온도 제어 레이어와의 충돌을 유발한다.
* **심각도:** 🟡 Medium
* **발생 가능성:** 🟡 Medium
* **대응 방안:** **전기화학식 또는 광학식(NDIR) 고선택성 센서** 채택으로 교차 감응 최소화. 센서 펌웨어 레벨에서 습도 보상 알고리즘 적용. RH 측정값을 NH₃/CO₂ 해석 로직의 보정 입력값으로 활용하는 **다변량 센서 퓨전(Sensor Fusion)** 설계.

* * *

### 5. 네트워크/엣지 컨트롤러 장애 시 제어 공백(Control Gap) 발생

* **설명:** ICT 기반 스마트 축사는 센서 데이터를 엣지 게이트웨이 또는 클라우드로 전송하여 제어 명령을 수신하는 구조를 전제로 한다. 네트워크 단절, 엣지 컨트롤러 재부팅, 서버 장애 발생 시 제어 명령이 중단되어 모든 환경 제어 장치가 마지막 상태(ON 또는 OFF)로 고착된다. 난방기 지속 ON 상태에서 네트워크 장애 발생 시 축사 과열 위험이 현실화된다.
* **심각도:** 🔴 High
* **발생 가능성:** 🟡 Medium
* **대응 방안:** 엣지 컨트롤러에 **로컬 Fallback 제어 로직(Standalone Mode)** 내장, 네트워크 단절 시 미리 정의된 안전 상태(Safe State: 적정 온도 유지를 위한 기본 환기 ON)로 자동 전환. 제어 명령 Watchdog Timer 도입으로 일정 시간 무응답 시 자동 안전 모드 진입. LTE/Wi-Fi 이중화 통신망 구성.

* * *

### 6. 계절적 외기 조건 변화에 대한 정적 임계값의 부적응

* **설명:** T-high, T-low, Proper Temperature, Proper Humidity 등 모든 임계값이 정적(static) 상수로 설정되어 있을 경우, 혹서기·혹한기의 극단적 외기 조건에서 실내외 온도차가 제어 가능 범위를 벗어날 수 있다. 예를 들어 외기 온도가 38°C인 혹서기에 환기만으로 T-indoor를 T-high 이하로 유지하는 것이 물리적으로 불가능한 상황이 발생한다.

* **심각도:** 🟡 Medium

* **발생 가능성:** 🔴 High

* **대응 방안:** **외기 온도·습도 센서** 추가 설치 및 외기 조건을 반영한 **적응형(Adaptive) 임계값 자동 조정** 알고리즘 도입. 기상청 API 연동을 통한 예측 기반 사전 제어(Predictive Control) 적용. 물리적 한계 도달 시 관리자에게 경보 발령 및 추가 냉방 장치 기동 권고 알림 자동화.
