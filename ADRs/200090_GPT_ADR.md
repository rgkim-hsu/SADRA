📋 ADR (Architecture Decision Record)
-------------------------------------

### ADR-001: 의사결정 트리 기반 작물 생육 상태 분류 및 진단 아키텍처 채택

| 항목                     | 내용                                                                                                                                                                                         |
| ---------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **상황(Context)**        | 시스템은 작물 데이터를 입력으로 받아 여러 개의 의사결정 트리(Tree a, b, n)를 통해 분석하고, 이를 기반으로 생육 상태를 분류(예: 생육 조건 적합, 질소 부족 등)한다. 이후 민감도 분석 및 평균값 산출을 통해 최종 진단 결과를 도출한다. 핵심 과제는 “작물 생육 상태를 자동으로 진단하고 문제 요인을 식별하는 것”이다. |
| **결정(Decision)**       | 다중 의사결정 트리(앙상블 형태)를 활용하여 작물 데이터를 분류하고, 결과를 집계하여 최종 생육 상태를 판단하는 분류 기반 아키텍처를 채택한다. 이후 민감도 분석을 통해 주요 영향 요인을 도출한다.                                                                             |
| **근거(Rationale)**      | 의사결정 트리는 해석 가능성이 높고 농업 데이터에 적합한 모델이다. 여러 트리를 사용하는 방식은 단일 모델보다 정확도를 높이고 과적합을 완화할 수 있다. 또한 결과를 직관적으로 이해할 수 있어 농업 현장에서 활용성이 높다.                                                               |
| **결과(Consequences)**   | **긍정적:** 높은 해석성, 비교적 낮은 계산 비용, 빠른 의사결정, 현장 적용 용이**부정적:** 복잡한 비선형 관계 표현 한계, 데이터 품질 의존성                                                                                                      |
| **트레이드오프(Trade-offs)** | 해석성과 실용성을 얻는 대신, 딥러닝 대비 복잡한 패턴 학습 능력은 제한된다.                                                                                                                                                |

* * *

⚠️ 잠재적 위험 분석
------------

### 1. 데이터 품질 문제

* **설명:** 입력 작물 데이터 오류 시 잘못된 분류 결과 발생

* **심각도:** 🔴 High

* **발생 가능성:** 🔴 High

* **대응 방안:** 데이터 검증 및 정제 시스템 연계, 이상치 제거

### 2. 모델 과적합

* **설명:** 특정 데이터에 과도하게 맞춰져 일반화 성능 저하

* **심각도:** 🟡 Medium

* **발생 가능성:** 🟡 Medium

* **대응 방안:** 앙상블 기법, 교차 검증, 가지치기(pruning)

### 3. 변수 선택 편향

* **설명:** 특정 변수에 과도하게 의존하여 잘못된 판단 가능

* **심각도:** 🟡 Medium

* **발생 가능성:** 🟡 Medium

* **대응 방안:** 피처 중요도 분석, 다양한 변수 확보

### 4. 클래스 불균형 문제

* **설명:** 특정 상태(예: 질소 부족)가 적게 나타나면 모델 성능 저하

* **심각도:** 🟡 Medium

* **발생 가능성:** 🔴 High

* **대응 방안:** 데이터 리샘플링, 가중치 조정

### 5. 민감도 분석 오류

* **설명:** 잘못된 영향도 계산으로 의사결정 왜곡 가능

* **심각도:** 🟡 Medium

* **발생 가능성:** 🟡 Medium

* **대응 방안:** 다양한 분석 기법 병행, 전문가 검증

### 6. 확장성 한계

* **설명:** 데이터 및 변수 증가 시 트리 구조 복잡도 증가

* **심각도:** 🟢 Low

* **발생 가능성:** 🟡 Medium

* **대응 방안:** 모델 단순화, 랜덤포레스트 등 확장 기법 적용

### 7. 실시간 처리 한계

* **설명:** 대규모 데이터 입력 시 처리 지연 발생 가능

* **심각도:** 🟢 Low

* **발생 가능성:** 🟡 Medium

* **대응 방안:** 경량 모델 유지, 배치/스트리밍 처리 분리
