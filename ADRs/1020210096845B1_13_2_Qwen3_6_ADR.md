# 🏗️ 아키텍처 분석 보고서

## 📋 ADR (Architecture Decision Record)

### ADR-001: FT-NIR 기반 실시간 양액 성분 분석 및 폐쇄 루프(Feedback Loop) 제어 아키텍처 채택

| 항목                     | 내용                                                                                                                                                                                                        |
| ---------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **상황(Context)**        | 스마트팜 환경에서 작물의 생육 단계별 최적 영양분을 공급하기 위해 양액 A, B, C 및 조절제를 혼합해야 함. 기존 개방형(Open-loop) 정량 이송 프 방식은 원액 농도 변동이나 프 오차로 인해 실제 혼합 양액의 성분이 목표치와 불일치할 수 있으며, 이는 작물 생육 저해로 이어질 수 있는 아키처적 한계가 존재함.                       |
| **결정(Decision)**       | 혼합 탱크 및 생산 탱크 내부에 **FT-NIR(푸리에 변환 근적외선) 분광 분석용 탐침(Probe, 31)**을 설치하고, 이를 **클라우드 기반 스마트 양액 공급관리 제어시스템(32)**과 실시간 연동하는 **폐쇄 루프(Closed-loop) 제어 아키텍처**를 채택함. 분석 데이터를 기반으로 양액 농축액을 보충 투입하여 목표 성분을 유지하도록 설계함.  |
| **근거(Rationale)**      | FT-NIR 기술은 비파괴적으로 다성분(질소, 인, 칼륨 등)을 동시에 정량 분석할 수 있음. 이를 혼합 과정(정량 이송 펌프 직후)과 순환 과정(생산 탱크)에 적용함으로써, 1) 혼합 직후의 초기 농도 검증과 2) 작물 흡수 후 변동된 양액 성분의 실시간 보정이 가능해짐. 이는 클라우드의 '최적조성비 기준' 명령을 물리적으로 정확히 구현하는 유일한 방법임. |
| **결과(Consequences)**   | 양액 관리의 정밀도가 획기적으로 향상되어 작물 품질 균일화가 가능해지며, 불필요한 비료 낭비를 줄일 수 있음. 반면, FT-NIR 센서 도입으로 초기 구축 비용이 상승하고, 분광 데이터 분석을 위한 화학계량학(Chemometrics) 모델 유지보수라는 새로운 운영 과제가 발생함.                                              |
| **트레이드오프(Trade-offs)** | 실시간 정밀 제어 및 양액 최적화 확보 vs. 고가의 센서 도입 비용, 복잡한 데이터 분석 모델 관리 부담, 및 시스템 통합 난이도 증가.                                                                                                                             |

---

## ⚠️ 잠재적 위험 분석

### 1. FT-NIR 탐침(Probe) 오염으로 인한 분석 데이터 왜곡

- **설명:** 양액 탱크 내부에 설치된 탐침(31)에 비료 침전물, 이물질, 또는 생물학적 막(Biofilm)이附着할 경우, 근적외선 투과율 또는 반사율이 변하여 실제 농도와 다른错误的인 분석 데이터가 전송됨.
- **심각도:** 🔴 High
- **발생 가능성:** 🔴 High
- **대응 방안:** 탐침에 자동 세척 기능(예: 에어 퍼지, 와이퍼, 초음파 세척) 탑재, 신호 강도 변화를 모니터링하여 오염 감지 시 자동 세척 사이클 실행 및 알림 기능 구현.
  
  ### 2. 클라우드 통신 지연에 의한 실시간 제어 실패
- **설명:** FT-NIR 분석 데이터가 클라우드 시스템(32)으로 전송되어 처리된 후, 다시 '양액 재활용을 위한 양액 농축액 보충투입' 명령으로 내려오는 과정에서 네트워크 지연이 발생하면, 탱크 내 양액 농도가 허용 오차 범위를 벗어나 작물에 공급될 수 있음.
- **심각도:** 🔴 High
- **발생 가능성:** 🟡 Medium
- **대응 방안:** 엣지 컴퓨팅(Edge Computing) 도입. 분석 데이터의 1차 판정 및 긴급 보충 밸브 제어는 로컬 컨트롤러에서 즉시 수행하고, 클라우드와는 동기화 및 장기 트렌드 분석용으로만 통신하는 하이브리드 구조 적용.
  
  ### 3. 화학계량학 모델(Calibration Model)의 드리프트(Drift)
- **설명:** FT-NIR 분석은 미리 학습된 수학적 모델에 의존함. 원료 비료(A, B, C)의 제조사 변경이나 성분 미세 변동이 발생할 경우, 기존 모델이 새로운 스트럼 패턴을 제대로 해석하지 못해 분석 결과가 систем적으로 틀어지는 현상이 발생함.
- **심각도:** 🟡 Medium
- **발생 가능성:**  Medium
- **대응 방안:** 정기적인 실험실 분석 결과와 FT-NIR 데이터를 비교하여 모델 재보정(Recalibration) 주기 수립, 머신러닝 기반의 적응형 모델(Adaptive Model) 도입을 통한 환경 변화 자동 학습.
  
  ### 4. 정량이송펌프와 분석 시스템 간의 제어 불협화음
- **설명:** 클라우드에서 지시한 '최적조성비'에 따라 정량이송펌프가 작동하는데, FT-NIR 분석 결과 혼합 비율이 틀린 경우, 시스템이 이를 보정하려 추가 주입을 명령함. 이 과정이 반복되면 탱크 내 총량이 초과(Overflow)하거나 혼합 비율이 진동(Oscillation)할 수 있음.
- **심각도:** 🟡 Medium
- **발생 가능성:** 🟡 Medium
- **대응 방안:** 제어 알고리즘에 PID 제어 또는 모델 예측 제어(MPC)를 적용하여 과도한 보정 명령 방지, 탱크 레벨 센서와 연동하여 총량 초과 시 펌프 자동 정지 로직 구현.
  
  ### 5. FT-NIR 센서 하드웨어의 화학적 부식 및 내구성 문제
- **설명:** 양액은 염류 농도가 높고 산성/알칼리성 성분을 포함함. 장기간 탱크 내부(특히 생산 탱크 순환 구간)에 노출된 FT-NIR 센서의 창(Window) 재질이나 하우징이 화학적 부식으로 손상될 수 있음.
- **심각도:**  High
- **발생 가능성:** 🟢 Low
- **대응 방안:** 사파이어(Sapphire) 창 등 내화학성이 뛰어난 소재 사용, IP68 이상의 방수/방진 등급 하우징 적용, 정기적인 예방 정비(Preventive Maintenance) 일정 수립.
