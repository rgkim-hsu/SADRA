# 🏗️ 아키텍처 분석 보고서

## 📋 ADR (Architecture Decision Record)

### ADR-001: [로봇 팔 중심의 이기종 센서 통합 아키텍처 채택]

| 항목 | 내용 |
|------|------|
| **상황 (Context)** | 스마트팜 환경에서 로봇 팔이 단순한 구동 장치를 넘어, 다양한 센서 데이터를 수집하고 제어하는 통합 인터페이스 노드로서 기능해야 한다. 특히 TTA 표준 (가상센서, 환경 모니터링 등) 에 맞춰 물리적 환경과 디지털 트윈 데이터를 동시에 처리해야 하는 요구사항이 있다. |
| **결정 (Decision)** | '제어부'에서 로봇 팔을 지시하는 신호를 받아, 로봇 팔 자체를 경유하여 '가상센서', '공간센서', '지온센서', 'CO2센서' 등 4 가지 유형의 센서에 대한 제어 및 데이터 수집을 중앙 집중화한다. |
| **근거 (Rationale)** | 이미지 분석 결과, 제어 신호가 제어부에서 로봇 팔로 전달된 후, 로봇 팔이 다수의 센서로 분산되어 신호를 보냄을 확인할 수 있다. 이는 모듈화 및 확장성 확보를 위해 로봇 팔을 센서 허브(Hub)로 설정하는 것이 효율적임을 시사함. 또한 관련 문서에서 언급된 TTA 표준 (TTAK.KO-10.1170 등) 에 따른 데이터 상호운용성을 위해 통합된 인터페이스가 필수적이다. |
| **결과 (Consequences)** | **긍정적:** 센서 관리의 간소화, 유지보수 비용 절감, 디지털 트윈 기반 가상 센서 연동 용이.<br>**부정적:** 로봇 팔의 부하 증가, 단일 포인트 고장 시 모든 센서 데이터 수집 중단 가능성. |
| **트레이드오프 (Trade-offs)** | **장점:** 단일 제어 로직으로 다양한 센서 타입 관리 가능.<br>**단점:** 로봇 팔 내구성과 센서 내구성을 동시에 고려한 설계 필요 (로봇 팔이 센서를 직접 만나는 경우). |

## ⚠️ 잠재적 위험 분석

### 1. [센서 데이터 동기화 및 편차 위험]
- **설명:** 로봇 팔이 이동하거나 조작하는 과정에서, '지온센서'와 'CO2 센서' 등 서로 다른 환경의 데이터가 실시간으로 업데이트되지 않거나, 가상센서의 계산값이 실제 물리값과 실시간으로 동조되지 않을 경우 오작동 발생.
- **심각도:** 🔴 High
- **발생 가능성:** 🟡 Medium
- **대응 방안:** 센서 간 데이터 동기화 주기 (Polling Interval) 를 최적화하고, 가상센서 연산 로직에 지연 보상 알고리즘 (Lag Compensation) 을 적용하여 실시간성을 보장한다.

### 2. [물리적 환경 변화로 인한 센서 손상 위험]
- **설명:** 로봇 팔이 '공간센서'나 'CO2 센서'와 물리적으로 상호작용할 때, 로봇의 움직임이 센서의 내구한계를 초과하거나 환경 변화 (습도, 진동) 로 인해 센서 오작동이 발생.
- **심각도:** 🔴 High
- **발생 가능성:** 🔴 High
- **대응 방안:** 센서 마운팅 구조물의 방진/방수 설계 (IP 등급 향상) 및 로봇 팔의 동작 범위를 센서 보호 영역에서 제외하는 소프트웨어 제한 (Software G-Force Limiter) 적용.

### 3. [제어 신호 간섭 및 보안 위험]
- **설명:** '제어부'에서 '로봇팔'로 보내지는 '확장/축소/회전 제어신호'가 외부 전자기 간섭 (EMI) 에 걸리거나, 해킹 시 악성 명령을 받아 로봇 팔이 센서를 파괴하거나 오류 명령을 수행.
- **심각도:** 🔴 High
- **발생 가능성:** 🟡 Medium
- **대응 방안:** 제어 프로토콜 암호화 (AES-256) 적용 및 물리적 절연 (Shielded Cable) 사용. 보안 표준 (ISO/IEC 30141:2024, ETSI EN 303 645) 준수 여부를 정기적으로 점검.

### 4. [네트워크 지연 (Latency) 으로 인한 제어 불안정]
- **설명:** 로봇 팔이 '가상센서'나 '공간센서'와 통신하며 데이터를 전송할 때, 네트워크 지연으로 인해 제어가 늦어지거나 명령이 실패할 경우 스마트팜 자동화 시스템 오작동.
- **심각도:** 🟡 Medium
- **발생 가능성:** 🟡 Medium
- **대응 방안:** 로컬 에지 컴퓨팅 (Edge Computing) 활용으로 네트워크 지연 최소化 및 MQTT, CoAP 등 경량 프로토콜을 통한 효율적 데이터 전송 경로 확보.

### 5. [가상 센서 데이터 신뢰성 저하]
- **설명:** 디지털 트윈 기반의 '가상센서'가 실제 센서 데이터 (지온, CO2 등) 를 기반으로 계산되는데, 입력 물리 센서의 데이터가 누락되거나 왜곡되면 가상센서 결과가 신뢰할 수 없는 값으로 변환되어 의사결정 오류 유발.
- **심각도:** 🟡 Medium
- **발생 가능성:** 🟡 Medium
- **대응 방안:** 물리 센서와 가상 센서 간 데이터 불일치 감지 알고리즘 구현. 불일치 감지 시 가상센서 값을 'Unavailable' 또는 이전 안전한 값으로 대체하는 Fail-Safe 로직 적용.
