📋 ADR (Architecture Decision Record)
-------------------------------------

### ADR-001: 시뮬레이션 기반 강화학습(DDPG) 환경제어 아키텍처 채택

| 항목                     | 내용                                                                                                                                                                                                  |
| ---------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **상황(Context)**        | 시스템은 온실 환경 제어를 위해 시뮬레이션 기반 가상 학습 환경(Greenhouse library, Weather forecast, Human experts)을 구축하고, 이를 기반으로 강화학습(DDPG) 모델을 학습시켜 실제 환경 제어에 적용하는 구조이다. 핵심 과제는 “복잡한 온실 환경에서 최적 제어 전략을 자동으로 학습하고 적용하는 것”이다. |
| **결정(Decision)**       | Environment–Agent 구조를 기반으로 Deep Deterministic Policy Gradient(DDPG) 알고리즘을 채택하고, Actor-Critic 신경망(DNN)을 활용하여 연속적인 환경 제어(action)를 수행하는 강화학습 아키텍처를 적용한다. 또한 실제 적용 전 시뮬레이션 환경에서 사전 학습을 수행하는 구조를 채택한다.   |
| **근거(Rationale)**      | 온실 환경은 연속적인 제어 변수(온도, 습도 등)를 가지므로 DDPG와 같은 연속 제어 강화학습 알고리즘이 적합하다. 시뮬레이션 기반 학습은 실제 환경에서의 시행착오 비용을 줄이고 안정성을 확보할 수 있다. 전문가 지식과 기상 데이터를 활용하면 학습 효율을 높일 수 있다.                                            |
| **결과(Consequences)**   | **긍정적:** 최적화된 자동 제어, 환경 적응력 향상, 에너지 효율 개선, 인력 의존도 감소**부정적:** 학습 모델 복잡성 증가, 초기 학습 비용, 모델 해석 어려움                                                                                                      |
| **트레이드오프(Trade-offs)** | 높은 자동화 및 최적화를 달성하는 대신, 모델 개발 및 운영의 복잡성과 계산 비용 증가를 감수해야 한다.                                                                                                                                          |

* * *

⚠️ 잠재적 위험 분석
------------

### 1. 시뮬레이션-현실 간 격차(Sim-to-Real Gap)

* **설명:** 시뮬레이션 환경과 실제 온실 환경 차이로 인해 학습된 정책이 실제에서 성능 저하

* **심각도:** 🔴 High

* **발생 가능성:** 🔴 High

* **대응 방안:** 도메인 랜덤화, 실제 데이터 기반 보정, 온라인 학습 병행

### 2. 학습 불안정성

* **설명:** DDPG 알고리즘 특성상 학습이 수렴하지 않거나 불안정하게 동작할 수 있음

* **심각도:** 🔴 High

* **발생 가능성:** 🟡 Medium

* **대응 방안:** 하이퍼파라미터 튜닝, 경험 재플레이 버퍼 활용, 안정화 기법 적용

### 3. 과도한 탐색으로 인한 환경 리스크

* **설명:** 학습 과정에서 비정상적인 제어(action)가 실행되어 작물 피해 발생 가능

* **심각도:** 🔴 High

* **발생 가능성:** 🟡 Medium

* **대응 방안:** 안전 제약(Safety Constraint) 적용, 정책 제한, 시뮬레이션 사전 검증

### 4. 데이터 및 모델 의존성

* **설명:** 기상 데이터 및 전문가 지식의 품질이 낮을 경우 학습 성능 저하

* **심각도:** 🟡 Medium

* **발생 가능성:** 🟡 Medium

* **대응 방안:** 데이터 품질 관리, 다양한 데이터 소스 확보

### 5. 계산 자원 및 비용 증가

* **설명:** DNN 기반 학습 및 시뮬레이션 수행에 높은 컴퓨팅 자원 요구

* **심각도:** 🟡 Medium

* **발생 가능성:** 🔴 High

* **대응 방안:** 클라우드 GPU 활용, 모델 경량화, 학습 효율 최적화

### 6. 모델 해석성 부족

* **설명:** 강화학습 모델의 의사결정 과정이 불투명하여 사용자 신뢰 저하

* **심각도:** 🟡 Medium

* **발생 가능성:** 🟡 Medium

* **대응 방안:** 설명 가능한 AI(XAI) 도입, 시각화 도구 제공

### 7. 시스템 통합 복잡성

* **설명:** 강화학습 모델을 기존 제어 시스템과 통합하는 과정에서 충돌 발생 가능

* **심각도:** 🟡 Medium

* **발생 가능성:** 🟡 Medium

* **대응 방안:** API 기반 통합, 단계적 적용(파일럿 운영), 하이브리드 제어 구조 적용
