# 🏗️ 아키텍처 분석 보고서

## 📋 ADR (Architecture Decision Record)

### ADR-001: 중앙 집중형 메시지 버스를 통한 모듈 간 비동기 통합 및 확장성 확보

| 항목 | 내용 |
|------|------|
| **상황(Context)** | 모니터링부(310), 제어부(320), 모델링부(350), 망구축부(340) 등 다수의 기능 조직이 유기적으로 연결되어야 함. 각 모듈 간 직접적인 강결합(Tight Coupling)이 발생할 경우, 특정 모듈의 변경이 시스템 전체의 불안정성을 초래하고 커스텀부(390)를 통한 유연한 확장이 어려움. |
| **결정(Decision)** | 모든 컴포넌트(310~390)를 중앙의 **양방향 공통 데이터 버스(Common Data Bus)** 아키텍처로 연결함. 각 모듈은 독립적인 상태를 유지하며, 이벤트 기반(Event-driven) 또는 메시지 지향 미들웨어(MOM)를 통해 상호작용하도록 설계함. |
| **근거(Rationale)** | 플랫폼부(360)와 연결부(370)의 역할을 강화하여 이기종 시스템 및 복수 필지 운용(380) 환경에서도 일관된 데이터 흐름을 보장하기 위함. 또한, 완료부(330)의 프로세스 종결 시점을 명확히 정의하기 위해 중앙 제어가 필수적임. |
| **결과(Consequences)** | 시스템의 유연성과 확장성이 극대화되어 신규 기능을 커스텀부(390)에 추가하기 용이해짐. 개별 모듈의 장애가 전체 시스템으로 전파되는 것을 방지하는 격리 효과(Isolation)를 얻음. |
| **트레이드오프(Trade-offs)** | 중앙 버스 시스템에 대한 의존도가 높아지므로, 버스 자체의 고가용성 확보를 위한 복잡도와 비용이 증가함. 직접 호출 방식에 비해 미세한 응답 지연(Latency)이 발생할 수 있음. |

---

## ⚠️ 잠재적 위험 분석

### 1. 중앙 버스 시스템의 단일 장애점(SPOF) 위험
- **설명:** 모든 모듈이 중앙 통로를 통해 통신하므로, 해당 버스 시스템에 장애 발생 시 전체 서비스가 마비됨.
- **심각도:** 🔴 High
- **발생 가능성:** 🟡 Medium
- **대응 방안:** 중앙 버스의 클러스터링 구성 및 다중화(Redundancy)를 통해 고가용성을 확보하고, 서킷 브레이커(Circuit Breaker) 패턴을 도입함.

### 2. 복수 필지 운용(380) 시 데이터 병목 현상
- **설명:** 대규모 필지 데이터를 실시간으로 처리할 때 모니터링부(310)와 제어부(320) 간의 트래픽 급증으로 인한 성능 저하.
- **심각도:** 🔴 High
- **발생 가능성:** 🔴 High
- **대응 방안:** 데이터 샤딩(Sharding) 및 스트리밍 처리 기술을 도입하고, 중요도에 따른 메시지 우선순위 큐(Priority Queue)를 운용함.

### 3. 모듈 간 데이터 정합성 불일치
- **설명:** 비동기 통신 환경에서 모델링부(350)의 결과가 망구축부(340)에 전달되는 과정 중 순서가 바뀌거나 누락되어 불일치 발생.
- **심각도:** 🟡 Medium
- **발생 가능성:** 🟡 Medium
- **대응 방안:** 분산 트랜잭션 관리 또는 Saga 패턴을 적용하여 최종적 정합성(Eventual Consistency)을 보장하고 멱등성(Idempotency) 설계를 강화함.

### 4. 커스텀부(390) 확장에 따른 보안 취약점
- **설명:** 외부 연동이나 사용자 정의 기능을 수행하는 커스텀부를 통해 비정상적인 데이터나 스크립트가 주입될 위험.
- **심각도:** 🔴 High
- **발생 가능성:** 🟡 Medium
- **대응 방안:** 커스텀 모듈 진입점에 엄격한 샌드박스(Sandbox) 환경을 구축하고, API Gateway를 통한 인증 및 인가 체계를 강화함.

### 5. 연결부(370)의 하드웨어/레거시 프로토콜 호환성 장애
- **설명:** 다양한 현장 장비와 연결 시 표준화되지 않은 프로토콜로 인해 제어부(320)의 명령이 정상 전달되지 않는 시나리오.
- **심각도:** 🟡 Medium
- **발생 가능성:** 🔴 High
