📋 ADR (Architecture Decision Record)
-------------------------------------

### ADR-001: IoT 기반 생육환경 폐루프 제어 및 원격 관리 아키텍처 채택

| 항목                     | 내용                                                                                                                                                                                           |
| ---------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **상황(Context)**        | 시스템은 누에 사육 공간 내 온도·습도·CO₂ 센서, 영상 획득 장치, 입력/출력 모듈과 환경 제어 시스템으로 구성되며, 외부에서는 웹 및 스마트폰 기반 제어 시스템이 인터넷을 통해 연결된다. 핵심 과제는 “생육 환경 데이터를 실시간으로 수집하고, 이를 기반으로 자동 또는 원격으로 환경을 제어하여 최적의 사육 조건을 유지하는 것”이다. |
| **결정(Decision)**       | 센서 및 영상 데이터를 기반으로 환경 제어 시스템을 자동으로 조정하는 폐루프(Closed-loop) 제어 구조를 채택하고, 동시에 웹/모바일 기반 원격 제어 인터페이스를 통합한다. 데이터 흐름은 “센서/영상 → 입력 모듈 → 제어 시스템 → 출력 모듈 → 환경 변화 → 센서 피드백” 구조로 설계한다.                     |
| **근거(Rationale)**      | 양잠과 같은 생물 사육 환경은 미세한 환경 변화에 민감하기 때문에 실시간 모니터링과 즉각적인 제어가 필수적이다. IoT 기반 폐루프 제어는 자동화 수준을 높이고 인력 의존도를 줄이며, 원격 제어는 운영 효율성과 대응 속도를 향상시킨다.                                                          |
| **결과(Consequences)**   | **긍정적:** 자동화된 환경 제어, 생육 안정성 향상, 원격 운영 가능, 데이터 기반 관리**부정적:** 네트워크 의존성 증가, 시스템 장애 시 영향 확대, 보안 리스크 증가                                                                                           |
| **트레이드오프(Trade-offs)** | 높은 자동화와 운영 효율성을 얻는 대신, 시스템 복잡성과 보안/운영 리스크를 감수해야 한다.                                                                                                                                          |

* * *

⚠️ 잠재적 위험 분석
------------

### 1. 센서 오작동 및 데이터 오류

* **설명:** 온도, 습도, CO₂ 센서 오류로 인해 잘못된 환경 제어가 수행될 수 있음

* **심각도:** 🔴 High

* **발생 가능성:** 🟡 Medium

* **대응 방안:** 센서 이중화, 정기 교정, 이상 데이터 필터링 적용

### 2. 네트워크 장애로 인한 원격 제어 불가

* **설명:** 인터넷 연결 문제 발생 시 웹/스마트폰 제어 기능이 중단됨

* **심각도:** 🟡 Medium

* **발생 가능성:** 🔴 High

* **대응 방안:** 로컬 자동 제어 로직 유지, 오프라인 모드 지원, 이중 네트워크 구성

### 3. 환경 제어 시스템 고장

* **설명:** 냉난방, 환기 등 환경 제어 장치 고장 시 생육 환경 급격히 악화

* **심각도:** 🔴 High

* **발생 가능성:** 🟡 Medium

* **대응 방안:** 장비 이중화, 상태 모니터링, 예방 정비 체계 구축

### 4. 영상 데이터 처리 지연

* **설명:** 영상 획득 및 분석 지연으로 생육 상태 판단이 늦어질 수 있음

* **심각도:** 🟡 Medium

* **발생 가능성:** 🟡 Medium

* **대응 방안:** 엣지 컴퓨팅 기반 영상 처리, 중요 이벤트 중심 분석, 데이터 압축

### 5. 보안 취약점 (원격 접근 공격)

* **설명:** 웹/모바일 제어 시스템이 해킹될 경우 환경 제어가 악의적으로 변경될 수 있음

* **심각도:** 🔴 High

* **발생 가능성:** 🟡 Medium

* **대응 방안:** 인증/인가 강화, 암호화 통신, 접근 로그 및 이상 탐지 시스템 적용

### 6. 수동 제어와 자동 제어 충돌

* **설명:** 사용자의 수동 제어 요청과 자동 제어 로직이 충돌하여 비정상 동작 발생

* **심각도:** 🟡 Medium

* **발생 가능성:** 🟡 Medium

* **대응 방안:** 제어 우선순위 정책 정의, 충돌 방지 로직 구현, 사용자 알림 제공

### 7. 데이터 저장 및 활용 부족

* **설명:** 수집된 환경 및 생육 데이터가 제대로 활용되지 못할 경우 시스템 가치 저하

* **심각도:** 🟢 Low

* **발생 가능성:** 🟡 Medium

* **대응 방안:** 데이터 분석 플랫폼 구축, 장기 데이터 저장 및 AI 분석 연계
