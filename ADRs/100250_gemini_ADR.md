## 📋 ADR (Architecture Decision Record)

### ADR-001: 클라우드-에지 하이브리드 데이터 관리 및 제어 구조 채택

| 항목 | 내용 |
|------|------|
| **상황(Context)** | 스마트팜은 24시간 실시간 제어가 필수적이나, 네트워크 장애 시 클라우드 서버(200)에만 의존할 경우 재배 환경 제어(30)가 중단되어 작물 피해가 발생할 수 있음. 또한, 방대한 농장 데이터를 클라우드로 전송하는 데 따른 대역폭 비용과 지연 시간 문제가 존재함. |
| **결정(Decision)** | 농장 제어기(100)를 단순한 게이트웨이가 아닌 에지(Edge) 컴퓨팅 노드로 활용하여 로컬에서 '농장 데이터 저장 및 관리'를 수행하고, 클라우드 서버(200)는 백업 및 대규모 데이터 분석/원격 관리자 단말(20) 인터페이스 역할을 수행하는 하이브리드 구조를 채택함. |
| **근거(Rationale)** | 외부 네트워크가 단절되어도 농장 제어기(100)가 로컬 데이터를 바탕으로 액추에이터(30)를 제어할 수 있는 자율성을 확보하기 위함임(Local Autonomy). 또한, 데이터의 1차 가공을 로컬에서 처리하여 클라우드 전송 부하를 최적화함. |
| **결과(Consequences)** | 시스템의 가용성(Availability)과 신뢰성이 비약적으로 향상됨. 인터넷 연결 없이도 기본적인 스마트팜 운영이 가능해짐. 다만, 로컬 제어기(100)와 클라우드(200) 간의 데이터 동기화 로직 및 일관성 유지를 위한 복잡성이 증가함. |
| **트레이드오프(Trade-offs)** | 로컬 하드웨어 사양 상향에 따른 초기 구축 비용(CAPEX)은 증가하나, 운영 안정성 확보 및 장기적인 클라우드 통신 비용(OPEX) 절감 효과를 얻을 수 있음. |

## ⚠️ 잠재적 위험 분석

### 1. 네트워크 분단(Network Partition)으로 인한 데이터 불일치
- **설명:** 농장 제어기와 클라우드 서버 간의 네트워크가 장기간 단절되었다가 복구될 때, 양측의 데이터 상태가 충돌하거나 누락되어 관리자 단말(20)에 잘못된 정보가 표시되는 시나리오
- **심각도:** 🟡 Medium
- **발생 가능성:** 🔴 High
- **대응 방안:** 시퀀스 번호 및 타임스탬프 기반의 데이터 동기화 프로토콜을 적용하고, 충돌 발생 시 '농장 제어기(현장 데이터)'를 우선순위로 두는 정책 수립

### 2. 농장 제어기(100) 하드웨어 단일 장애점(SPOF)
- **설명:** 농장의 모든 액추에이터 제어와 데이터 저장을 담당하는 농장 제어기가 하드웨어 고장으로 정지할 경우, 모든 자동화 기능이 마비되는 시나리오
- **심각도:** 🔴 High
- **발생 가능성:** 🟡 Medium
- **대응 방안:** 주요 제어 모듈의 이중화(Redundancy)를 검토하거나, 제어기 장애 시 수동으로 액추에이터를 조작할 수 있는 물리적 바이패스(Bypass) 스위치 설치

### 3. 클라우드 서버 접근 권한 탈취 및 원격 제어 오남용
- **설명:** 관리자 단말(20) 혹은 클라우드 서버(200)의 계정이 해킹되어 공격자가 원격 제어 기능을 통해 재배 환경을 고의적으로 파괴(온도 급상승 등)하는 시나리오
- **심각도:** 🔴 High
- **발생 가능성:** 🟡 Medium
- **대응 방안:** 다요소 인증(MFA) 필수 적용, 제어 명령 실행 시 임계치 기반의 이상 탐지 알고리즘 적용, 물리적 안전 범위를 벗어나는 제어 명령에 대한 하드웨어 록(Lock) 설정

### 4. 농장 제어기(100)의 로컬 저장소 용량 초과
- **설명:** 농장 제어기에서 수행하는 '농장 데이터 저장 및 관리' 과정에서 로그나 센서 데이터가 예상을 초과하여 로컬 저장 장치(SD카드, SSD 등)가 가득 차 시스템이 멈추는 시나리오
- **심각도:** 🟡 Medium
- **발생 가능성:** 🔴 High
- **대응 방안:** FIFO(First-In-First-Out) 방식의 자동 데이터 순환 삭제 정책 적용 및 저장 용량 80% 도달 시 관리자 알림(Alert) 기능 구현

### 5. 액추에이터(30) 피드백 루프 부재로 인한 제어 실패
- **설명:** 농장 제어기가 '재배 환경 제어' 신호를 보냈으나, 액추에이터의 물리적 고장으로 인해 동작하지 않았음에도 제어기는 성공으로 판단하여 실제 환경과 데이터가 괴리되는 시나리오
- **심각도:** 🔴 High
- **발생 가능성:** 🟡 Medium
