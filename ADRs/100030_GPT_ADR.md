📋 ADR (Architecture Decision Record)
-------------------------------------

### ADR-001: 단계적 이미지 처리 기반 생육·과중 예측 통합 아키텍처

| 항목                     | 내용                                                                                                                                                                                                                                                                               |
| ---------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **상황(Context)**        | 시스템은 이미지 촬영부(110)와 이미지 전송부(120)를 포함하는 이미지 제공모듈(100)에서 데이터를 수집하고, 생육정보 산출모듈(200) 내부에서 다단계 분석을 수행한다. 내부 구성은 이미지 입력(210) → 기간분류(220) → 이미지 보정(230) → 계측치 산출(240) → 과중 산출(250) → 생육정보 산출(260) → 영농정보 매칭(270) → 정보 전송(280)으로 이어진다. 외부로는 기존정보 DB(300), 영농정보 DB(400), 사용자단말(500)과 연동된다. |
| **결정(Decision)**       | **멀티스테이지 컴퓨터비전 + 농업지식 결합 아키텍처**를 채택한다. <br/>* 수집 계층: 이미지 촬영 및 전송<br/>* 전처리 계층: 이미지 보정 및 정규화<br/>* 분석 계층: 생육 단계 분류 및 계측<br/>* 예측 계층: 과중(수확량) 및 생육 상태 산출<br/>* 지식 결합 계층: 영농 DB 매칭<br/>* 서비스 계층: 사용자 단말 제공                                                                          |
| **근거(Rationale)**      | 단일 모델로 생육 상태를 판단하기보다 단계별 처리(전처리→분류→계측→예측)를 수행하면 정확도와 확장성이 향상된다. 또한 농업 DB와 결합하면 단순 분석을 넘어 실질적인 의사결정 지원이 가능하다.                                                                                                                                                                     |
| **결과(Consequences)**   | 정밀한 생육 분석과 수확량 예측이 가능하며, 사용자에게 실질적인 농업 의사결정 정보를 제공할 수 있다. 그러나 파이프라인이 길어지면서 처리 복잡성과 지연이 증가한다.                                                                                                                                                                                     |
| **트레이드오프(Trade-offs)** | 분석 정확도 향상(장점) vs 처리 지연 증가(단점), 기능 확장성(장점) vs 시스템 복잡성 증가(단점)                                                                                                                                                                                                                      |



* * *

⚠️ 잠재적 위험 분석
------------

### 1. 이미지 전처리 실패 (230)

* **설명:** 보정 오류로 이후 모든 분석 단계에 영향

* **심각도:** 🔴 High

* **발생 가능성:** 🟡 Medium

* **대응 방안:** 자동 품질 검사, 다중 보정 알고리즘 적용

* * *

### 2. 생육 단계 분류 오류 (220)

* **설명:** 작물 성장 단계 오판 → 잘못된 분석 흐름

* **심각도:** 🔴 High

* **발생 가능성:** 🟡 Medium

* **대응 방안:** CNN/Transformer 기반 분류 모델 고도화

* * *

### 3. 계측치 산출 부정확 (240)

* **설명:** 크기, 면적 등 계측값 오류 → 과중 예측 오류

* **심각도:** 🔴 High

* **발생 가능성:** 🟡 Medium

* **대응 방안:** Depth 정보 활용, 기준 스케일 적용

* * *

### 4. 과중(수확량) 예측 오류 (250)

* **설명:** 실제 생산량과 예측값 차이 발생

* **심각도:** 🔴 High

* **발생 가능성:** 🟡 Medium

* **대응 방안:** 회귀 모델 + 시계열 데이터 결합

* * *

### 5. DB 매칭 오류 (270)

* **설명:** 영농정보와 잘못 매칭되어 잘못된 추천 제공

* **심각도:** 🟡 Medium

* **발생 가능성:** 🟡 Medium

* **대응 방안:** 데이터 표준화 및 키 매칭 강화

* * *

### 6. 처리 지연 및 성능 문제

* **설명:** 다단계 처리로 인해 실시간성 저하

* **심각도:** 🟡 Medium

* **발생 가능성:** 🔴 High

* **대응 방안:** 병렬 처리, Edge AI 도입

* * *

### 7. 사용자 전달 정보 해석 문제

* **설명:** 사용자단말(500)에서 제공된 정보 이해 어려움

* **심각도:** 🟡 Medium

* **발생 가능성:** 🟡 Medium

* **대응 방안:** 시각화 및 UX 개선

* * *
