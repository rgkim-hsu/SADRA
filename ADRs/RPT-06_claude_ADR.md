===============

📋 ADR (Architecture Decision Record)
-------------------------------------

### ADR-001: NFC 기반 지하 매설물 정보 제공을 위한 엣지-클라우드 하이브리드 아키텍처 채택

| 항목                     | 내용                                                                                                                                                                                               |
| ---------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **상황(Context)**        | 지하 매설관로(상하수도, 가스관 등)는 육안으로 위치 및 속성 파악이 불가능하며, 굴착 공사 시 매설물 파손 사고, 지진·재난 현장에서의 긴급 대응 지연이 반복적으로 발생한다. 기존 도면 기반 관리는 현장 정합성이 낮고, 119·국가기관·시설물관리기관 등 다수 이해관계자가 실시간으로 동일 정보에 접근해야 하는 멀티 테넌트 요구사항이 존재한다. |
| **결정(Decision)**       | 지하 매설물 표지기에 NFC 칩을 내장하여 관로정보를 로컬 저장(엣지)하고, 스마트폰 Tagging 시 GPS 위치정보와 결합하여 중앙 매설관로 통합서버(클라우드)로 전송한다. 정보 조회는 웹(시설물관리기관/국가기관)과 전용 APP(119/재난현장) 두 채널로 이중화한다.                                         |
| **근거(Rationale)**      | NFC는 별도 전원 없이 수동 태깅만으로 데이터 판독이 가능해 지하 매설 환경에 최적이다. GPS 위치정보 결합으로 GIS 연계가 가능하고, 통합서버를 단일 진실 공급원(Single Source of Truth)으로 삼아 기관 간 데이터 일관성을 보장한다. 웹/앱 이중 채널은 재난 시 인터넷 환경 다양성을 수용한다.                |
| **결과(Consequences)**   | (긍정) 현장 작업자가 스마트폰만으로 즉시 매설물 정보를 확인 가능하며, 119·재난기관의 골든타임 대응력 향상. 시설물관리기관은 웹 포털을 통해 전국 단위 통합 조회 가능. (부정) NFC 태깅이라는 물리적 근접 행위가 필수로, 원격 자동 감지는 불가. 통합서버 장애 시 클라우드 데이터 조회 불가(엣지 NFC 로컬 데이터만 가용).      |
| **트레이드오프(Trade-offs)** | **얻는 것:** 무전원 내구성, 저비용 현장 배포, 멀티 기관 실시간 공유, GIS 연동. **감수하는 것:** 능동적 실시간 모니터링 불가(수동 태깅 의존), NFC 통신 거리 제약(~10cm), 태그 물리적 손상 시 정보 소실 위험                                                             |

### ADR-002: GPS 위치정보와 NFC 태그 데이터의 서버 측 결합 아키텍처

| 항목                     | 내용                                                                                                                                          |
| ---------------------- | ------------------------------------------------------------------------------------------------------------------------------------------- |
| **상황(Context)**        | NFC 태그는 관로 속성정보를 저장하나 절대 위치정보를 자체 산출할 수 없다. 매설물의 정확한 GIS 좌표 등록 및 지도 기반 서비스 제공을 위해 위치정보와 관로정보의 결합이 필수적이다.                                    |
| **결정(Decision)**       | 스마트폰이 NFC 태깅 시점에 GPS 수신 위치를 동시 수집하여 관로정보와 함께 통합서버로 전송하고, 서버에서 위치-속성 결합 처리 후 GIS 레이어로 저장한다.                                                  |
| **근거(Rationale)**      | 클라이언트(스마트폰)에서 GPS와 NFC를 동시 수집하면 별도의 위치측위 인프라 없이 저비용으로 GIS 데이터를 구축할 수 있다. 서버 측 결합은 다중 클라이언트로부터 수집된 위치 데이터의 정규화와 오류 필터링을 중앙에서 일괄 처리할 수 있게 한다. |
| **결과(Consequences)**   | (긍정) 별도 측량 장비 없이 현장 작업자의 태깅 행위 자체가 GIS 데이터 갱신으로 이어지는 크라우드소싱 효과. (부정) GPS 음영지역(건물 밀집, 지하 진입로 인근)에서 위치 정확도 저하로 GIS 오류 발생 가능.                  |
| **트레이드오프(Trade-offs)** | **얻는 것:** 인프라 비용 절감, 실시간 GIS 갱신. **감수하는 것:** GPS 정확도 의존성(오차 3~15m), 실내·협곡 환경에서의 위치 신뢰성 저하                                                   |

* * *

⚠️ 잠재적 위험 분석
------------

### 1. NFC 태그 물리적 손상 및 데이터 소실

* **설명:** 지하 매설 환경 특성상 차량 하중, 굴착 장비 충격, 수분 침투 등으로 NFC 태그가 물리적으로 손상될 경우, 해당 매설물에 대한 현장 접근 경로(태깅)가 완전히 차단된다. 특히 재난 현장에서 정보 공백이 발생할 경우 2차 사고로 이어질 수 있다.
* **심각도:** 🔴 High
* **발생 가능성:** 🔴 High
* **대응 방안:** IP68 이상 방수·방진 등급 및 차량 하중 기준(예: 25톤 이상) 내압 설계 적용. 태그 이중화(주/보조 태그 분리 매설). 통합서버에 GIS 기반 대체 조회 경로 확보. 정기적 태그 상태 점검 프로세스 수립(연 1회 이상 전수 태깅 검증).

* * *

### 2. 중앙 통합서버 단일 장애점(SPOF) 위험

* **설명:** 매설관로 통합서버가 단일 인스턴스로 운영될 경우, 서버 장애·네트워크 단절·사이버 공격 시 시설물관리기관, 국가기관, 119 등 모든 이해관계자의 웹/앱 조회 서비스가 동시에 중단된다. 재난 대응 중 서버 장애가 겹치면 골든타임을 놓칠 수 있다.
* **심각도:** 🔴 High
* **발생 가능성:** 🟡 Medium
* **대응 방안:** 통합서버 Active-Active 이중화 및 지리적 분산 배포(Primary/DR 데이터센터 분리). CDN 및 로드밸런서 적용으로 부하 분산. 재난 발생 시 오프라인 캐시 모드 지원(전용 앱 로컬 캐시 최신 데이터 유지). RTO/RPO 목표를 SLA로 명문화(예: RTO 15분 이하).

* * *

### 3. GPS 위치 정확도 저하로 인한 GIS 데이터 오염

* **설명:** 도심 밀집 지역, 고층 건물 인근, 지하 진입부 등 GPS 음영지역에서 태깅 시 위치 오차가 10~15m 이상 발생할 수 있다. 잘못된 좌표가 통합서버에 누적되면 GIS 레이어가 오염되어, 굴착 공사 시 실제 매설 위치와 다른 좌표를 참조하는 심각한 오판이 발생한다.
* **심각도:** 🔴 High
* **발생 가능성:** 🟡 Medium
* **대응 방안:** GPS + Wi-Fi RTT + 기지국 삼각측위 융합(Fused Location Provider) 적용으로 정확도 향상. 서버 측 위치 이상값 탐지 로직 구현(동일 태그의 이전 등록 좌표 대비 허용 반경 초과 시 플래그 처리). 정밀 위치가 필요한 최초 등록 시에는 RTK-GPS 측량 장비 사용 의무화.

* * *

### 4. NFC 통신 구간 보안 취약점 및 태그 위변조

* **설명:** NFC는 ~10cm 근거리 통신이지만 전용 장비를 이용한 릴레이 공격(Relay Attack) 또는 태그 데이터 위변조가 가능하다. 악의적 공격자가 특정 매설물의 관종·매설심도·밸브 위치 정보를 변조할 경우, 가스관·상수도관 긴급 차단 판단에 오류를 유발할 수 있다.
* **심각도:** 🔴 High
* **발생 가능성:** 🟢 Low
* **대응 방안:** NFC 태그 내 데이터에 디지털 서명(ECDSA) 적용하여 위변조 탐지. 읽기 전용 영역과 쓰기 제어 영역 분리(NDEF 락 비트 설정). 태그 쓰기 권한은 인가된 관리자 단말에만 부여(기기 인증서 기반 접근 제어). 통합서버에서 수신 데이터의 서명 검증 후 저장.

* * *

### 5. 스마트폰 분실·도난으로 인한 관로 정보 유출

* **설명:** 전용 APP이 설치된 현장 작업자 스마트폰 분실 또는 도난 시, 앱에 캐시된 매설물 정보(위치, 관종, 밸브 위치 등)가 제3자에게 노출될 수 있다. 특히 도심 가스관·전력구 매설 정보는 테러·사보타주에 악용될 수 있는 민감 인프라 데이터다.
* **심각도:** 🔴 High
* **발생 가능성:** 🟡 Medium
* **대응 방안:** 전용 APP에 MDM(Mobile Device Management) 적용하여 원격 데이터 삭제 기능 확보. 앱 로컬 캐시 데이터 AES-256 암호화 저장. 생체인증 또는 PIN 기반 앱 잠금 의무화. 민감 인프라(가스·전력) 관로 정보는 역할 기반 접근 제어(RBAC)로 조회 범위 제한.

* * *

### 6. 관로정보 최초 입력 오류의 장기 지속 위험

* **설명:** 관로정보 입력 단계에서 담당자가 관종, 매설심도, 관경 등을 잘못 입력하면 해당 오류가 NFC 태그와 통합서버에 동시에 기록된다. 오류 데이터는 수년간 검증 없이 사용될 수 있으며, 굴착 공사 시 잘못된 매설심도를 신뢰하여 장비 충돌 사고가 발생할 수 있다.
* **심각도:** 🔴 High
* **발생 가능성:** 🟡 Medium
* **대응 방안:** 입력 데이터 유효성 검증 로직 구현(관종별 표준 매설심도 범위 벗어날 경우 경고). 이중 검토자 승인(Dual Approval) 워크플로우 도입(입력자 외 감독자 승인 후 서버 반영). 기존 도면 데이터와의 자동 교차 검증 모듈 구현. 정기 현장 실측을 통한 데이터 정합성 감사 체계 수립.
