# 🏗️ 아키텍처 분석 보고서

## 📋 ADR (Architecture Decision Record)

### ADR-001: 다중 센서 데이터 통합 기반의 가변형 로봇팔 제어 아키텍처 채택

| 항목 | 내용 |
|------|------|
| **상황(Context)** | 로봇팔이 복잡한 환경(지온, CO2, 공간 정보 등)에서 정밀한 작업을 수행하기 위해, 단순한 위치 제어를 넘어 환경 데이터를 실시간으로 피드백 받아 확장/축소/회전 성능을 최적화해야 하는 과제에 직면함. |
| **결정(Decision)** | 제어부(Controller)와 로봇팔(Actuator) 사이에 가변 제어 신호(확장/축소/회전) 인터페이스를 구축하고, 4종의 이기종 센서(가상, 공간, 지온, CO2) 데이터를 비동기적으로 수집하여 제어 로직에 반영하는 이벤트 기반 피드백 루프를 설계함. |
| **근거(Rationale)** | 물리적 센서(지온, CO2)와 논리적 센서(가상 센서)를 통합함으로써 예측 제어가 가능해지며, 공간 센서를 통해 작업 반경 내 장애물 회피 및 정밀 위치 보정이 가능하기 때문임. |
| **결과(Consequences)** | **긍정적:** 환경 변화에 따른 유연한 로봇팔 운용이 가능하며 작업 정확도가 향상됨. **부정적:** 다수 센서 데이터 처리로 인한 제어부의 연산 부하 증가 및 시스템 복잡도 상승. |
| **트레이드오프(Trade-offs)** | 센서 데이터의 실시간성을 확보하기 위해 시스템 응답 속도를 얻는 대신, 센서 네트워크 구축 및 데이터 동기화 알고리즘 개발에 따른 비용과 복잡성을 감수함. |

---

## ⚠️ 잠재적 위험 분석

### 1. 센서 데이터 동기화 및 지연(Latency) 문제
- **설명:** 지온, CO2 등 반응 속도가 다른 이기종 센서 데이터가 제어부에 도달하는 시간이 불일치하여 로봇팔이 잘못된 시점에 가변 제어 신호를 발생시키는 시나리오.
- **심각도:** 🔴 High
- **발생 가능성:** 🔴 High
- **대응 방안:** 실시간 OS(RTOS) 도입 및 타임스탬프 기반의 데이터 동기화 프로토콜 적용.

### 2. 가상 센서 모델의 신뢰성 결여
- **설명:** 물리 센서를 대체하거나 보조하는 가상 센서의 알고리즘 오류로 인해 실제 환경과 괴리된 가공 데이터를 제공하여 로봇팔의 오작동을 유발하는 시나리오.
- **심각도:** 🔴 High
- **발생 가능성:** 🟡 Medium
- **대응 방안:** 물리 센서 데이터와의 교차 검증(Cross-validation) 로직 구현 및 가상 모델의 지속적인 캘리브레이션.

### 3. 극한 환경에서의 센서 내구성 저하
- **설명:** 고농도 CO2 또는 극한의 지온 변화 환경에서 물리 센서가 부식되거나 오차가 발생하여 제어 신호에 노이즈가 유입되는 시나리오.
- **심각도:** 🟡 Medium
- **발생 가능성:** 🟡 Medium
- **대응 방안:** 산업용 등급의 하드웨어 채택 및 센서 노이즈 필터링(Kalman Filter 등) 알고리즘 고도화.

### 4. 제어 신호 간섭 및 보안 위협
- **설명:** 제어부에서 로봇팔로 전달되는 확장/축소/회전 신호가 외부 통신 간섭으로 인해 왜곡되거나, 비인가자의 접근으로 임의의 제어 명령이 주입되는 보안 사고.
- **심각도:** 🔴 High
- **발생 가능성:** 🟢 Low
- **대응 방안:** 제어 신호 전송 구간의 암호화 및 폐쇄형 네트워크(CAN bus 등) 보안 강화.

### 5. 가변 하드웨어의 물리적 피로 누적
- **설명:** 빈번한 확장 및 축소 제어 신호로 인해 로봇팔의 구동부(Actuator)에 기계적 마모가 가속화되어 예상 수명보다 빠르게 고장이 발생하는 시나리오.
- **심각도:** 🟡 Medium
- **발생 가능성:** 🔴 High
- **대응 방안:** 예지 보전(Predictive Maintenance) 시스템 구축 및 가동 범위 제한(Soft-limit) 설정.
