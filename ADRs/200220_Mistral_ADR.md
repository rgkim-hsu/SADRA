📋 ADR (Architecture Decision Record)
-------------------------------------

### ADR-001: IoT 기반 실시간 환경 모니터링 및 제어 아키텍처 채택

| 항목                     | 내용                                                                                                                                                                          |
| ---------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **상황(Context)**        | 스마트팜 시스템은 기상, 온도, 습도, 토양 수분, 영상 등 다양한 환경 데이터를 실시간으로 수집하여 농작물 재배 최적화를 목표로 함. 기존 시스템은 데이터 수집과 제어가 분리되어 있어 지연 및 비효율성이 발생하며, 사용자(농업인)는 원격에서 실시간으로 시스템을 모니터링하고 제어할 수 있는 기능이 필요함. |
| **결정(Decision)**       | 센서 데이터 수집층(기상관측센서, 온도/습도센서, CCTV)을 통해 데이터를 수집하고, 인터넷을 통해 중앙 서버(사용자 관리 시스템)에 전송한 후, 스마트폰 앱을 통해 사용자에게 제공하며, 동시에 스마트 제어 시스템(전자 밸브, 컨베이어 벨트, 시스템 제어 장치)으로 피드백을 보냄.              |
| **근거(Rationale)**      | 실시간 데이터 수집과 제어를 통해 농작물의 성장 환경을 최적화하고, 원격 모니터링을 통해 사용자의 편의성을 높임. 또한, IoT 기술과 클라우드 기반 아키텍처를 도입하여 확장성과 유연성을 확보함.                                                               |
| **결과(Consequences)**   | **장점**: 실시간 데이터 기반 의사결정 가능, 자동화된 제어로 인력 비용 절감, 원격 접근성 향상. **단점**: 네트워크 의존성 증가로 인한 연결 불안정성, 센서 오류 시 데이터 신빙성 저하.                                                              |
| **트레이드오프(Trade-offs)** | **얻는 장점**: 생산성 향상, 자동화로 인한 효율성 증대. **감수해야 할 단점**: 초기 구축 비용 증가, 시스템 복잡성 증가, 보안 취약점 노출 가능성.                                                                                   |

* * *

⚠️ 잠재적 위험 분석
------------

### 1. 네트워크 연결 불량으로 인한 데이터 손실

* **설명:** 센서에서 수집된 데이터가 인터넷을 통해 서버로 전송되는 과정에서 네트워크 장애가 발생할 경우, 실시간 데이터가 유실되어 농작물 관리에 지장이 발생할 수 있음.
* **심각도:** 🔴 High
* **발생 가능성:** 🟡 Medium
* **대응 방안:** 로컬 스토리지(에지 디바이스)에 데이터를 임시 저장하고, 네트워크 복구 시 동기화하는 메커니즘 도입. 또한, 5G 또는 LTE 백업 네트워크 구축.

* * *

### 2. 센서 오류로 인한 잘못된 제어 명령

* **설명:** 온도/습도 센서 또는 CCTV의 오류로 인해 잘못된 데이터가 수집되어, 스마트 제어 시스템(예: 전자 밸브)이 잘못된 동작을 수행할 수 있음(예: 과도한 관수).
* **심각도:** 🔴 High
* **발생 가능성:** 🟡 Medium
* **대응 방안:** 다중 센서 데이터 교차 검증 및 AI 기반 이상 탐지 시스템 도입. 주기적인 센서 교정 및 유지보수 수행.

* * *

### 3. 보안 취약점으로 인한 시스템 해킹

* **설명:** 인터넷을 통해 연결된 시스템은 사이버 공격(예: DDoS, 데이터 변조)에 노출될 수 있으며, 제어 시스템이 해킹당할 경우 농장 전체에 물리적 손상이 발생할 수 있음.
* **심각도:** 🔴 High
* **발생 가능성:** 🟡 Medium
* **대응 방안:** 끝단에서 끝단 암호화(E2EE), 인증 강화(다요소 인증), 정기적인 보안 패치 및 침입 탐지 시스템(IDS) 도입.

* * *

### 4. 스마트폰 앱의 호환성 문제

* **설명:** 사용자가 다양한 기기(안드로이드/iOS, 구형 기기)에서 앱을 사용할 경우, 호환성 문제로 인해 앱이 제대로 동작하지 않을 수 있음.
* **심각도:** 🟡 Medium
* **발생 가능성:** 🟡 Medium
* **대응 방안:** 크로스 플랫폼 프레임워크(예: Flutter, React Native) 사용 및 정기적인 호환성 테스트 수행.

* * *

### 5. 전력 공급 중단으로 인한 시스템 정지

* **설명:** 센서, 서버, 제어 시스템 등이 전력 공급에 의존적이며, 전력 중단 시 시스템이 정지되어 데이터 수집 및 제어가 중단될 수 있음.
* **심각도:** 🔴 High
* **발생 가능성:** 🟢 Low
* **대응 방안:** UPS(무정전 전원 공급 장치) 및 태양광 발전 등 대안 에너지원 도입. 중요 시스템에 이중화 전원 공급 구축.
