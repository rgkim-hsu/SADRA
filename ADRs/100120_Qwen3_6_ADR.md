## 100120

# 🏗️ 아키텍처 분석 보고서

## 📋 ADR (Architecture Decision Record)

### ADR-001: 스마트팜 제어 시스템 검증을 위한 가상 센서/제어기 기반 시레이션 아키텍처 채택

| 항목                     | 내용                                                                                                                                                                                                                                                  |
| ---------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **상황(Context)**        | 스마트팜 통합 제어 시스템을 개발하거나 검증할 때, 실제 농장 환경(작물, 설비)을 대상으로 테스트하는 것은 시간과 비용이 많이 들며, 잘못된 제어 알고리즘으로 인해 작물 폐사나 설비损坏 등의 치명적 위험이 존재함. 또한, 극한 기상 조건이나 특정 병해충 상황과 같은 드문 시나리오를 실제 환경에서 재현하기 어려움.                                                                    |
| **결정(Decision)**       | 실제 물리적 센서와 제어기를 대체하는 **가상 센서(Virtual Sensor)** 및 **가상 제어기(Virtual Controller)** 모듈을 도입하고, 이들을 **환경 제너레이터(Environment Generator)**와 연동하여 통합 제어 시스템이 실제와 동일한 인터페이스로 상호작용하도록 하는 **시뮬레이션 기반 테스트베드 아키처**를 채택함. 또한, 시뮬레이션 상태를 시각화하기 위해 **3D 환경 뷰어**를 통합함. |
| **근거(Rationale)**      | 1. **안전성 및 비용 효율:** 실제 작물이나 고가 설비에 대한 위험 없이 제어 알고리즘의 안정성을 검증할 수 있음.<br>2. **시나리오 다양성:** 환경 제너레이터를 통해 폭설, 폭염, 장비 고장 등 다양한 가상 상황을 생성하여 시스템의 대응 능력을 광범위하게 테스트할 수 있음.<br>3. **개발 효율성:** 하드웨어 조달 및 설치 대기 시간 없이 소프트웨어 개발과 병렬로 통합 테스트를 진행할 수 있음.           |
| **결과(Consequences)**   | 통합 제어 시스템의 품질과 안정성이 크게 향상되며, 배포 전 잠재적 버그를 사전에 제거할 수 있음. 반면, 가상 센서/제어기의 물리적 모델링 정확도가 낮을 경우 실제 환경 적용 시 예상치 못한 오류가 발생할 수 있음.                                                                                                                           |
| **트레이드오프(Trade-offs)** | 높은 테스트 안전성 및 시나리오 유연성 확보 vs. 가상 모델링(물리 엔진, 센서 노이즈 모델 등)의 복잡도 증가 및 실제 하드웨어와의 미세한 동작 차이 발생 가능성.                                                                                                                                                       |

---

## ⚠️ 잠재적 위험 분석

### 1. 가상 센서/제어기 모델의 정확도 부족으로 인한 검증 신뢰성 하락

- **설명:** 가상 센서가 실제 센서의 응답 특성(지연 시간, 노이즈, 비선형성 등)을 정확히 모사하지 못하거나, 가상 제어기가 실제 액추에이터의 동역학을 반영하지 못할 경우, 시뮬레이션에서는 완벽해 보였던 제어 로직이 실제 농장에 적용되었을 때 오작동할 수 있음.
- **심각도:** 🔴 High
- **발생 가능성:** 🟡 Medium
- **대응 방안:** 실제 하드웨어의 데이터를 수집하여 가상 모델의 파라미터를 보정(Calibration)하는 과정 필수화, 시뮬레이션 결과와 실제 소규모 테스트베드 결과를 비교 검증하는 단계 도입.
  
  ### 2. 통합 제어 시스템과 시뮬레이션 모듈 간 통신 프로토콜 불일치
- **설명:** 스마트팜 통합 제어 시스템이 가상 센서/제어기와 통신할 때 사용하는 프로토콜(MQTT, Modbus 등)이나 데이터 포맷이 실제 기기 и 완전히 일치하지 않을 경우, 시스템이 가상 장치를 인식하지 못하거나 잘못된 데이터를 수신할 수 있음.
- **심각도:** 🔴 High
- **발생 가능성:** 🟡 Medium
- **대응 방안:** 가상 센서/제어기 개발 시 실제 기기의 통신 스펙을 100% 준수하는 에뮬레이터(Emulator) 로직 구현, 프로토콜 분석 도구를 통한 패킷 레벨 검증 수행.
  
  ### 3. 실시간 시뮬레이션 성능 저하 및 지연 (Latency)
- **설명:** 환경 제너레이터의 복잡한 물리 연산이나 3D 환경 뷰어의 렌더링 부하가 높아질 경우, 가상 센서 데이터 생성 및 제어 명령 처리에 지연이 발생하여 통합 제어 시스템의 실시간 제어 루프가 불안정해질 수 있음.
- **심각도:** 🟡 Medium
- **발생 가능성:** 🔴 High
- **대응 방안:** 시뮬레이션 엔진의 최적화(LOD 적용, 계산 주기 분리), 하드웨어 가속(GPU) 활용, 제어 루프와 시각화 루프의 스레드 분리를 통한 성능 격리.
  
  ### 4. 3D 환경 뷰어와 제어 시스템 간 상태 불일치
- **설명:** 3D 환경 뷰어가 표시하는 농장 상태(예: 창문 개폐 상태, 온도 분포)와 통합 제어 시스템이 인식하고 있는 상태가 데이터 동기화 문제로 인해 불일치할 경우, 운영자가 잘못된 판단을 내릴 수 있음.
- **심각도:** 🟡 Medium
- **발생 가능성:** 🟡 Medium
- **대응 방안:** 단일 데이터 소스(SSOT) 원칙 적용하여 환경 제너레이터 또는 가상 센서/제어기의 상태를 중앙에서 관리하고 양쪽 시스템에 동기화, 상태 변경 시 이벤트 기반 업데이트機制 도입.
  
  ### 5. 시뮬레이션 환경 구축 및 유지보수 복잡성
- **설명:** 다양한 작물, 설비, 기상 조건을 시뮬레이션하기 위해 방대한 양의 모델 데이터와 시나리오 스크립트를 관리해야 하므로, 시스템 유지보수 비용이 증가하고 새로운 시나리오 추가에 시간이 많이 소요될 수 있음.
- **심각도:** 🟢 Low
- **발생 가능성:** 🔴 High
- **대응 방안:** 시나리오 편집기(Scenario Editor) 등 사용자 친화적인 도구 제공, 모듈화된 환경 컴포트 라이브러리 구축, 클라우드 기반 시레이션 리소스 공유 플랫폼 도입.
