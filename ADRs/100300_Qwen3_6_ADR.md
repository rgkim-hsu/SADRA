# 🏗️ 아키텍처 분석 보고서

## 📋 ADR (Architecture Decision Record)

### ADR-001: 데이터 기반 순차적 공정 제어 및 환경 최적화 아키텍처 채택

| 항목                    | 내용                                                                                                                                                                                                                                                                         |
| --------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **상황(Context)**       | 버섯 재배 및 가공 공정(S210~S250)에서 알받기, 젤리 투입, 밥 공급, 절식 등 각 단계가 생물학적 반응과 물리적 환경 제어에 민감하게 의존함. 특히 S230(톱밥 공급)과 S240(절식) 공정에서 온도, 습도, 배지 상태 등이 균일하게 관리되지 않을 경우, 최종 출하(S250) 제품의 품질 편차가 심화되는 아키텍처적 과제가 존재함.                                                                           |
| **결정(Decision)**      | 각 공정 단계(S210~S250)를 독립적인 모듈로 분리하되, 상위 제어 시스템이 전 공정의 데이터를 실시간으로 수집하여 다음 단계의 파라미터(예: 톱밥 공급량, 절식 시간)를 동적으로 결정하는 **데이터 기반 순차적 공정 제어(Data-Driven Sequential Process Control) 아텍처**를 채택함.                                                                                        |
| **근거(Rationale)**     | 1. **품질 균일성:** S220(젤리 투입) 데이터와 S230(톱밥 공급) 데이터를 연계하여 배지의 영양 상태와 수분 함량을 최적화함으로써, S240(절식) 단계에서 균사 생육의 균일성을 보장함.<br>2. **실시간 대응:** 공정 중 발생하는 이상 신호(예: 온도 급변, 오염 징후)를 즉시 감지하여 다음 공정으로 전파되는 것을 차단하거나 보정함.<br>3. **추적성:** 각 단계별 데이터(S210~S250)를 기록하여 출하 제품의 이력을 완벽하게 추적할 수 있음. |
| **결과(Consequences)**  | 공정 자동화 수준이 향상되고 인력 의존도가 낮아지며, 제품 품질의 표준화가 가능해짐. 반면, 센서 데이터의 정확도와 실시간 처리 성능이 전체 시스템의 성패를 좌우하게 되며, 초기 시스템 통합 비용이 증가함.                                                                                                                                                        |
| **트레이드프(Trade-offs)** | 고질 균일성 확보 및 공정 효율성 향상 vs. 데이터 의존도 증가로 인한 센서 장애 시 전체 라인 정지 위험 및 시스템 유지보수 복잡성 상승.                                                                                                                                                                                            |

---

## ⚠️ 잠재적 위험 분석

### 1. 톱밥 공급(S230) 제어 오류로 인한 배지 불량

- **설명:** S230 단계에서 톱밥의 공급량이나 교체 주기가 잘못 제어될 경우(예: 과다 공급으로 통기성 저하, 과소 공급으로 영양 부족), 후속 절식 공정(S240)에서 균사 생육이 저해되거나 오염이 발생할 수 있음.
- **심각도:** 🔴 High
- **발생 가능성:** 🟡 Medium
- **대응 방안:** 톱밥 공급 장치에 중량 센서 및 수분 센서를 이중으로 설치하여 공급량 정확도 검증, 공급 오류 시 자동 차단 및 관리자 알림 기능 구현, 정기적인 장비 보정(Calibration) 스케줄 의무화.
  
  ### 2. 젤리 투입(S220) 불균형으로 인한 오염 확산
- **설명:** S220 단계에서 젤리(영양제 또는 응고제)의 투입량이 균일하지 않거나 살균이 불완전할 경우, 특정 알받기(S210) 단계에서만 오염이 발생하여 전체 배지의 오염률이 급증할 수 있음.
- **심각도:** 🔴 High
- **발생 가능성:** 🟡 Medium
- **대응 방안:** 젤리 투입 노즐의 막힘 감지 센서 도입, 투입량 모니터링 및 피드백 제어 루프 적용, 젤리 탱크 내부의 위생 상태(온도, pH) 실시간 모니터링 및 자동 세정(CIP) 시스템 연계.
  
  ### 3. 절식 공정(S240) 환경 제어 실패
- **설명:** S240 단계는 균사 성장에 가장 중요한 시기로, 온도, 습도, CO2 농도 등의 환경 변수가 엄격하게 유지되어야 함. 제어 시스템 장애로 인해 환경 변수가 임계치를 벗어날 경우, 생육 지연 또는 기형 버섯 발생 가능성이 높음.
- **심각도:** 🔴 High
- **발생 가능성:**  Medium
- **대응 방안:** 절식실 내 다중 위치 환경 센서 배치 및 평균값 기반 제어, HVAC(난방, 환기, 공조) 시스템의 이중화(Redundancy) 구성, 환경 이상 시 비상 환기 또는 가동 장치 자동 작동 로직 도입.
  
  ### 4. 공정 간 데이터 동기화 지연
- **설명:** S210부터 S250까지 순차적으로 진행되는 과정에서, 이전 공정의 데이터가 다음 공정 제어 시스템에 실시간으로 전달되지 않을 경우(예: 네트워크 지연), 잘못된 파라미터로 공정이 진행되어 불량품이 양산될 수 있음.
- **심각도:**  Medium
- **발생 가능성:**  Medium
- **대응 방안:** 공정 간 통신에 메시지 큐(Message Queue)를 도입하여 데이터 유실 방지 및 순서 보장, 로컬 엣지 컴퓨팅 장치를 통해 네트워크 단절 시에도 기본 공정 로직이 지속되도록 설계.
  
  ### 5. 출하(S250) 전 품질 데이터 위변조 또는 누락
- **설명:** 최종 출하 단계(S250)에서 이전 공정들의 데이터(S210~S240)가 누락되거나 위변조될 경우, 불량 제품이 정상 제품으로 둔갑하여 출하될 수 있으며, 이는 브랜드 신뢰도 하락으로 이어짐.
- **심각도:** 🟡 Medium
- **발생 가능성:** 🟢 Low
- **대응 방안:** 각 공정 단계의 데이터를 블록체인 또는 변조 방지 로그 서버에 암호화하여 저장, 출하 전 데이터 완전성 검증(Integrity Check) 프로세스 필수화, 이상 데이터 감지 시 출하 중지 인터록(Interlock) 적용.
