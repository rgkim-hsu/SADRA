# 🏗️ 아키텍처 분석 보고서

## 📋 ADR (Architecture Decision Record)

### ADR-001: 엣지-클라우드 협업 기반의 지능형 스마트팜 통합 제어 아키텍처 채택

| 항목 | 내용 |
|------|------|
| **상황(Context)** | 동충하초 재배는 온도, 습도, 조도, CO2 등 환경 변수에 극도로 민감하며, 곰팡이 오염 및 생장 장애 발생 시 대량 폐기 위험이 큼. 이를 실시간으로 감지하고 예측하기 위해 방대한 센서 데이터와 이미지 데이터를 처리할 고성능 AI 모델이 필요하나, 현장(농가)의 네트워크 불안정성과 데이터 보안 문제를 해결해야 함. |
| **결정(Decision)** | 중앙 집중형 빅데이터 학습 플랫폼과 현장 맞춤형 AI 추론 엔진(Edge AI)을 분리하는 하이브리드 아키텍처를 구축함. 중앙 플랫폼에서 전 주기 재배 데이터를 학습하고, 암호화된 최적화 모델을 각 스마트팜 제어기에 배포하여 로컬 실시간 제어를 수행함. |
| **근거(Rationale)** | 1. **실시간성**: 곰팡이 확산 방지를 위해 지연 시간 없는 즉각적인 환경 제어 필요. 2. **보안성**: 이미지 내 '재배 노하우' 누출 방지를 위해 데이터 암호화 전송 및 로컬 처리가 유리. 3. **확장성**: 다양한 농가 환경에서 수집된 데이터를 통합하여 모델의 범용적 정확도를 향상시킬 수 있음. |
| **결과(Consequences)** | 농가별 맞춤형 정밀 제어가 가능해져 수확률이 극대화되고 오염 발생을 최소화함. 데이터 암호화 체계(Lock 아이콘 참조)를 통해 지식 재산권 보호가 강화됨. |
| **트레이드오프(Trade-offs)** | 중앙 학습 인프라와 엣지 디바이스 간의 동기화 복잡성이 증가하며, 초기 인프라 구축 비용이 단순 제어 시스템 대비 높음. |

---

## ⚠️ 잠재적 위험 분석

### 1. 데이터 편향으로 인한 AI 모델 예측 오류
- **설명:** 특정 농가나 계절의 데이터에 편중된 학습이 이루어질 경우, 새로운 환경이나 변종 균주 발생 시 AI가 곰팡이를 오염으로 인식하지 못하거나 오판할 위험.
- **심각도:** 🔴 High
- **발생 가능성:** 🟡 Medium
- **대응 방안:** 다양한 환경 변수를 포함한 합성 데이터(Synthetic Data)를 활용하고, 지속적인 재학습(Continuous Training) 파이프라인을 구축하여 모델 성능을 상시 모니터링함.

### 2. 센서 노후화 및 데이터 정합성 결여
- **설명:** 고습도 환경에서 운영되는 스마트팜 특성상 센서 부식이나 오작동이 잦아, 잘못된 환경 데이터가 AI 모델에 입력되어 시스템 전체의 제어 로직이 붕괴될 시나리오.
- **심각도:** 🔴 High
- **발생 가능성:** 🔴 High
- **대응 방안:** 센서 데이터 이상치 탐지(Outlier Detection) 알고리즘 적용 및 하드웨어 이중화, 정기적인 센서 교체 알림 시스템 운영.

### 3. 데이터 전송 구간 및 모델 암호화 탈취 위험
- **설명:** 학습된 모델이 현장으로 배포되는 과정이나 수집 데이터가 중앙으로 전송될 때, 암호화 알고리즘의 취약점을 이용해 재배 노하우가 외부로 유출될 위험.
- **심각도:** 🟡 Medium
- **발생 가능성:** 🟡 Medium
- **대응 방안:** End-to-End 암호화(TLS 1.3 이상) 적용 및 엣지 디바이스 내 하드웨어 보안 모듈(HSM)을 활용한 모델 복호화 및 실행 보안 강화.

### 4. 엣지 디바이스의 하드웨어 리소스 제약
- **설명:** 고도화된 AI 모델(객체 탐지 등)을 현장의 저사양 제어기에서 구동할 때 메모리 부족이나 연산 지연으로 인해 실시간 대응 속도가 저하될 위험.
- **심각도:** 🟡 Medium
- **발생 가능성:** 🟡 Medium
- **대응 방안:** 경량화 모델(Model Quantization/Pruning) 기법을 적용하여 추론 속도를 최적화하고, 성능 기반의 하드웨어 사양 표준을 준수함.

### 5. 통신 장애 시 로컬 제어 불능 상태 발생
- **설명:** 중앙 서버와의 연결이 끊겼을 때 암호화된 모델 업데이트를 받지 못하거나, 클라우드 의존적인 기능이 멈추면서 대량 재배 플랫폼 전체의 가동률이 저하될 위험.
- **심각도:** 🔴 High
- **발생 가능성:** 🟡 Medium
- **대응 방안:** 오프라인 모드(Fail-safe)를 지원하는 로컬 캐싱 로직 구현 및 통신 복구 시 데이터 동기화 기능을 갖춘 에이전트 설계.
