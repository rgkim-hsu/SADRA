📋 ADR (Architecture Decision Record)
-------------------------------------

### ADR-001: 축종/농가 규모별 맞춤형 스마트 축사 서비스 아키텍처

| 항목                     | 내용                                                                                                                                                                                                |
| ---------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **상황(Context)**        | 본 시스템은 양돈 농가를 대상으로 하며, 대형·소규모·중돈 농장 등 다양한 운영 규모와 환경을 지원해야 합니다. 이미지 상 “맞춤형 스마트 돈사 서비스”는 농가 수요 기반으로 기능이 다르게 제공되며, 출입/시설 관리, 생장 관리, 출하 관리 기능이 모듈화되어 구성되어 있습니다. 핵심 과제는 다양한 농가 환경에 대응하는 유연한 서비스 구조입니다. |
| **결정(Decision)**       | 기능을 **모듈화(Modular Architecture)**하고, 농가 규모 및 요구사항에 따라 선택적으로 조합 가능한** 커스터마이징 기반 서비스 아키텍처**를 채택합니다.                                                                                                 |
| **근거(Rationale)**      | 농가별로 필요한 기능 수준과 투자 여력이 다르기 때문에 일괄적인 시스템 제공은 비효율적입니다. 모듈형 구조는 확장성과 비용 효율성을 동시에 확보할 수 있습니다.                                                                                                         |
| **결과(Consequences)**   | 다양한 고객 요구 대응이 가능하며 시장 확장성이 증가합니다. 반면, 모듈 간 의존성 관리와 테스트 복잡성이 증가합니다.                                                                                                                                |
| **트레이드오프(Trade-offs)** | 유연성과 확장성을 확보하는 대신, 시스템 통합 복잡성과 운영 비용 증가를 감수해야 합니다.                                                                                                                                                |

### ADR-002: 영상 기반 모니터링 및 행동 분석 시스템 도입

| 항목                     | 내용                                                                                            |
| ---------------------- | --------------------------------------------------------------------------------------------- |
| **상황(Context)**        | 시스템에는 CCTV 기반 영상 분석 기능(활력 확인, 이상 행동 감지, 체중/온도 추정 등)이 포함되어 있으며, 단순 센서 기반을 넘어 영상 데이터 활용이 핵심입니다. |
| **결정(Decision)**       | **영상 스트림 처리 및 AI 기반 행동 분석 엔진**을 도입하여 실시간 모니터링 및 자동 이벤트 감지 기능을 구현합니다.                          |
| **근거(Rationale)**      | 영상 데이터는 개체 상태를 직관적으로 파악할 수 있으며, 질병 징후 및 이상 행동을 조기에 탐지할 수 있습니다. 이는 생산성 및 질병 예방 측면에서 매우 중요합니다.  |
| **결과(Consequences)**   | 자동화된 모니터링과 정밀 관리가 가능해집니다. 그러나 높은 연산 비용과 데이터 저장 부담이 발생합니다.                                     |
| **트레이드오프(Trade-offs)** | 고급 분석 기능을 확보하는 대신, 인프라 비용(GPU, 저장소 등)과 시스템 복잡성이 증가합니다.                                        |

### ADR-003: 통합 운영 관리 플랫폼 및 단계적 기능 제공 전략

| 항목                     | 내용                                                                                     |
| ---------------------- | -------------------------------------------------------------------------------------- |
| **상황(Context)**        | 시스템은 출입/시설 관리, 생장 관리, 출하 관리 기능으로 구성되며, 각 기능은 농가 규모에 따라 일부만 제공되거나 전체 제공됩니다.             |
| **결정(Decision)**       | 핵심 기능을 **단계별(기본 → 확장 → 고급)**로 나누어 제공하는 **계층형 서비스 제공 전략**을 채택합니다.                       |
| **근거(Rationale)**      | 초기 도입 장벽을 낮추고 점진적 고도화를 가능하게 하기 위함입니다. 특히 소규모 농가는 필수 기능만 필요하며, 대형 농가는 고급 분석 기능까지 요구합니다. |
| **결과(Consequences)**   | 고객 유입이 용이해지고 업셀링(Up-selling) 전략이 가능해집니다. 반면, 기능 간 버전 관리가 복잡해질 수 있습니다.                  |
| **트레이드오프(Trade-offs)** | 시장 확대와 유연한 도입이 가능하지만, 제품 라인업 관리와 유지보수 부담이 증가합니다.                                       |

⚠️ 잠재적 위험 분석
------------

### 1. 영상 데이터 처리 부하 증가

* **설명:** 다수의 CCTV 영상이 동시에 처리되면서 분석 지연 및 시스템 성능 저하 발생 가능

* **심각도:** 🔴 High

* **발생 가능성:** 🔴 High

* **대응 방안:** Edge AI 도입, 이벤트 기반 처리, GPU 클러스터링 및 스트리밍 최적화

* * *

### 2. 개인/농가 데이터 보안 및 프라이버시 문제

* **설명:** 영상 및 운영 데이터 유출 시 농가 운영 정보가 외부에 노출될 위험

* **심각도:** 🔴 High

* **발생 가능성:** 🟡 Medium

* **대응 방안:** 데이터 암호화, 접근 제어, 영상 마스킹 및 보안 정책 강화

* * *

### 3. 모듈 간 호환성 및 통합 문제

* **설명:** 다양한 기능 모듈 조합 시 인터페이스 충돌 및 데이터 불일치 발생 가능

* **심각도:** 🟡 Medium

* **발생 가능성:** 🔴 High

* **대응 방안:** 표준 API 정의, 마이크로서비스 아키텍처 적용, 통합 테스트 자동화

* * *

### 4. AI 분석 정확도 저하

* **설명:** 환경 변화(조명, 밀집도 등)에 따라 영상 분석 정확도가 떨어질 가능성

* **심각도:** 🟡 Medium

* **발생 가능성:** 🟡 Medium

* **대응 방안:** 지속적인 모델 학습, 데이터셋 다양화, 정확도 모니터링 체계 구축

* * *

### 5. 현장 네트워크 인프라 한계

* **설명:** 농장 환경 특성상 네트워크 품질이 낮아 데이터 전송 지연 발생 가능

* **심각도:** 🔴 High

* **발생 가능성:** 🟡 Medium

* **대응 방안:** 로컬 캐싱, Edge 처리, 저전력 통신 기술(LPWAN 등) 활용

* * *

### 6. 사용자(농가)의 기술 수용성 부족

* **설명:** 고도화된 시스템에 대한 농가의 이해 부족으로 활용도가 낮아질 수 있음

* **심각도:** 🟡 Medium

* **발생 가능성:** 🟡 Medium

* **대응 방안:** UI/UX 단순화, 사용자 교육 프로그램 제공, 운영 지원 서비스 강화
