# 🏗️ 아키텍처 분석 보고서

## 📋 ADR (Architecture Decision Record)

### ADR-001: 근적외선(NIR) 분광 분석 기반의 실시간 정량 분석 시스템 채택

| 항목 | 내용 |
|------|------|
| **상황(Context)** | 화학 물질이나 식품, 제약 공정에서 시료의 파괴 없이 실시간으로 성분 함량을 측정해야 하는 과제에 직면함. 기존 FT-IR(중간적외선) 방식은 정성 분석과 구조 파악에는 유리하나, 높은 흡광도로 인해 시료 전처리가 필수적이며 수분이 포함된 시료 측정에 한계가 있음. |
| **결정(Decision)** | **0.8μm ~ 2.5μm(12,500 ~ 4,000cm⁻¹)** 영역의 **근적외선(NIR)**을 활용한 **FT-NIR** 분광 분석 아키텍처를 주 분석 엔진으로 결정함. |
| **근거(Rationale)** | NIR 영역은 배음(Overtone)과 조합(Combination) 밴드를 활용하므로 투과력이 좋아 시료의 직접 측정이 가능함. 특히 '정량 분석'에 특화되어 있어 생산 라인의 인라인(In-line) 모니터링에 최적화된 데이터 흐름을 생성할 수 있음. |
| **결과(Consequences)** | 시료 전처리 과정이 생략되어 분석 리드타임이 획기적으로 단축됨. 복잡한 파형 데이터를 처리하기 위한 다변량 통계 분석(Chemometrics) 모델 도입이 필수적이며, 이를 통해 실시간 품질 제어가 가능해짐. |
| **트레이드오프(Trade-offs)** | FT-IR 대비 신호가 약하고 피크가 중첩되어 있어, 데이터 해석을 위한 초기 알고리즘 구축 비용과 고성능 연산 자원이 추가로 요구됨. |

---

## ⚠️ 잠재적 위험 분석

### 1. 분광 데이터의 중첩 및 모델 해석 복잡성
- **설명:** NIR 영역의 특성상 Overtone과 Combination 밴드가 서로 겹쳐 나타나므로, 특정 성분의 변화를 단일 피크로 식별하기 어려워 정량 모델의 오차가 발생할 시 원인 파악이 지연될 수 있음.
- **심각도:** 🔴 High
- **발생 가능성:** 🔴 High
- **대응 방안:** 고차 분광(Derivative) 처리 및 PLS(Partial Least Squares) 등 고급 다변량 분석 알고리즘을 적용하고, 주기적인 표준 시료 대조를 통해 모델을 갱신함.

### 2. 주변 환경(온도/습도) 변화에 따른 데이터 왜곡
- **설명:** 근적외선은 온도 변화와 수분에 매우 민감함. 측정 환경의 미세한 변화가 스펙트럼의 베이스라인 시프트(Shift)를 유발하여 분석 결과의 신뢰도를 떨어뜨릴 수 있음.
- **심각도:** 🟡 Medium
- **발생 가능성:** 🔴 High
- **대응 방안:** 항온·항습 설비를 구축하거나, 소프트웨어적으로 온도 보정 알고리즘을 분석 파이프라인에 포함시킴.

### 3. 검교정 모델(Calibration)의 전이성(Transferability) 결여
- **설명:** 특정 장비에서 생성한 정량 모델이 하드웨어의 미세한 공차로 인해 다른 장비(Scale-out 시)에서 동일하게 작동하지 않을 위험이 있음.
- **심각도:** 🟡 Medium
- **발생 가능성:** 🟡 Medium
- **대응 방안:** 장비 간 표준화(Standardization) 프로토콜을 수립하고, Master-Slave 장비 간의 스펙트럼 매칭 기술을 도입함.

### 4. 실시간 데이터 처리 부하 및 지연
- **설명:** FT-NIR에서 생성되는 대용량 간섭계 데이터를 실시간으로 푸리에 변환(FFT)하고 정량 알고리즘에 통과시키는 과정에서 컴퓨팅 자원 병목이 발생할 수 있음.
- **심각도:** 🟢 Low
- **발생 가능성:** 🟡 Medium
- **대응 방안:** 분석 엔진의 병렬 처리 아키텍처를 도입하고, 엣지 컴퓨팅 노드를 활용하여 전처리와 추론 과정을 분산함.

### 5. 광원(Source) 노후화에 따른 신호 대 잡음비(SNR) 저하
- **설명:** NIR 광원은 소모품으로, 사용 시간에 따라 광량이 감소하며 이는 곧 데이터의 노이즈 증가로 이어져 정밀한 정량 분석을 방해함.
- **심각도:** 🟡 Medium
- **발생 가능성:** 🔴 High
- **대응 방안:** 광원 가동 시간 모니터링 시스템을 구축하고, SNR 수치가 임계치 이하로 떨어질 경우 자동으로 관리자에게 교체 알람을 송출하는 예방 정비(PdM) 체계 가동.
