📋 ADR (Architecture Decision Record)
-------------------------------------

### ADR-001: 이미지 기반 생육정보 산출 아키텍처

| 항목               | 내용                                                                                                                                                                                 |
| ---------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **상황(Context)**  | 시스템은 이미지 제공모듈(100)로부터 작물 이미지를 입력받아 생육정보 산출모듈(200)에서 분석을 수행한다. 분석 과정에서는 기존정보 데이터베이스(300)와 영농정보 데이터베이스(400)를 참조하며, 최종 결과는 사용자단말(400)에 제공된다. 핵심 목표는 이미지 기반으로 작물 생육 상태를 자동으로 판단하는 것이다. |
| **결정(Decision)** | **이미지 분석 기반 AI 생육 판단 아키텍처**를 채택한다.                                                                                                                                                 |

* 입력 계층: 이미지 제공모듈

* 분석 계층: 생육정보 산출모듈 (AI/Computer Vision)

* 데이터 계층: 기존정보 DB + 영농정보 DB

* 서비스 계층: 사용자 단말 결과 제공 |  
  | **근거(Rationale)** | 작물 생육 상태를 육안으로 판단하는 것은 주관적이며 비효율적이다. 이미지 분석을 활용하면 객관적이고 자동화된 판단이 가능하며, 기존 데이터와 결합하면 정확도를 높일 수 있다. |  
  | **결과(Consequences)** | 생육 상태를 자동으로 분석하여 농업 의사결정을 지원할 수 있다. 그러나 이미지 품질과 데이터셋에 대한 의존도가 증가한다. |  
  | **트레이드오프(Trade-offs)** | 자동화 및 객관성 확보(장점) vs 데이터 품질 의존성(단점), 분석 속도 향상(장점) vs AI 모델 구축 비용(단점) |

* * *

⚠️ 잠재적 위험 분석
------------

### 1. 이미지 품질 문제

* **설명:** 해상도, 조명, 촬영 각도에 따라 분석 결과 왜곡

* **심각도:** 🔴 High

* **발생 가능성:** 🔴 High

* **대응 방안:** 촬영 가이드 제공, 이미지 전처리(노이즈 제거, 보정)

* * *

### 2. AI 모델 정확도 한계

* **설명:** 병해, 생육 단계 등을 정확히 판별하지 못할 가능성

* **심각도:** 🔴 High

* **발생 가능성:** 🟡 Medium

* **대응 방안:** 대규모 학습 데이터 확보, 지속적 모델 개선

* * *

### 3. 데이터베이스 의존성

* **설명:** 기존정보 DB 및 영농정보 DB가 부정확할 경우 결과 오류 발생

* **심각도:** 🔴 High

* **발생 가능성:** 🟡 Medium

* **대응 방안:** 데이터 검증 및 정기 업데이트

* * *

### 4. 실시간 처리 지연

* **설명:** 이미지 분석 처리 시간이 길어 사용자 경험 저하

* **심각도:** 🟡 Medium

* **발생 가능성:** 🟡 Medium

* **대응 방안:** 경량 모델 사용, GPU/엣지 추론 도입

* * *

### 5. 다양한 작물/환경 대응 한계

* **설명:** 특정 작물 또는 환경에만 최적화된 모델일 가능성

* **심각도:** 🔴 High

* **발생 가능성:** 🟡 Medium

* **대응 방안:** 작물별 모델 분리, 도메인 확장 학습

* * *

### 6. 사용자 입력/사용 오류

* **설명:** 잘못된 이미지 업로드 또는 사용 방식 오류

* **심각도:** 🟡 Medium

* **발생 가능성:** 🔴 High

* **대응 방안:** UX 개선, 자동 검증(blur detection 등)
