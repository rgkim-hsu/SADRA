# 🏗️ 아키처 분석 보고서

## 📋 ADR (Architecture Decision Record)

### ADR-001: 로봇팔 기반 다중 물리-가상 센서 통합 및 제어 아텍처 채택

| 항목                     | 내용                                                                                                                                                                                                                                                                                                                  |
| ---------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **상황(Context)**        | 복잡한 환경 모니터링(예: 스마트팜, 공장 자동화 등)에서 단일 고정 센서로는 공간적, 물리적 제약으로 인해 정확한 데이터 수집이 어려움. 특히 지온, CO2 농도, 공간 정보 등 이기종 데이터를 종합적으로 수집하고, 이를 기반으로 시뮬레이션 또는 예측(가상 센서)을 수행해야 하는 아키텍처적 과제가 존재함.                                                                                                                                        |
| **결정(Decision)**       | **로봇팔(Robot Arm)**을 중심 액추에이터로 채택하고, 제어부로부터 확장/축소/회전 제어 신호를 받아 이동하며 **가상센서, 공간센서, 지온센서, CO2센서**를 통합적으로 운용하는 **모바일 센서 융합 아키텍처**를 채택함.                                                                                                                                                                                 |
| **근거(Rationale)**      | 1. **공간적 유연성:** 로봇팔의 확장/축소/회전 기능을 활용하여 고정형 센서가 접근하기 어려운 지점(예: 특정 깊이의 토양, 높은 곳의 공기 중 CO2)에 센서를 배치하여 데이터 수집의 정밀도를 높임.<br>2. **다중 데이터 소스 통합:** 물리적 센서(지온, CO2, 공간)와 소프트웨어적 모델인 가상센서를 단일 플랫폼에 통합함으로써, 실제 데이터와 시뮬레이션 데이터를 교차 검증 및 보강할 수 있음.<br>3. **중앙 집중식 제어:** 제어부에서 로봇팔의 동작과 센서 데이터 수집 시점을 동기화하여 효율적인 데이터 파이프라인을 구성함. |
| **결과(Consequences)**   | 환경 데이터 수집의 범위와 정확도가 획기적으로 향상되며, 가상 센서를 통한 예측 분석이 가능해짐. 반면, 로봇팔의 기계적 제어 복잡도가 증가하고, 이동 중 센서 데이터의 노이즈 발생 가능성이 높아짐.                                                                                                                                                                                                     |
| **트레이드오프(Trade-offs)** | 데이터 수집의 공간적 유연성 및 다중 센서 통합 효율성 확보 vs. 기계적 제어의 복잡성 증가 및 센서 데이터의 물리적 간섭(진동, 열 등) 위험.                                                                                                                                                                                                                                  |

---

## ️ 잠재적 위험 분석

### 1. 로봇팔 동작에 의한 센서 데이터 노이즈 및 왜곡

- **설명:** 제어부의 확장/축소/회전 신호에 따라 로봇팔이 움직일 때 발생하는 진동이나 모터의 발열이 민감한 센서(특히 지온센서, CO2센서)의 측정값에 영향을 미쳐 부정확한 데이터를 수집할 수 있음.
- **심각도:** 🔴 High
- **발생 가능성:** 🔴 High
- **대응 방안:** 데이터 수집 시 로봇팔의 동작을 일시 정지하는 'Stop-and-Measure' 프로토콜 적용, 센서와 모터 사이에 방열/방진 패드 설치, 소프트웨어적 필터링(Kalman Filter 등)으로 노이즈 제거.
  
  ### 2. 가상센서 모델의 오류 전파 (Garbage In, Garbage Out)
- **설명:** 가상센서가 다른 물리 센서(공간, 지온, CO2)의 데이터를 입력값으로 사용하여 값을 추정할 경우, 물리 센서의 오차가 가상센서의 출력으로 증폭되어 전달될 수 있음.
- **심각도:** 🟡 Medium
- **발생 가능성:** 🟡 Medium
- **대응 방안:** 물리 센서 데이터의 신뢰도 점수(Confidence Score)를 계산하여 임계치 이하일 경우 가상센서 연산 중단 또는 경고 발생, 정기적인 가상센서 모델 보정(Calibration) 프로세스 도입.
  
  ### 3. 제어 신호 지연으로 인한 로봇팔 오작동
- **설명:** 제어부에서 생성된 확장/축소/회전 제어 신호가 로봇팔에 전달되는 과정에서 네트워크 지연이나 처리 병목이 발생하면, 로봇팔이 예상치 못한 위치에서 멈추거나 과속하여 센서나 주변 기기를 파손할 수 있음.
- **심각도:** 🔴 High
- **발생 가능성:**  Medium
- **대응 방안:** 실시간 제어 프로토콜(예: EtherCAT, CAN) 적용, 로봇팔 내부에 로컬 컨트롤러를 두어 실시간 안전 로직(Emergency Stop) 처리, 통신 손실 시 자동 복귀(Fail-safe) 기능 구현.
  
  ### 4. 이기종 센서 간 물리적 간섭
- **설명:** 로봇팔이라는 제한된 공간에 공간센서, 지온센서, CO2센서가 밀집되어 설치될 경우, 센서 간의 전자기 간섭(EMI)이나 열 간섭이 발생하여 측정 정확도가 떨어질 수 있음.
- **심각도:** 🟡 Medium
- **발생 가능성:** 🟡 Medium
- **대응 방안:** 센서 배치 시 간섭 최소화 거리 확보, 차폐(Shielding) 처리된 케이블 및 하우징 사용, 센서 동작 주기를 시분할(Time-division)하여 동시 작동 시 간섭 방지.
  
  ### 5. 단일 제어부의 장애로 인한 전체 시스템 마비
- **설명:** 로봇팔의 모든 동작과 센서 데이터 수집을 제어부가 중앙에서 관리하므로, 제어부에 장애가 발생할 경우 로봇팔의 움직임은 물론 모든 센서 데이터 수집이 중단되는 단일 장애점(SPOF)이 될 수 있음.
- **심각도:** 🔴 High
- **발생 가능성:** 🟢 Low
- **대응 방안:** 제어부의 이중화(Redundancy) 구성, 로봇팔 자체에 간단한 자율 제어 로직(장애 시 원점 복귀 등) 내장, 정기적인 제어부 상태 모니터링 및 헬스 체크 수행.
