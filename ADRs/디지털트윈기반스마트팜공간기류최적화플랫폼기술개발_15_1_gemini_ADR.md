# 🏗️ 아키텍처 분석 보고서

## 📋 ADR (Architecture Decision Record)

### ADR-001: 기류 최적화를 위한 3-Way Digital Twin 동기화 모델 채택

| 항목 | 내용 |
|------|------|
| **상황(Context)** | 식물 공장(Plant Factory) 내의 정밀한 기류 제어를 위해 물리적 시스템의 공간 정보, 물리 법칙(행동), 실시간 운영 데이터가 통합된 고정밀 시뮬레이션 환경이 필요함. |
| **결정(Decision)** | 물리 시스템으로부터 **Spatial copy(GIS/BIM)**, **Behavior copy(Simulation Model)**, **Data copy(Operation Data)**를 분리하여 수집하고, 이를 **DT Formalism**을 통해 하나의 기류 모델로 통합하는 아키텍처를 결정함. |
| **근거(Rationale)** | 단순 모니터링을 넘어선 기류 최적화를 위해선 정적인 공간 구조(BIM)와 동적인 센서 데이터, 그리고 물리적 기류 방정식(CFD 등)이 유기적으로 결합되어야만 실제 현상과 일치하는 시뮬레이션이 가능하기 때문임. |
| **결과(Consequences)** | 실제 식물 공장과 가상 모델 간의 높은 정합성을 확보할 수 있으며, 시뮬레이션 데이터를 바탕으로 가상 환경 내에서 다양한 기류 제어 시나리오를 사전에 테스트할 수 있음. |
| **트레이드오프(Trade-offs)** | 고정밀 데이터 통합으로 인한 분석 정확도는 향상되나, 세 가지 다른 소스의 데이터를 실시간으로 동기화하고 Formalism을 유지하기 위한 시스템 복잡도 및 컴퓨팅 자원 소모가 증가함. |

---

## ⚠️ 잠재적 위험 분석

### 1. 실시간 데이터 동기화 지연 (Data Latency)
- **설명:** 물리적 시스템(Physical System)의 센서 데이터가 Digital Twin의 Operation Data로 전달되는 과정에서 지연이 발생하여 실제 상황과 시뮬레이션 간의 시차가 발생하는 시나리오.
- **심각도:** 🔴 High
- **발생 가능성:** 🟡 Medium
- **대응 방안:** Edge Computing 계층을 도입하여 현장에서 1차 데이터 처리를 수행하고, 고속 메시지 큐(Kafka 등)를 활용한 저지연 데이터 파이프라인 구축.

### 2. 시뮬레이션 모델의 물리적 정확도 저하 (Model Fidelity Risk)
- **설명:** Simulation Model이 실제 유체 역학적 변수(온도, 습도에 따른 기류 변화)를 충분히 반영하지 못해 실제 환경과 시뮬레이션 결과값 사이에 오차가 발생하는 경우.
- **심각도:** 🔴 High
- **발생 가능성:** 🟡 Medium
- **대응 방안:** ML 기반 DT Validation 단계를 강화하여 실제 운영 데이터와 시뮬레이션 데이터를 지속적으로 비교(Back-testing)하고 모델 파라미터를 자동 최적화하는 피드백 루프 구현.

### 3. 공간 정보 업데이트 누락 (BIM Static Data Drift)
- **설명:** 식물 공장 내 물리적 구조물(재배 선반, 환풍기 위치 등) 변경 시 GIS/BIM/3D-CAD 데이터가 즉각 업데이트되지 않아 기류 분석의 기본 전제가 왜곡되는 시나리오.
- **심각도:** 🟡 Medium
- **발생 가능성:** 🟡 Medium
- **대응 방안:** 변경 관리 프로세스를 자동화하거나, 주기적으로 LiDAR 스캐닝 등을 통해 실제 공간 구조와 디지털 모델의 일치 여부를 검증하는 프로세스 도입.

### 4. 머신러닝 모델의 오버피팅 및 검증 실패
- **설명:** Machine Learning based DT Validation 과정에서 특정 시점의 데이터에만 과적합(Overfitting)되어, 계절 변화나 설비 노후화 등 새로운 변수가 발생했을 때 유효한 검증을 수행하지 못하는 경우.
- **심각도:** 🟡 Medium
- **발생 가능성:** 🔴 High
- **대응 방안:** 다양한 환경 변수를 포함한 합성 데이터(Synthetic Data)를 활용하여 학습 데이터를 증강하고, MLOps 체계를 도입하여 모델의 성능을 지속적으로 모니터링 및 재학습.

### 5. 데이터 무결성 및 보안 위협
- **설명:** 외부로부터 Data copy 경로에 비정상적인 데이터가 주입되거나, 공간 정보 시스템(GIS/BIM)에 대한 접근 권한 탈취로 인해 디지털 트윈의 제어 로직이 왜곡되는 시나리오.
- **심각도:** 🔴 High
- **발생 가능성:** 🟢 Low
- **대응 방안:** 데이터 전송 구간 암호화(TLS), API Gateway를 통한 접근 제어 및 이상 데이터 탐지(Anomaly Detection) 알고리즘 적용.
