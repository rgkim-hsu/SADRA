# 🏗️ 아키텍처 분석 보고서

## 📋 ADR (Architecture Decision Record)

### ADR-001: 컴퓨터 비전 기반 생육 정보 산출 시스템의 모듈화 아키텍처 채택

| 항목 | 내용 |
|------|------|
| **상황(Context)** | 농작물의 생육 상태를 정밀하게 진단하기 위해 이미지 데이터를 수집(100), 분석(200), 데이터베이스(300, 400) 연동 및 사용자 인터페이스(500) 제공이 필요함. 특히 이미지로부터 기관 분류(220), 보정(230), 계측(240), 과중 산출(250) 등 복잡한 전처리와 추론 과정을 거쳐야 하므로 각 기능 간의 독립성과 확장성 확보가 필수적인 상황임. |
| **결정(Decision)** | 전체 시스템을 이미지 제공, 생육 정보 산출, 기준 정보 관리, 영농 정보 관리, 사용자 단말의 5대 핵심 모듈로 분리하고, 생육 정보 산출 모듈(200) 내부를 기능 단위의 하위 컴포넌트(210~280)로 세분화하는 **강결합 방지형 파이프라인 아키텍처**를 결정함. |
| **근거(Rationale)** | 1. **유지보수 용이성:** 특정 단계(예: 보정 로직 230)의 알고리즘 개선 시 타 모듈에 미치는 영향을 최소화함. 2. **재사용성:** 산출된 생육 데이터(260)를 다양한 영농 정보(400)와 매칭(270)하여 부가가치를 창출하기 용이함. 3. **전문성 분리:** 데이터 수집 하드웨어와 분석 소프트웨어를 독립시켜 이기종 단말 지원이 가능함. |
| **결과(Consequences)** | 긍정적으로는 알고리즘 업데이트 주기가 빨라지고 시스템 유연성이 향상됨. 부정적으로는 모듈 간 통신(데이터 전송부 120, 정보 전송부 280)에 따른 오버헤드와 지연 시간이 발생할 수 있으며, 모듈 간 인터페이스 표준화 작업에 초기 비용이 발생함. |
| **트레이드오프(Trade-offs)** | 개발 복잡도와 초기 구축 비용은 상승하나, 장기적인 시스템 운영 안정성과 농업 현장의 다양한 요구사항에 대응할 수 있는 확장성을 확보함. |

---

## ⚠️ 잠재적 위험 분석

### 1. 이미지 데이터 품질 저하에 따른 분석 정밀도 하락
- **설명:** 야외 농장 환경의 조도 변화, 카메라 렌즈 오염, 초점 불량 등으로 인해 이미지 제공 모듈(100)에서 전송된 원천 데이터의 품질이 낮을 경우, 이후 모든 산출 단계(220~260)에서 심각한 오차 발생.
- **심각도:** 🔴 High
- **발생 가능성:** 🔴 High
- **대응 방안:** 이미지 입력부(210)와 보정부(230) 사이에 품질 검수 알고리즘을 도입하여, 기준 미달 이미지는 즉시 재촬영 요청을 보내거나 사용자에게 알림을 전송하는 전처리 강화.

### 2. 대량 이미지 처리 시 발생하는 시스템 병목 현상
- **설명:** 수많은 사용자 단말(500)로부터 동시에 고해상도 이미지가 유입될 경우, 생육 정보 산출 모듈(200)의 연산 부하가 급증하여 정보 전송(280)이 지연됨.
- **심각도:** 🔴 High
- **발생 가능성:** 🟡 Medium
- **대응 방안:** 생육 정보 산출 모듈을 컨테이너화(Containerization)하여 트래픽에 따라 오토스케일링이 가능하도록 구성하고, 비동기 큐 방식을 도입하여 처리 우선순위 관리.

### 3. 기준 정보 데이터베이스(300)의 일관성 및 정합성 위기
- **설명:** 작물별 생육 기준 정보가 최신화되지 않거나 데이터베이스(300) 오류 발생 시, 과중 산출(250) 및 생육 정보 산출(260) 결과가 실제 농가 현황과 맞지 않아 잘못된 영농 의사결정을 유도함.
- **심각도:** 🔴 High
- **발생 가능성:** 🟢 Low
- **대응 방안:** 기준 정보의 주기적 마스터 데이터 업데이트 프로세스를 구축하고, 산출 결과가 임계치를 벗어날 경우 전문가의 승인을 거치도록 하는 휴먼-인-더-루프(Human-in-the-loop) 검증 단계 도입.

### 4. 사용자 단말(500)과 서버 간 보안 취약점
- **설명:** 사용자 단말과 시스템 사이의 통신 과정에서 영농 정보 및 개인 자산 정보가 유출되거나, 비인가된 단말이 시스템에 접속하여 데이터를 조작할 위험.
- **심각도:** 🟡 Medium
- **발생 가능성:** 🟡 Medium
- **대응 방안:** 모든 통신 구간에 TLS 암호화를 적용하고, API 게이트웨이를 통한 강화된 인증/인가 체계 및 단말별 고유 키 관리 정책 시행.

### 5. 데이터 스토리지(400) 용량 급증에 따른 비용 및 성능 문제
- **설명:** 지속적으로 축적되는 고해상도 원본 이미지와 분석 결과가 영농 정보 데이터베이스(400)에 무한정 쌓이면서 스토리지 비용 상승 및 쿼리 성능 저하 초래.
- **심각도:** 🟡 Medium
- **발생 가능성:** 🔴 High
- **대응 방안:** 데이터 생명주기 관리(Information Lifecycle Management) 정책을 수립하여 일정 기간이 지난 원본 이미지는 콜드 스토리지로 이동하거나 압축/삭제하고, 메타데이터 중심의 인덱싱 최적화 수행.
